# video-single-skill

视频提示词工作流纯净版

## Skills

- [storyboard-prompt-optimizer-l5](skills/storyboard-prompt-optimizer-l5/SKILL.md)：AI分镜提示词全知优化器·L5微表情与打斗质感版。诊断原始分镜提示词，输出待确认槽位、每镜独立文本框的 L5 优化版、多模型适配映射、八层反提示词与自检清单。

- [v1.1 Seedance 2.5 适配](docs/优化记录-v1.1-Seedance2.5.md)：依据火山方舟 Seedance 2.5 官方提示词指南与教程，新增 Seedance 2.5 适配模块。
- [v1.2 人物位置关系](docs/优化记录-v1.2-位置关系.md)：依据位置关系提示词样例（36 条），新增人物位置关系库并接入诊断、槽位、写作和自检。
- [v1.3 运镜写法](docs/优化记录-v1.3-运镜.md)：依据运镜教程（12 种运镜），新增运镜写法库，并把每种运镜改写成 Seedance 2.5 整数秒时间戳写法。
- [v1.4 镜头语法](docs/优化记录-v1.4-镜头语法.md)：依据 script-to-drama-prompt-sd25 的镜头语法选择表，新增“为什么这样拍”的选择依据和可执行度分级，并修正竖屏站位和高风险运镜。

- [v1.7 场景道具连续性](docs/优化记录-v1.7-场景道具连续性.md)：解决场景图道具重复叠加、切镜后握手错手和站位互换、多个同类物体选错三类实际问题。
- [v1.8 姿态锁定](docs/优化记录-v1.8-姿态锁定.md)：解决切镜后坐站姿态错乱和左右互换。
- [v1.9 片头片尾标题](docs/优化记录-v1.9-片头片尾标题.md)：依据官方案例补上片头标题卡、片尾和 logo 的写法。
- [v1.10 轴线视频教程核对](docs/优化记录-v1.10-轴线视频教程核对.md)：修正过肩示例的左右肩错误，新增空间锚点、反应后切镜和分段拼接的 1 秒技术全景。

- [v1.15 动作焦点情绪弧](docs/优化记录-v1.15-动作焦点情绪弧.md)：经官方核对后吸收动作阶段、移焦写法、负载检查、群戏、占手与固定光线、画内演奏例外，以及情绪弧功能位、触发器、强度和核心道具状态表；镜头数改为两档参考。
