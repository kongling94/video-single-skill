# 分支优化记录：AIGC 手册借鉴（实验分支，未发布为正式版本）

分支：`opt/aigc-manual-iso-night-focal`，基于 main `b3bab13`（v1.43）。

## 来源与边界

来源是用户提供的外部《AIGC电影短片制作全手册》（即梦 Seedance 2.5 面板打法），不是官方文档。本分支只借 3 件小事，不把手册的单镜头扁平公式、面板强度数字、音频开关参数照搬进本 skill；主版本号仍为 v1.43，不升 v1.44，合并前须由用户实测反馈决定。

## 改动（共 2 个文件，4 行新增）

1. `references/reference-asset-prep.md` 第五节：把 90° 正俯视和斜俯视正等轴测线稿（iso）分开。90° 平面图仍默认不上传；iso 只有在纯轮廓无文字、空间锁文字仍是第一约束、严格站位仍用关键帧、每集先实测的前提下才可实验上传，不升为默认。面板强度数字不写进提示词和适配参数表。
2. `references/camera-grammar.md` 第五节：新增夜景人脸补光句，只用场景里已有的暖黄漫射光，不凭空新增光源，不写霓虹、射灯频闪。
3. `references/camera-grammar.md` 第六节：新增景别与焦距的内部选镜对照（特写≈长焦、中景≈标准、全景≈广角；浅/中/深景深的效果写法），毫米数和光圈数只用于内部选镜，不写进提示词，API 里焦段、光圈不是可设置参数。

## 用户实测清单（调用验证时请按此对比）

1. 同一集、同一段，分别用“不上传 iso”和“纯轮廓无文字 iso”各生成一次，对比：家具位置是否移位、人物左右是否对调、线稿画风是否漏进成片。
2. 夜景人脸镜头：有补光句 vs 无补光句，对比面部曝光和暗部层次。
3. 特写/中景/全景：按内部对照选镜后，检查背景虚化、空间开阔程度是否符合预期，提示词里不得出现毫米数和光圈数。
4. 任一项出现左右对调、画风泄露、人脸异常时，停用该项并反馈，回退到 v1.43 的做法；不要把实验项当成已验证规则。
