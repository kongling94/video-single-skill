# 优化记录 v1.19：剧本内容不删减

- 日期：2026-10-17
- 起因：用户的剧本由甲方提供，公司审组会逐项对照剧本，删减内容会被打分登记。用户决定把“不删减剧本内容”写成强制规则。

## 一、新增强制规则

SKILL.md 核心原则 16：
- 原剧本或原分镜里的剧情、台词、镜头、动作、停顿、铺垫、人物和道具，一律保留。
- 不删除、不合并、不跨集挪动、不调换顺序。
- 认为多余、拖沓或可以前移时，只在诊断报告里提示并说明理由，由用户决定。
- 可以删的只限优化时自己添加的修饰和写法。

禁止行为和自检清单各加一条对应检查。

## 二、改掉的 5 处删减规则

| 文件 | 原规则 | 改为 |
|---|---|---|
| `camera-grammar.md` | 没有新信息的镜头删掉 | 自己加的镜头没有新信息就不加；原分镜的镜头保留，只在诊断中提示 |
| `camera-grammar.md`（v1.18 新增） | 次要信息挪到前后镜头 | 补充：拆分和挪动不改变原剧本顺序，不删任何一条 |
| `acting-objectives.md` | 空的停顿删掉 | 用手头动作或视线填上；原剧本写的停顿保留 |
| `acting-objectives.md` | 删掉装饰性小动作和解释性表情 | 只减自己添加的；原剧本写的保留，太多时只提示 |
| `episode-hook-rhythm.md` | 开场前移高能内容、压短或删掉铺垫；结尾剩余内容移到下一集 | 只在诊断中建议；分集和切点以剧本为准 |
| `action-focus-crowd.md` | 过载时先删修饰 | 先删自己添加的修饰；原剧本的动作和反应不删，只拆开写 |

SKILL.md 阶段 4 中钩子检查的说明同步改为“只在诊断中建议”。

## 三、对外部资料分析的影响

之后分析外部资料时，凡是要求删改、重排剧本的写法（例如 higgsfield-scene-engine 的剧本改写），最多吸收为诊断提示，不进入输出。
