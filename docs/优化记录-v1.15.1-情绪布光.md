# 优化记录 v1.15.1：情绪布光

- 日期：2026-10-17
- 来源：用户提供的“6 种情绪布光”示例（梦幻、神秘、温暖、主角感、孤独、阴森）。
- 改动文件：`references/camera-grammar.md` 第五节“光线＝写物理事实，不写形容词”。

## 对比结论

- 已有：单侧硬光（侧光 + 硬光）、局部顶光（顶光）、低位硬光（底光）、冷暖色温。镜头语法选择表原来就有这些，并且要求场景里有真实光源。
- 新增 3 条（经验）：
  - 逆光加薄雾：梦幻、美好回忆；
  - 侧后方轮廓光：主角登场、高光时刻；
  - 暖色侧前方柔光：温情、治愈。
- 新增写法要求：每种布光写成“光源 + 方向 + 软硬或色温 + 照在哪里、影子落在哪里”。官方案例写法是“阳光从左上方穿过树林，形成斑驳光影”“暖色烛光勾勒人物轮廓”。
- 新增“只换光”的适用范围：
  - 只用于出首帧图或设定图的版本挑选；
  - 或用于视频编辑任务（推断，需试片）；
  - 或剧情里光线确实变化时。
  - 同一场戏的镜头之间不随意换光源。这条与 v1.15“光线固定”一致。
- 新增提醒：强逆光、轮廓光用在情绪强烈的近景时，加“人物为正常人眼、不发光”。依据是官方“情绪过度响应”案例。

## 没有吸收的内容

- 原文“只替换光线关键词就能快速切换情绪”：在同一场戏里会破坏光线连续性，只保留上面列出的适用范围。
- 没有写光源的手法描述：改成必须写出光源。
