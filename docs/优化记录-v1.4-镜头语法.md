## 一、学到了什么

v1.3 的运镜写法库解决“运镜怎么写”，这份镜头语法表解决“为什么这样拍、该选哪种”：先判断这段戏的关系任务（对峙、逼问、揭示、权力反转、亲近、疏远、沉默、羞辱），再按“景别＝情绪距离、角度＝权力关系、构图＝心理暗示、光线写物理事实”选镜头，并给每种手法标出可执行度（直接写、改写后写、交给剪辑）。它还补上了本 skill 之前没有的切点规则、听者优先的对话戏法则，以及横屏和竖屏下不同的构图写法。

## 二、改了什么、为什么、带来什么

### 1. 新增镜头语法选择表

改动：新增 `references/camera-grammar.md`，按本 skill 的流程改编：去掉了指向原 skill 其他章节的引用，表格内容改成列表，光线部分与本 skill 的光影阴影规则衔接，关系任务与位置关系库衔接，运镜部分与运镜写法库衔接。

为什么：v1.0 的输出格式要求每镜都写景别、机位、运镜、光影，但没有说明怎样根据剧情选择，容易变成参数堆砌。

提升：每个镜头的选择都有叙事理由，减少无动机运镜、只拍说话者、整场同一景别、光线只写形容词等问题。

### 2. 引入可执行度三级

改动：每种手法标注“直接写 / 改写后写 / 交给剪辑”；交给剪辑的手法不写进提示词，需要时在镜头后附一行“剪辑建议”。

为什么：段与段之间的转场、快切、跳切、倒放、越轴等无法在单次生成里实现，写进提示词只会干扰模型。

提升：提示词只包含模型能执行的内容，剪辑工作单独列出。

### 3. 修正已有参考文件里与它不一致的地方

改动：
- 运镜写法库：开头指向镜头语法表；环绕标为“改写后写，幅度限定在半圈以内，先试片”；移焦标为“先试片，不稳定时拆成两个镜头”；规则汇总里加入“没有叙事收益时用固定镜头”和“交给剪辑”的手法清单。
- 位置关系库：新增“先看画幅”规则。9:16 竖屏下左右分居、并肩、三分法对峙、中心夹击等横向排列容易挤出画外，优先改用前后纵深；左右并排三人以上必须改纵深；不为构图制造原分镜中不存在的近距离。

为什么：v1.2 的位置模板来自 9:16 样例图，却大量使用左右排列；v1.3 的环绕示例没有提示风险。镜头语法表对这两点有更稳妥的经验。

提升：多人站位在竖屏下不再挤压变形，高风险运镜会在输出前被提示。

### 4. 接入主流程

改动：SKILL.md 按需加载清单新增镜头语法表；阶段 4 要求每个镜头先判断关系任务和情绪目标；诊断新增第 16 项“镜头语法风险”；自检清单新增 9 条镜头语法专项。
