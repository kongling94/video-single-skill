# 优化记录 v1.26：同一人物多状态资产图的写法

- 日期：2026-10-18
- 来源：用户询问官方是否有“同一人物多个状态、多张资产图”的写法；官方没有专门写法，按官方三处内容推断，用户确认写入

官方依据（推断来源）：
- 指南“素材输入建议”：素材“可能指向的是同一个或者不同的主体”，要写明每个编号的用途；
- 指南关键帧案例：时间段开头标“（参考 <3pic>）”，“角色外形与各阶段的关键帧保持一致”；
- 指南“角色对应错误”：按首次出场顺序上传，编号与角色一一对应。

改动（reference-asset-prep.md 第六节第 9 条，adapter 第三节、自检清单同步）：
1. 素材指代里每个状态单独绑定：“鹿知遥（红嫁衣）@图片1，鹿知遥（摆摊布衫）@图片2，图片1、图片2是同一个人”，加“同一画面中仅保留单个对应角色”。
2. 一段只有一种状态时，只上传这个状态的图。
3. 段内状态会变时，时间段开头标“（参考图片N）”，变化写成看得见的动作。
4. 时间段里仍只写名字，不重复 @。
