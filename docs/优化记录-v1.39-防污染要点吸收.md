## 二、Codex 复审后的修正（同一 PR）

Codex 指出 4 处问题，均已修正：
1. 新增规则落在按需读取的文件里，普通任务可能读不到：否定正向化的定义移到默认读取的适配模块第十一节，局部返修的定义移到入口，详细库只保留引用。
2. 打斗放宽没有同步反提示词库：已同步。
3. 声线控制写成了统一要求：改为只在复杂变化、续说或已知串读时拆分。
4. 打斗适用范围过宽：限定为第 7、13、14 条，物理一致性规则不再附加条件。

另外更正一处事实：v1.38 并非没有物件展示规则，`camera-grammar.md` 原本就有，这次只是提升到默认核心。
