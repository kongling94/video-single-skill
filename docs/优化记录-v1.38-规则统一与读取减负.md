# v1.38 规则统一与读取减负

基于 0dc33e3，2026-10-28。保留原剧本不删减和单集一次完整交付。

## 改动

- 确认政策只在 SKILL.md 定义：继承已确认项，镜头设计由 skill 完成；文字声线、无额外配乐、不新增片头均不再自动停问。按缺项对当前段的影响判断是否阻塞，删除“超过三项”和“至少五选项”的数量门槛。
- 缺失剧情事实仍询问；安全默认不授权猜剧情。无依赖段继续交付，阻塞段保留段号与原稿范围并标未定稿，不把占位称为整集完成。
- 原稿重复按出现次数和顺序保留，只移除模型额外重复；原稿变焦与授权组合照做，排除内容不能否定所选运镜。修复反提示词库和动作库的旧变焦禁令引用。
- 入口负责政策和交付，production-core.md 负责普通制作，适配模块负责模型参数与格式。原稿英文目标模型语言分支保留。
- 默认读取入口、制作核心及目标适配；详细库的门槛从“有人物/两人/多段”改为具体难题。同步各文件开头的读取条件，避免旧入口重新触发全库读取。
- 25 类诊断移至按需审计目录；自检由大段重复清单改为权威定义索引。默认交付完整提示词、必要资产和参数、简短衔接表及一句实际核对结果，完整五栏格式、评分和审计按用户要求恢复。
- 适配模块第三节的完整素材写法和第七至九节的特殊任务/案例迁入 seedance-special-tasks.md；旧编号保留导航，常用第三节给直接可用的精简格式。
- 眼部异常约束在适配模块第六节定义一次；情绪库不再逐条复制。具体提示词示例及每个独立生成段需要的防护仍可保留，避免为去重而破坏独立生成。

## 读取量口径

按 UTF-8 解码后的 Unicode 字符数计数，含 Markdown 标点、空白、英文；不是汉字数、字节数或 token 数，也不是实测耗时。

| 工作集 | 字符数 |
|---|---:|
| 旧入口 + 旧 Seedance 适配 + 旧自检（最低必读三文件） | 36,519 |
| 新入口 | 4,793 |
| 新制作核心 | 1,986 |
| 新适配模块 | 6,218 |
| 新普通 Seedance 文戏默认工作集 | 12,997 |

新默认工作集较旧最低必读量减少约 64.4%；旧普通文戏还会追加读取镜头、表演、轴线等库，未把这些额外读取量计入节省比例。复杂打斗、返修、特殊转场等仍会增加读取量。详细能力库并未删除，不以仓库总体大小作为读取负担指标。

## 验证

修改前只读执行推演暴露：缺音频、音乐、标题可能变成三项强制询问；任务类型再算一项会暂停整集；变焦和重复原稿要靠跨文件优先级消歧。

修改后用独立上下文检查以下执行场景，未生成视频：

| 场景 | 结果 |
|---|---|
| 三段书房文戏，原稿两次“走吧”，明确缓慢变焦，无音频/音乐/标题要求 | 保留两次及原顺序，保留变焦，无音频不阻塞，不加额外音乐或片头 |
| 仅末段偷信者身份未知、前两段无依赖 | 交付前两段，末段待确认，不声称整集完成 |
| 参数充分，整集全部且希望快 | 仍交全部段，精简附文，不以节选代替成品 |
| 安全默认但偷信者身份未知 | 制作参数可默认，剧情事实仍确认 |
| 仅修改第二段且确无下游影响 | 只交修改段，核对两侧接缝，无需重写整集 |

前向测试者曾额外通读运镜库，超过新路由要求，说明按需读取仍依赖执行者遵守；此处不把理论工作集当成实际工具调用的强制上限。独立审阅发现并修正英文目标模型语言分支和迁移后第五节的跨文件引用。

静态检查命令：

```text
python scripts/check_skill.py --base 0dc33e3
```

检查文件引用、代码块闭合、入口元数据、普通工作集预算，并对照基线确保适配参数、任务锁定、时间戳、声音、运镜及合规章节未改写，迁移章节仅修正一处跨文件引用。它不能证明生成视频质量或模型执行稳定性；场景测试验证的是规则解释，不是真实整集素材验收。
