## 二、有案例基础，但具体方法属于推断

这些可以辅助执行，不能承诺一定避免穿帮。

| 方法 | 官方支持范围 | 我们增加的部分 |
|---|---|---|
| 镜尾状态及下一段接续 | 案例包含起始/结束状态和运动轨迹 | 统一“进入—变化—离开”记录是项目方法 |
| 道具图与场景同一件物品绑定 | 素材映射、主体定义与数量约束 | 把人物映射原则扩展到茶杯、信封等 |
| 手部交接与落点 | 有递出、接过等动作案例 | 接手先握住、递出再松手的检查方式是经验 |
| 场景固定光源、反打换算 | 有保留光线、静态环境固定要求 | 逐机位换算受光方向是摄影与工作流补充 |
| 表演挂在具体触发上 | 案例由事件推动表演 | 固定触发器分类及检查表是提炼方法 |
| 参照物表达尺度 | 官方以门等物体说明人物身高 | 扩展至家具尺度与动作空间是经验性应用 |

## 三、创作经验与项目约定

没有同等官方制度不等于无用，但不应升级为模型硬限制。

| 内容 | 性质 | 使用边界 |
|---|---|---|
| 目标、阻力、选择、因果 | 编剧诊断 | 从已有剧情找，不补理论所需事件 |
| 每镜主要观看重点 | 分镜方法 | 可以同时存在对白、动作、环境与反应 |
| 克制表演细节泄露 | 表演经验 | 确实隐藏情绪时选用，不强制压抑周期 |
| 情绪弧五功能位 | 创作参考 | 不要求补齐，不强制高峰数或回落 |
| 2–3秒负载窗口 | 制作经验 | 查拥挤，不是动作数量上限 |
| 语速、字数估算 | 容量经验 | 按语气、停顿及生成结果调整 |
| 一句短否定禁配乐 | 第31集试片经验 | 官方方案之外的替代尝试，未证明普遍更好 |
| 静默预算 | 第31集试片经验 | 提示音频风险，不删除沉默或强加声响 |
| 绑定一次、正文统一人名 | 工作流经验 | 保持指代清楚，不是官方通用禁令 |
| 单张定位图加文字 | 制作折中 | 可减少出图，不保证复杂反打或换位稳定 |
| 通路、蹲起空间、支撑、占手 | 空间动作检查 | 检查可行性，不擅改锁定场景 |
| 资产版本、不对称特征、状态记录 | 项目管理 | 防版本与左右混淆，不属于模型参数 |
| 不删剧本、改编须有对应授权 | 用户项目约定 | 防止提示词优化擅自改成剧本重写 |

## 四、v1.37已经修正的冲突与过度限制

| 旧表述/做法 | 问题性质 | 已改为 |
|---|---|---|
| 情绪必须1–3秒渐变，禁止瞬间暴怒、落泪或尖叫 | 不相容于官方快速转折案例，覆盖原剧本 | 有触发可突然反应，不统一规定渐变时长 |
| 不写情绪标签 | 过度限制，官方使用情绪/语气 | 行为为主，可用简短情绪/语气辅助 |
| 大反应等整句说完 | 经验泛化 | 关键信息到达即反应，可在半句中发生 |
| 每次变化必须完整五步 | 单例扩成通用流程 | 只写实际步骤，立即行动可直接发生 |
| 至少一次回落/假平静 | 无官方要求的配额 | 是否回落由剧本决定 |
| 必须有手头动作、停顿必填动作 | 易新增道具和事件 | 允许凝视、沉默、不动及无手头道具 |
| 强者安静、弱者躁动 | 固定化人物表现 | 只作可选观察方向 |
| 一镜只能一条新信息 | 经验硬化 | 一个主要焦点，允许内容共同发生 |
| 每2–3秒限一个主要动作/明显反应 | 配额拆碎自然表演 | 改为负载检查，允许合理同步 |
| 所有动作不能同时发生 | 扩大解释官方单例 | 需先后的动作串行；对白、动作与听者反应可同步 |
| 一律排除多人同时说话 | 会反向删除抢话、齐喊 | 普通轮流对白避免错误发声；锁定交叠保留并列风险 |
| 禁配乐不准列同义词或首尾重复 | 与官方p43–44建议相反 | 同时保留官方方案与短否定经验，注明差别 |
| 静默超过固定秒数必须接动作声 | 项目经验泛化 | 保留原稿静默，不为填声新增事件 |
| 文字→宫格→关键帧→白模是统一强度阶梯 | 没有官方排名依据 | 按具体问题选择，白模解决不同需求 |
| 后级必须保留全部前级材料 | 无官方要求，可能增加冲突 | 使用最小够用且相容的组合 |
| 官方没有展开粗细白模 | 文档归属误述 | 恢复p48–49、52已有详细依据 |
| 所有输出必为整数秒 | 混淆参数与产物 | 明确编辑输出非整数、略短的例外 |
| Draft同一任务变正式片 | API流程不准确 | 基于Draft任务ID新建正式片任务 |
| 场景容不下就直接改底图 | 可能绕过锁定资产 | 先报告冲突；具体授权内才修图、挪家具或调整空间 |

相关修正已同步主skill、表演/情绪、对白、动作焦点、空间、关键帧、负向库与自检，避免只改一处留下相反检查条款。
