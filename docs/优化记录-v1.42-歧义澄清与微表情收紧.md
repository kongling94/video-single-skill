# v1.42 歧义澄清与微表情收紧（2026-11-02）

本次只澄清三处歧义并收紧微表情，不改剧本保护优先级、不改门窗与对白接话的 v1.41 规则。

## 1. 重复拆成三个固定词

- 原稿重复：剧本或原分镜里本来就出现两次以上的台词、动作，按原次数和顺序保留。
- 跨镜同句：同一句台词被拆成多个镜头连续播放时只发声一次，不在每个镜头重说，这不叫删原稿。
- 模型赘余：模型转写多写出来的重复、以及未授权新增的事件，可以删。
- 删减建议只允许动跨镜同句的重复发声和模型赘余；原稿重复不在删减排序里，必须用户逐条确认后才动。
- 改动文件：SKILL.md、script-polish-capacity.md。

## 2. 片头标题触发拆两档

- 只说“要片头标题”默认是指要留白画面，走剪辑加字，不视为覆写。
- 只有用户明确说“由视频直接生成文字”或给出具体字形、字体、位置要求时，才视为覆写，届时只调整该段排除内容里的这一条。
- 改动文件：SKILL.md 路由表、opening-ending-title.md。

## 3. 运镜组合定义为先后衔接

- 一镜一个主导运镜；允许的是先后衔接的第二运动，两个运动有明确先后和停稳点。
- 不允许同一秒内同时叠加两种运动；例外只有一镜到底和风格化奇观镜头，且仍须写清连续路径和先后。
- 改动文件：camera-movement-library.md、camera-grammar.md。

## 4. 微表情收紧

- 微表情只写在已有触发之后的一个细小变化里，近景通常取视线、呼吸和一处细小变化三选一，不堆全部情绪信号。
- 微表情不单独占一个时间段，不连续多个时间段都用微表情拖时间，不用来填补台词和动作之间的空档。
- 没有触发、没有台词、没有动作的纯表情段视为无来源时长，须缩短本段或标待确认，不得直接写入提示词。
- 改动文件：production-core.md、micro-expression-engine.md。
