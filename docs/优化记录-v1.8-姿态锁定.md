# storyboard-prompt-optimizer-l5 优化记录 v1.8：姿态与站位锁定

- 日期：2026-10-17
- 依据：用户反馈的问题（一站一坐切镜后变成都站或都坐、站着的人左右互换）；对照火山方舟《Doubao Seedance 2.5 提示词指南》的“情绪过度响应”“台词复述引发字幕”案例。

## 改了什么

`references/scene-blocking-axis.md` 新增第七节“姿态与站位锁定”：成因、3 条官方依据、8 条解决方法（标明官方写法或推断）和一个一站一坐对话示例。SKILL.md 第 17 项诊断补充姿态检查；自检清单新增 3 条。

## 为什么

近景只拍到脸和肩，画面看不出坐站，模型切镜后会重画姿态。官方案例的做法是把姿态和画面位置、朝向、所靠物体一起写进站位设定，并在镜头行里重复“站着的”；姿态变化写成动作并写结束状态。

## 带来什么

- 姿态与左右位置在每个镜头都有文字约束。
- 用机位高低（拍坐者略俯、拍站者略仰）和过肩前景让画面本身带有姿态证据。
- 姿态只能通过写明的动作改变，减少无理由的坐站突变。

## 说明

机位高低、过肩前景、近景姿态线索三条是推断，需要试片验证。
