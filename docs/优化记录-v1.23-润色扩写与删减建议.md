# 优化记录 v1.23：剧本润色扩写与删减建议（可选）

- 日期：2026-10-18
- 来源：v20 分镜模板的“流程 A 故事润色”和“时长容量评估”；用户说明甲方剧本有时本身有问题，决定作为优化项吸收

## 改动

1. 新增 `references/script-polish-capacity.md`：
   - 每段时长评估：台词、动作、转场估时，能同时发生的只算一次；结论分够用 / 勉强 / 不够。
   - 不够时给三种方案：延长本段（不超过 30 秒）、在关系转折处拆段、删减建议，等用户选择。
   - 润色扩写六条：感官和环境、可见的身体反应、台词默认逐字保留、声源、修补逻辑断裂、不新增人物事件地点结局。
   - 改动对照表：位置、原文、改后、类型、理由、代价，一处一行；用户逐条确认后才写进提示词。
2. 核心原则 16 和禁止行为加例外：默认仍不删减，只有用户明确要求润色或采纳删减建议时按新文件执行。
3. 阶段 1 需求校准加“每段时长评估”和“是否要求润色或删减”。
4. 自检清单新增“润色与时长专项”4 条。

## 和 v20 的不同

- 删减不会自动执行，必须逐条确认；未采纳的内容按原剧本保留。
- 增加改动对照表，便于向甲方和审核说明改了什么。
- 时长按 Seedance 2.5 单段 4–30 秒、整数秒估算。
