# storyboard-prompt-optimizer-l5 优化记录 v1.11：“不要文字”设为强制规则

- 日期：2026-10-17
- 依据：用户指示“保持 skill 中的不要文字！这是强制规则！”

## 改了什么

撤回 v1.9 中“排除内容改为‘除标题外不出现其他文字’”的做法。

- `references/opening-ending-title.md`：开头写明强制规则；做法改为视频只生成留好标题位置的干净画面（留白区域、整数秒时长、稳定镜头），片名、集数、“未完待续”、logo 全部写进“剪辑建议”由剪辑添加；示例同步改写。官方资料清单保留作背景，其中让模型直接生成文字的写法不采用。
- SKILL.md、`references/seedance-2-5-adapter.md`、自检清单同步改为：“不要字幕、水印文字”任何情况下不得删改。

## 为什么

用户要求排除文字是不可变的规则。标题在剪辑中添加，字形准确，也可随时修改。

## 带来什么

- 视频提示词不会再因为标题而放开文字限制。
- 片头片尾仍有专门的画面和时长，后期加标题有位置可用。

## 更正

v1.9 记录和片头文件里写过“本 skill 默认在排除内容里写‘不要字幕、文字、标志’”，这句话不准确。skill 里实际的规则只有两条：

1. `references/negative-prompt-library.md` 视频 / 电影分镜层的“不要水印文字”（v1.0 原始规则，所有优化版必须注入）。
2. 同文件“Seedance 2.5 注入方式”第 3 条和 `references/seedance-2-5-adapter.md` 第五节：字幕必须显式写“不要字幕”（v1.1 依据官方指南加入）。

强制规则的措辞已统一为“不要字幕、水印文字”，与这两条原文一致，不再出现自造的“标志”。
