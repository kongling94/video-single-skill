# 优化记录 v1.24.1：官方文档对照后的 3 处微调

- 日期：2026-10-18
- 来源：`v1.22-v1.24官方文档对照.md` 第四节，用户确认全部执行

1. 关键动作五项（action-focus-crowd.md 第一节第 7 条）：只用于少数改变局面的关键动作，其他动作按官方“概括性描述”写，不重复写相同动作。
2. 机位路径（camera-movement-library.md 第一节）：写实剧情镜头不穿墙、不穿家具；一镜到底、FPV、穿透或穿梭运镜等风格化镜头可以穿过物体，写清穿过什么、从哪进、到哪出。依据：教程案例“环绕与穿透运镜”“无缝穿梭运镜”，指南列 FPV、一镜到底。
3. 一镜一个主导运镜（同上）：一镜到底和风格化奇观镜头可写组合运镜，仍写清连续路径和先后。

自检清单对应 3 条同步修改。
