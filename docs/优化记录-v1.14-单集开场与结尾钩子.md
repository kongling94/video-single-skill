# storyboard-prompt-optimizer-l5 优化记录 v1.14：单集开场与结尾钩子

- 日期：2026-10-17
- 依据：用户提供的《极致开幕钩子生成器》skill（剧本写作类，只取与视频提示词相关的 3 部分）；对照《Doubao Seedance 2.5 提示词指南》《Seedance 2.5 教程》核对。

## 官方核对结果

| 条目 | 官方是否提及 | 落到提示词时用的官方写法 |
|---|---|---|
| 开场 1 / 3 / 5 秒节奏 | 未提及（经验） | 时间点控制“第 2 秒……”；时间段内容过多会过度剪切，所以开头只放一个事件；文戏案例排除“快速剪辑、跳帧” |
| 第二集起接住上集钩子 | 未提及（经验） | 首帧“图片 1 为首帧”；向后延长，输入 2.5 自己生成的视频衔接更好，推荐 mov |
| 冷开场 | 未提及 | 单独生成后剪辑拼接（推断）；片名按 v1.11 规则在剪辑中加 |
| 结尾钩子 | 未提及（经验） | “结束时……”状态；“画面定格 1 秒” |
| 声音先入 / 后留 | 无 J-cut / L-cut 术语 | 声音标记 () <> {}、“画外音：”；跨段用延长“画面 / 音频无缝衔接”或剪辑 |

不吸收：剧本格式（【音效】、OS 标签）、去 AI 味台词改写、依赖画面文字的开场示例（违反“不要字幕、水印文字”）、推入瞳孔（诱发眼睛发光）、画幅突变、自评分数。

## 改了什么

新增 `references/episode-hook-rhythm.md`；SKILL.md 新增第 21 项诊断“单集节奏风险”和阶段 4 读取说明；自检清单新增 5 条；片头片尾文件和适配模块加指引。

## 为什么

用户的视频没有片头，开场抓人和每集结尾留悬念需要在分镜阶段处理。用户关心单集时长，因此规则限定为只调顺序和切点：不做前情回顾，需要新增内容时列为待确认项。

## 说明

开场节奏、结尾钩子类型、冷开场单独生成的做法都是经验或推断，需要试片验证。
