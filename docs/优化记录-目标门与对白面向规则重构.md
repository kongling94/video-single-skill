# 目标门与对白面向规则重构

本轮按用户反馈调整通用规则，不编辑或上传场景图片、人物图及剧本资产。

- 目标门：正向动作与贯穿要求移除用于排除的非目标门描述，只保留已证目标特征。不凭建议臆定双扇或画面位置；保护原剧情的多门动作。
- 对白：绑定本镜画面左右、头身朝向、面部可见角度与视线；过肩前景、画外说话、高低差和原稿背身对白保留各自语法。
- 参考图：确认拓扑矛盾时拦截同时使用；先选一致图，必要时在本地副本裁切并重新验看，不自动裁掉剧情必需空间。
- 7份剧集原稿及临时验证记录移出版本控制并忽略，本地原文保留。忽略规则不清理历史提交；此前记录仍可能在Git历史中存在。本轮未重写历史。
- 新通用短测模板位于 scene-blocking-axis.md 第十一节，无剧集专名和臆定门型。原始样本未手改冒充模型复测。

验证边界：只运行仓库文档校验和差异检查；本轮图片生成0次、视频生成0次，不宣称修复了成片或已达到任何成功率。Cross-Attention解释未作为已证机制采纳。
