# 画外来源与未知边界纯文本回归记录

日期：2026-11-04。用途：验证 Skill 能否阻止人物从场景图未知区域凭空生成门窗、穿墙出入，或没有来源地从画外突然出现。本文仅保存纯文本提示词，不保存场景图片、人物图或视频。

## 失败机制与验证口径

画面边缘只是摄影机构图边界，不是房间边界。人物“进入画面”与“进入房间”是两种不同事件：

- 已在同一房间但位于画外：位置仍属于室内某个已确认地标，只需沿室内地面走入画框，不开门、不跨门槛。
- 位于另一空间：必须从已确认来源空间，经已确认门洞或通道跨越边界，并在目标空间的明确落点停下。
- 来源和通路都未建立：受影响镜头暂停，不允许从未知墙面、镜头边缘、家具后方或临时生成的门窗出现。

以下回归场景的固定拓扑只有：客厅、室外走廊、连接两者的深色入户门；客厅侧墙和窗只作为固定墙面及采光结构，不是通路。画面裁切到门外时，入户门仍存在于世界状态，但不能把裁切边当成另一入口。

## 回归一：从另一空间进入房间

```text
生成段A，总时长8秒，参考生视频。
素材指代：来访者@图片1；客厅与已确认入户门@图片2。图片2只参考客厅固定墙面、窗、家具，以及连接室外走廊与客厅的同一扇深色入户门；画面其他边缘和未见墙面不新增开口。
概述：来访者从室外走廊，经图中已确认的深色入户门进入客厅，在门内落点停下。
场景空间锁：客厅与室外走廊只通过图中深色入户门连接；窗是关闭的固定采光结构，侧墙连续完整。镜头画框边缘不是门洞。
进入状态：来访者在室外走廊、尚未进入客厅；深色入户门关闭；客厅内无人。
0-2秒：机位在客厅内朝向已确认的深色入户门，固定中全景。门保持图中位置，来访者在门外，不从画面侧边或墙后出现。
2-5秒：同一机位，来访者从室外一侧操作同一深色入户门，门扇打开；来访者跨过同一门槛进入客厅。
5-8秒：来访者在门内侧已确认落点停下，身体完整进入画面；身后的同一入户门保持打开。客厅墙面、窗和家具结构不变。
贯穿要求：人物来源始终是室外走廊，进入路径始终经过同一扇已确认入户门；摄影机不绕到未知区域，不把构图边缘变成建筑开口。
排除内容：不要字幕、水印文字；不要新增门窗、穿墙、从家具后凭空出现或人物复制。
```

文本验收：

- 人物来源空间、跨越边、门槛和室内落点完整。
- 机位明确拍到已确认入口，没有依靠画外区域补门。
- 窗和未知墙面没有被用作通路。

## 回归二：已在房间，只从画外进入画面

```text
生成段B，总时长6秒，参考生视频。
素材指代：住户@图片1；客厅@图片2。图片2只参考客厅固定结构、沙发、茶几、连续侧墙和关闭的窗；本段不发生跨房间出入。
概述：住户原本就在同一客厅的沙发外侧，只是处于当前画框左侧之外；他沿客厅地面走入画面，到茶几旁停下。
场景空间锁：住户的起点、路线和终点都在同一客厅内。当前画框左边缘只是构图裁切，不是门洞；侧墙和窗保持原结构。
进入状态：住户已在客厅内，位于沙发外侧、当前画面左边缘之外；不是在室外，也不是尚未到场。
0-2秒：固定客厅中景，画面先看到沙发和茶几。住户仍在同一客厅的画外左侧，脚步声从该室内位置接近；墙面、窗和家具不变化。
2-5秒：住户从画面左边缘步行进入画面，脚始终沿同一客厅可见地面移动；他没有开门、跨窗或穿墙。
5-6秒：住户在茶几旁停下，面向室内既定互动对象。其来源仍是同一客厅的沙发外侧。
贯穿要求：这是同空间进入画框，不是从室外进入房间；镜头边缘只控制可见性，不改变建筑结构或人物所在空间。
排除内容：不要字幕、水印文字；不要在画面边缘生成门框、窗洞、走廊或第二个房间，不要人物瞬现。
```

文本验收：

- 人物在开头已经属于客厅，只有可见性从画外变为画内。
- 提示词没有开门、跨门槛或空间切换动作。
- 画面边缘没有被描述为入口。

## 回归三：走出画面但仍留在房间

```text
生成段C，总时长5秒，参考生视频。
素材指代：住户@图片1；客厅@图片2。
概述：住户从茶几旁沿客厅地面走向沙发外侧，最终离开当前画框，但仍留在客厅内。
进入状态：住户在客厅茶几旁、画内可见。
0-4秒：固定客厅中景，住户沿客厅内既有地面走向画面左边缘的沙发外侧；全程不接触门窗。
4-5秒：住户从画面左边缘走出当前构图，位置更新为同一客厅沙发外侧、画外在场；没有离开房间。
贯穿要求：走出画面只改变可见性，不改变人物所在空间；墙面、窗、门和家具保持原结构。
排除内容：不要字幕、水印文字；不要把画面边缘生成出口，不要人物消失、穿墙或出现在室外。
```

## 文本回归结论

三个提示词分别覆盖“跨空间进入”“同空间入画”“同空间出画”。每次人物出现或消失都有来源空间、最后地标、路径和结束状态；只有回归一使用已确认入户门，回归二、三没有门窗动作。由此可在文本层拦截未知边界造门、造窗和无来源人物。

未验证项：没有实际场景图和失败视频，本轮未调用 Seedance，不能证明模型不会自行幻觉建筑开口；真实任务仍需用当次参考图核对拓扑。
