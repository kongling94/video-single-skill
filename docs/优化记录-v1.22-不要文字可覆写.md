# 优化记录 v1.22：“不要文字”改为默认规则，用户可覆写

- 日期：2026-10-18
- 来源：用户参考 v20 分镜模板的覆写条款后决定

## 改动

1. “不要字幕、水印文字”从强制规则改为默认规则：每段排除内容默认照写。用户在当前对话中明确要求某段由视频直接生成文字（片名、字幕、logo 等）时，只调整该段排除内容里的这一条，其余排除条目原文保留，其他段不受影响，并在诊断中注明“按用户要求覆写”。没有明确要求时仍按原做法：视频留白，标题在剪辑中添加。
2. 覆写时的标题写法（官方依据）：写明文字位置、字体和内容；需要准确展示的文字做成图片作参考素材；英文按字母顺序依次出现。
3. 参考图上的文字改为在出场景图、道具图时管控（画成图案或不画可读文字），视频提示词不再写“图片 N 中的文字只保留色块和形状，显示为不可辨认的图案”。设定图的标题栏、图注上传前裁掉的做法不变。
