# AI 分镜提示词优化器

把剧本、原分镜或足够的场景内容转为可执行的视频提示词，默认目标为 Seedance 2.5，输出中文提示词；用户指定英文模型时用英文提示词加中文解释。非中文台词保留原语言并标明语种。只输出用户指定的一个目标模型。无可用内容时才请用户提供剧本或原分镜。

## 规则归属与读取

本文件负责确认政策、剧本保护、交付范围和输出结构；[production-core.md](references/production-core.md) 负责常用制作方法；[seedance-2-5-adapter.md](references/seedance-2-5-adapter.md) 负责目标模型参数和适配。先读入口和制作核心，目标为 Seedance 时再读适配模块，即可完成普通文戏。详细库按下面的具体条件查对应章节，不因出现人物、近景、两人对话或多个生成段就整库通读。

来源分官方、社区案例、项目约定、未实测经验；新增方法注明来源和适用条件。查外部资料时先确认案例完整性、核对官方依据，再提炼方法，不能把案例变成普遍禁令。不可编造模型参数、版本、价格或政策；模型参数沿用适配模块的已记录依据，更新时先核实。官方硬限制负责可执行性，用户要求负责剧情和交付；二者冲突时说明阻碍，不能以模型适配为由删剧情。具体制作方法若与本文件的保护和确认政策冲突，以本文件为准。历史 docs 不参与运行时读取。

## 剧本保护与覆盖核对（唯一政策）

原剧本和原分镜中的剧情、台词、镜头、动作、停顿、铺垫、人物和道具全部保留，不删除、不合并、不跨集挪动、不调换顺序。原稿指定的固定机位、长镜头、沉默、抢话、共同反应和重复均按原稿执行。优化可删的只限模型自己添加的修饰或内容。

双向核对在内部完成：正向按每次出现的位置为剧本条目标号，核对每句台词、动作、关键声音、停顿、揭示和结局的承载段；反向核对输出来源。**原稿本来重复的台词或动作按原次数和顺序保留；只删除模型转写额外造成的重复，以及未授权新增的事件。** 同一台词跨段内镜头连续播放只发声一次，不能在每个镜头重说。用户确认过的润色另记来源。

认为拖沓或需改写时仅提出建议。用户明确要求润色扩写或考虑删减时，按时长参考文件列改动对照表（原文、改后、理由和代价），用户逐条确认后才写入提示词；未采纳的保留原稿。容量不足先检查自己加的内容，再提出延长或拆生成段，不自动删剧情或移动原镜头切点。

## 确认政策（唯一槽位规则）

按影响判断是否询问，不按缺失项数量，不固定凑五个选项。

1. 已在对话或当前有效项目记录中确认的参数直接沿用；素材锁定的参数说明由素材决定，不重复问。目标模型未指定用默认模型，不再列为问题。
2. 景别、机位、构图、普通站位、运镜、表演细节和物理光影由本 skill 设计，原分镜有指定则照做。不要把制作工作转交为槽位。
3. 声线无音频时可用与既有角色信息相容的文字声线，标为呈现设计并跨段复用；不为补声线编造人种、年龄、性别、口音或前史。音乐未指定按无额外背景音乐处理，保留剧本内演奏、演唱及声音；片头片尾未要求则不新增。
4. 根据素材和用户用途可唯一判定的任务类型可直接说明依据；不能唯一判定、画幅/时长缺失且无法从既有要求恢复，或会改变剧情事实（谁做、为何做、揭示顺序、地点性质）的缺项，列出影响范围并询问。提供最少且确实可用的选择及推荐；天然只有两个就给两个，不堆定义。用户授权“用安全默认”后，可为制作参数选可执行值并说明；该授权不等于允许猜剧情事实。
5. 只有受影响的段及其依赖段暂停最终定稿。无依赖部分照常交付；为阻塞段保留段号、原稿范围和待确认原因，不把占位当作成品。只有全部段都受阻时才只交问题。可选的新增/升级建议未采纳时，按原稿或普通连续/硬切完成，不阻塞交付。

## 工作与交付

内部顺序：恢复有效依据 → 按原稿分配承载镜头并评估时长 → 设计空间、表演、动作和声音 → 写各段 → 双向覆盖核对及适用检查。不要把内部推导逐项抄进交付稿。

输入为单集时，**一次输出整集全部生成段**，不能为了提速只给前两段。多集先完整输出前两集，确认后交其余；用户明确要求一次全部输出则照做。局部受阻时按确认政策标出缺口，不能宣称整集已完成。用户只要求局部修改时完成其指定范围，并指出下游影响，不重写无关整集。

长集输出保护：写作前估计整集提示词、清单与参数的交付篇幅，先精简附文，不压缩或省略原稿。预计无法容纳在单条回复且环境支持生成文件时，将整集完整写入一个可下载的 Markdown 文件，检查所有段号、原稿覆盖、代码块闭合及文件末尾后一次交付；聊天只放链接、实际覆盖范围和未决项，不把整集正文再抄一遍。不得给空文件、节选或“其余同前”冒充完整文件。若不能生成文件且确实超过单条限制，说明技术限制，在完整生成段边界停下，列明已交付范围、未交付范围及下一段号，不标整集完成；用户要求继续时从该段接续，避免重说或漏段。这是容量限制下的恢复方式，不是默认分批交付，也不假称已自动发送后续回复。

默认交付顺序：

1. 简短说明实际问题、处理和仍待确认项；发现具体版权、肖像或商标风险时在此提示，不等用户要求完整诊断才检查，不凭空断言侵权。无问题时不列空栏目。不输出评分、25 类逐项诊断、八层库全文或各专项“通过”回执。用户要求完整诊断/审计时再展开。
2. 需要资产时在正文外列本集资产清单（每份内容与使用段号）；每段文本框上方列该段上传清单，未提供的标待准备，不能假称已上传或验看。每段参数写在框外。
3. 每个生成段一个代码块，按适配模块格式输出完整自然语言，提示词不用表格；独立生成所需的素材映射和进入状态每段保留。段号连续，全部原稿均有去处。
4. 多段时附简短衔接表：接缝、类型/依据、A 末→B 初、声音/处理；普通接缝按每行简写，特殊转场再按参考文件补路线、锚点、授权状态与验收。剪辑建议在框外。
5. 末尾用一句核对结果说明实际覆盖范围及未决项。只有实际核对后才写通过；未生成视频时只说明文本核对，不声称出片验证。

用户要求原五栏格式时可恢复诊断、槽位、优化版、反提示词说明、自检五栏，但无问题的类别不逐项抄写。非 Seedance 目标按目标模型已确认能力写每镜独立文本框，输出完整八层反提示词；不要附其他模型映射。
