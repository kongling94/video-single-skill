# 八层反提示词库

所有优化版必须完整注入以下八层反提示词。

## 通用缺陷防护

不要过度解释；不要编造参数；不要自行填充关键身份参数；不要遗漏反提示词；不要用模糊词代替可执行细节；不要混用中英文；不要忽略版权与肖像权；不要输出无法被 AI 执行的抽象描述；不要遗漏主体数量；不要忽略分辨率比例；不要忽略目标 AI 母语优先。

## 视频 / 电影分镜专属缺陷防护

不要镜头语言缺失；不要运镜冲突；不要时长与动作不匹配；不要转场突兀；不要光线方向矛盾；不要主体数量漂移；不要人物畸形；不要多手多指；不要五官融化；不要水印文字；不要低清塑料感；不要背景杂乱；不要音画不同步；不要物理运动违反常识；不要景别混乱；不要越轴。

## 流畅优先专属缺陷防护

不要单镜头多主运镜；不要镜头内变焦；不要镜头内变光圈；不要单镜头多景别跳切；不要节拍过密；不要使用跳跃词；不要缺失光线方向锚点；不要缺失服装锚点；不要缺失天气锚点；不要缺失主体位置锚点；不要相邻镜头光线方向矛盾。

## 物理自洽专属缺陷防护

不要只有动作没有物理反馈；不要衣摆发丝反向飘动；不要人物瞬间起步停止；不要碰撞没有反作用力；不要水花灰尘方向错误；不要雨雪方向与风矛盾；不要马匹没有重量感；不要水波不扩散；不要蒸汽不升腾；不要剑身反光固定不变；不要物理反馈与镜头时长不匹配；不要重心不转移；不要惯性缺失；不要粒子悬浮。

## 光影阴影专属缺陷防护

不要主光源方向缺失；不要阴影方向与光源同向；不要太阳在角色前方而影子也在前方；不要光源在左上方而阴影也在左上方；不要低角度光配短阴影；不要高角度光配长阴影；不要柔光配锐利阴影；不要硬光配模糊阴影；不要主体与地面接触处没有接触阴影；不要逆光没有轮廓光；不要顺光没有后方阴影；不要主体移动阴影静止；不要主体动作变化阴影僵硬；不要多光源阴影方向混乱；不要阴影穿过不透明物体；不要阴影穿墙穿树穿人；不要水面倒影静止；不要日光阴影纯黑；不要月光阴影暖黄；不要烛光阴影冷蓝；不要阴影色温与光源矛盾；不要主体漂浮无影；不要阴影长度与时间矛盾；不要火星不熄灭；不要倒影不随水波晃动；不要倒影方向与主体同向。

## 微表情专属缺陷防护

不要情绪缺失；不要表情面瘫；不要情绪突变；不要情绪与动作矛盾；不要眼神无焦点；不要眼神游离；不要呼吸不匹配；不要悲伤无泪；不要恐惧无汗；不要愤怒声音温柔；不要受伤无反应；不要打斗全程面瘫；不要单一表情持续全镜头；不要情绪过渡生硬；不要瞬间变脸；不要眼神方向混乱；不要呼吸节奏与情绪矛盾；不要泪液汗液面色与情绪矛盾。

## 打斗质感专属缺陷防护

不要攻防无逻辑；不要击中无反馈；不要穿透感；不要打击反馈反向；不要只有手臂发力；不要打斗中呼吸平稳；不要脚步不动；不要衣摆静止；不要兵器像纸片；不要格挡无后坐力；不要闪避像平移；不要倒地无尘；不要打斗节奏匀速；不要全程连续无停顿；不要全程无眼神；不要突然结束无收招；不要兵器碰撞无火星；不要火星不熄灭；不要格挡无火花；不要刺中无停顿；不要击退无踉跄；不要倒地头部不后仰。

## 用户自定义防护

1. 不要改变用户指定的品牌符号。
2. 不要删除用户指定的关键台词。
3. 不要替换用户指定的演员形象。
4. 不要忽略用户指定的平台比例。
5. 不要添加用户未要求的血腥、恐怖、政治敏感元素。
6. 不要输出未确认的版权音乐。

## Seedance 2.5 注入方式

依据官方提示词指南：Seedance 2.5 要求情节“尽量使用正向描述”，官方明确支持的负向控制是字幕和音频。因此投喂 Seedance 2.5 时，八层反提示词按以下方式进入生成段文本框，不整段粘贴：

1. 先转正向：把与该段相关的缺陷防护改写成正向要求写进情节，例如“不要阴影方向与光源同向”写成“阳光从左上方照来，影子落在人物右后方”，“不要闪避像平移”写成“闪避时身体先下沉再侧移”。
2. 再压缩：只把该段确实存在风险的条目合并成一句“排除内容：……”，放在文本框末尾，参照官方案例的“排除内容”段落写法。官方案例里段落标签用过 【】，但教程规定 【】 表示字幕，为避免混淆，本 skill 统一改用冒号标签。
3. 字幕和音频必须显式写：例如“不要字幕”“无 bgm，只生成环境音和动作音”。禁止背景音乐时，一次性穷举音乐、背景音乐、BGM、配乐、器乐、旋律、合成器音效、氛围铺底音，并在提示词开头和结尾各写一遍。
4. 有人物情绪特写时，加一句“人物为正常人眼、不发光”。
5. 画内演奏或演唱的例外：剧情里有人在画面中弹琴、唱歌、敲鼓时，这段音乐是画面内容，不属于背景音乐。依据是教程的乐队案例：画内演唱，写“精准对口型”、乐手动作随节拍。
   - 写法：“只保留画内××演奏的琴声，无其他背景音乐、配乐、BGM”；不把“器乐、旋律”写进排除。
   - 写清谁在演奏、演奏的动作和声音同步。
   - 歌词照常保持“不要字幕”（官方乐队案例同样写了“无字幕、无文字叠加”）。
   - 演奏开始前和结束后的时间段，仍按第 3 条排除背景音乐。
6. 移焦不算“镜头内变焦”：流畅优先层的“不要镜头内变焦”指改变焦距和画面大小。移焦（焦点从一处平滑转到另一处，人物大小不变）是官方示例写法，按 `references/action-focus-crowd.md` 第二节写，每个时间段最多一次。
7. 最终提示词里不留修改过程的负面句，例如“不要再背跟”“删除换装”“不要像上一版那样”。改动直接写成正向结果，例如“她始终穿白色衬衫”；排除内容只保留本段确实存在风险的条目。
