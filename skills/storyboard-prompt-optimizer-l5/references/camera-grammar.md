# 镜头语法选择表

用途：决定每个镜头“为什么这样拍”，即景别、角度、构图、光线、焦距景深、运镜怎样服务情绪和人物关系。`references/camera-movement-library.md` 管“运镜怎么写”，本文件管“选哪种”。普通选镜使用 production-core.md；选镜目的不清、复杂构图或光型按入口路由查对应章节。

来源：用户自己的 AIGC-Drama-Skills 仓库中 `script-to-drama-prompt-sd25/references/camera-grammar.md`（整理自《镜头语法：全维度情绪表达手册》，已按 Seedance 2.5 官方指南更新部分标注）。本文件按本 skill 的流程改编：去掉了指向原 skill 其他章节的引用，补上与本 skill 微表情、光影、位置关系、运镜模块的衔接。原文中的可执行度标注保留：凡未经 2.5 试片的仍是 2.0 时期的经验，使用时注意。

## 使用原则

- 这是选择依据，不是配额。镜头数量、景别、角度都由剧情决定，不要求每段出现几种。
- 每个镜头先确定要让观众感到或看清什么，再选相互兼容的手法组合（如“微仰＋缓慢推近”）；彼此矛盾或分散观看重点时，只删自己添加的手法；原分镜指定的手法冲突时在诊断中提示。
- 道具、光源、陈设的举例只是示意，以原分镜、资产和场景设定为准，不为镜头效果凭空添加（古装戏不出现手机）。
- 全片色调由风格设定锁定，场景光源由场景设定锁定，本表只决定单个镜头的选择。
- 可执行度分三级：
  - 直接写：可以写进镜头。
  - 改写后写：换成模型能执行的说法再写。
  - 交给剪辑：不写进提示词，在剪辑软件拼接时处理；需要时在该镜头后附一行“剪辑建议”。

## 一、先判断关系任务，再选镜头

关系任务只在内部使用，不写进提示词。具体站位写法见 `references/position-relationship-library.md`。

- 建立关系、交代站位：全景或中景、平视、固定机位，看清谁站在哪里。横屏可双方同框，竖屏用纵深排列。
- 对峙：单人正反打，景别逐步收紧；强势方微仰，弱势方微俯。
- 逼问、施压：施压者微仰、缓慢推近；被逼问者近景，优先给听者反应。
- 揭示、反转：揭示的台词或画外声先出现，再切听者反应；揭示后景别收紧，或推近到关键道具。
- 权力反转：先确定观众必须看到的关系变化，再选最少的镜头变化。可用站位变化、道具归属变化、听者反应，或角度反转（原本被俯拍的一方转为平视或微仰）。角度反转往往要换机位方向，会带来背景和光向变化，按需使用。
- 结盟、亲近：横屏双人同框中景或过肩；竖屏只在两人实际靠近时用过肩或前后纵深，相隔较远时不硬凑同框。
- 疏远、孤立：单人镜头正反打，画面里没有对方；负空间构图。
- 沉默、克制：优先保持原镜头或切到人物反应；可插入人物手中或身边的道具；空镜只用来承接画外仍在持续的动作、台词、声音或后果，或承担时空转换，不用空镜填时长；保留停顿。
- 羞辱、围观：被羞辱者微俯，周围人群作前景遮挡；围观者的反应作反应镜头。

## 二、景别＝情绪距离

景别收紧＝情绪收紧，景别放开＝情绪抽离。对话从平和到激烈时，景别从中景逐步收到近景、特写。以下景别都可直接写。

- 大远景 / 远景：渺小、孤独、疏离、客观交代；用于开场建立空间、人物进入场景、收尾余韵。
- 全景：关系交代，站位就是权力；多人互动的基准镜头。
- 中景：中性、日常对话的主力景别。
- 中近景：情绪开始浮现，对话升温的过渡。
- 近景：紧张升温，冲突升级、关键台词。
- 特写：强调、情绪顶点、关键道具、核心台词落点。
- 大特写：极端强调、窒息感；按剧情需要用，脸部变形是经验风险，需试片核对。
- 过肩：关系平衡、介入感；写清越过谁的肩膀、看向谁。
- 主观视角：代入、共情、悬疑；改写后写成“从某人的视线方向看向……”。
- 插入镜头：信息强调、线索揭示，用于关键道具。

各景别单镜参考时长（经验，按整数秒取，配合 `references/action-focus-crowd.md` 第四节负载检查）：大远景、远景 3–5 秒；全景 2–4 秒；中景 2–3 秒；近景 2–3 秒；特写 1–2 秒；大特写、插入镜头 1 秒左右。情绪段落可适当延长，快节奏段落取下限。以上是无台词镜头的参考；有台词的镜头按台词时长定（字数 ÷ 语速，再留约 1 秒反应，语速见 `references/seedance-2-5-adapter.md` 第五节），不为凑这里的秒数截断台词；同一生成段内可切镜不断声，保持字序和音轨连续（v1.30）。

### 景别组合

景别组合的使用规则（来源：用户提供的《AI 分镜：15 套景别组合》）：

1. 每镜确定明确的观看作用，可以提供新信息、承载反应，也可以维持有依据的等待、倾听或状态。同一张图无目的地连续放大容易产生跳动感，但不以信息数量判定镜头是否成立。自己添加的镜头需说明用途；原分镜里的镜头保留，确有问题只在诊断中提示（剧本内容不删减，见 SKILL.md 核心原则 16）。（经验；指南：时间段内剧情过少，模型会自由发挥）
   - 每镜确定一个主要观看重点，允许动作、对白、环境和反应共同出现；只有重点竞争或内容超载时才建议拆镜，按原剧本先后排列，不把“一镜一条信息”当硬配额，不擅改原分镜。（经验；指南：时间段内剧情过多，会导致过度剪切或剧情遗漏）
   - 关键信息可以借次要载体揭示：不直接拍出答案，而是拍它在人物身上留下的变化，例如脸上的光突然变亮、对方的手停住、杯子被放下。载体必须是画面里已有的人或物，不凭空增加。（经验）
2. 景别顺序不是禁令。同一生成段内按“镜头 N”分开写时，远景可以直接接特写（官方乐队案例：“每次切换双重反差（景别与镜头类型同时改变）”）。能不能接，看新信息、动作、视线和切换时机。
3. 从特写切到远景揭示环境时，要有锚点：特写里的杯子、桌面、光线，在远景里要能对上，观众才知道是同一个地方。（经验）
4. 一套 2–6 镜的组合可以放进一个生成段，按官方“镜头 1｜0 秒 - 2 秒”的思路排列；本 skill 输出统一写成“0-2秒：”格式。

按情景选组合（参考，不是公式）：

| 情景 | 组合 | 连接关键 |
|---|---|---|
| 干脆利落、突出一个动作 | 中景 → 特写 | 从伸手切到抓住，动作接着做，不重新伸手 |
| 看到消息或东西后的反应 | 特写 → 近景 | 先让观众看到她看到了什么，再看反应 |
| 揭示环境 | 特写 → 远景，或特写 → 中景 → 远景 | 特写里的物体在远景里能对上 |
| 寻找、发现 | 远景 → 中景 → 特写 | 环境 → 寻找动作 → 被发现的东西，视线指向它 |
| 对话、关系 | 全景 → 近景A → 近景B（→ 特写 → 全景） | 先交代位置，再分别看说话和回应，最后用行动回应 |
| 操作、产品 | 全景 → 中景 → 特写 → 全景 | 在哪儿做 → 怎么做 → 关键细节 → 结果 |
| 认识一个人 | 远景 → 全景 → 中景 → 近景 → 特写 | 每靠近一层，多一种值得看的信息 |
| 准备、行动、释放 | 全景 → 特写 → 中景 → 全景 → 近景 | 动作只做一次，下一镜接后续阶段，情绪在结果之后出现 |

剧情靠手机消息、信件、招牌这类文字推进时，按默认规则“不要文字”处理（用户明确要求画面显示文字时可覆写）：
- 画面只写“手机屏幕亮起一条新消息，看不清内容”；
- 消息文字写在“剪辑建议”里，由剪辑添加。

## 三、角度＝权力关系

谁占上风，谁被仰拍。角度不是唯一手法，站位、道具归属、听者反应同样能表达，按剧情选最少的变化。

- 平视：平等、客观，对话默认角度。直接写。
- 微仰：优势地位、主角正面塑造。直接写。
- 仰拍：强势、压迫、权威。直接写。
- 极端仰拍：压倒性压迫、渺小感。直接写，人物近景慎用，容易畸变。
- 微俯：轻微弱势、审视。直接写。
- 俯拍：弱势、无力、被审视。直接写。
- 极端俯拍（鸟瞰）：全知、冷漠、宿命。直接写，只适合群像或空间交代。
- 荷兰角：不安、失衡。改写后写成“画面微微倾斜”，先试片（2.5 官方示例用过，2.0 时常被执行成晃动）。
- 正反打角度对称：势均力敌，双方用同样的景别和角度。
- 正反打角度错位：权力不对等，强势方微仰近景，弱势方微俯中景。

## 四、构图＝心理暗示

- 三分法、黄金分割：稳定、自然。写成“人物位于画面左侧三分之一处”。
- 对称构图：秩序、压迫、仪式感。直接写。
- 框中框：被困、窥视、隔离。直接写，框必须是场景里真实存在的门窗。
- 负空间：孤独、空虚。写成“人物只占画面一侧，另一侧大片空白墙面”。
- 前景遮挡：窥视、临场感。写清前景是什么（人群肩背、花艺、门框）。
- 对角线：张力、不安定。改写成人物和道具的斜向排列。
- 正三角 / 倒三角：稳定权威 / 失衡危险。改写成三人的前后左右位置。
- 群像金字塔 / 散点：等级森严 / 混乱无序。改写成高低、前后排列。
- 镜面反射：双重身份、自我审视。高风险，画面复杂时单独成镜或补参考图，同镜呈现先试片。

## 五、光线＝写物理事实，不写形容词

“氛围压抑”模型无法执行，“只有一盏顶灯垂直照下，她半张脸没入阴影”才可以。光线选择必须和场景中的光源位置一致，只能调整机位看光的方向，不能凭空新增光源。与本 skill 的光影阴影规则一起使用：写清光源方向、阴影方向和接触阴影。

- 顺光：平淡、纪实。机位与主光同侧。
  - 蝴蝶光：柔美、精致、复古。柔和的光从人物正前上方照来，鼻子下方留下一小块对称的阴影。写清光源，例如“正前上方的柔光灯”。（经验）
- 侧光：冲突、矛盾。机位与主光成直角，人物明暗各半。
  - 伦勃朗光：深沉、厚重、神秘。光从人物侧前上方照来，暗的那半边脸颊留下一小块三角形亮斑。写成“窗光从她左前上方照来，右脸颊留下一小块三角形亮斑”，不只写术语。（经验）
- 逆光 / 轮廓光：悲伤、离别、疏离。机位对着主光，人物边缘被勾亮。
  - 逆光加薄雾：梦幻、美好回忆、浪漫。写光源和介质，例如“傍晚的阳光从她身后穿过薄雾，发丝边缘泛着金色轮廓光，整体朦胧柔和”。（经验）
  - 侧后方轮廓光：主角登场、高光时刻。光从人物侧后方照来，勾出肩膀和头部的边缘，让人物从较暗的背景里分离出来。要写清光源，例如“身后左侧的路灯勾亮他的肩膀和头发边缘”。（经验；官方案例写法：“暖色烛光勾勒人物轮廓”）
- 顶光：压迫、审讯。场景有顶部光源时才用。
- 硬光 / 柔光：锋利冲突 / 温柔伤感。写光源性质，如“窗外直射的阳光”“纱帘透进的柔光”。
- 暖色侧前方柔光：温情、日常、治愈。写成“傍晚窗边的暖黄阳光从她右前方照来，阴影柔和”或“厨房的暖灯从侧前方照亮两人”。（经验）
- 冷暖对比：两个世界、关系对立。两个实际光源分别照在两人身上。
- 实际光源：真实、生活化。台灯、烛光、屏幕光，写清位置。
- 底光：恐怖、诡异、反常。场景里确有低处光源时才用，例如“烛火从下方照亮她的下巴和鼻翼，眼窝陷在阴影里”。
- 运动光：危机逼近、时间流逝、不安。写清光源和阴影怎么动，如“摇曳的烛火让墙上的影子来回晃动”。

每种布光都写成“光源 + 方向 + 软硬或色温 + 照在哪里、影子落在哪里”，不只写手法名。官方案例都带光源，例如“阳光从左上方穿过树林，形成斑驳光影”（指南）。只写“光从下巴方向往上打”而不写光源，模型可能凭空加一个光源。

强逆光、轮廓光的情绪近景，按 seedance-2-5-adapter.md 第六节处理眼部异常风险；限制环境光仅作用于面部轮廓。

### “人物和构图不变、只换光”的适用范围

同一画面换一种布光可以完全改变情绪，但在视频里只能这样用：

1. 出首帧图、设定图时，做几个布光版本挑选；选定后整场戏按这个光源固定。（经验）
2. 对已生成的视频用编辑任务改光线：写“保留视频 1 的人物、构图、机位、动作和表演，只把光线改为……”。依据：官方编辑案例写过“保留 @视频 1 的构图、机位、光线与表演节奏，只改写……”，反过来只改光线是推断，需要试片。
3. 剧情里光线确实变了：开灯、关灯、太阳落山、闪电。写成画面里的事件，见 `references/scene-prop-continuity.md` 第四节。

同一场戏的镜头之间，不为了换情绪随意换光源位置或方向。

## 六、焦距与景深（改写后写）

不写毫米数，写画面效果：

- 广角：写成“广角，空间显得开阔”；在狭小空间里强化压抑。
- 长焦：写成“长焦压缩背景，远处的人物显得很近”；用于窥视、远距离观察。
- 浅景深：写成“背景虚化，只有她清晰”；用于单人情绪戏。
- 深景深：写成“前景到背景都清晰”；用于群像和藏线索。
- 背景光斑：写成“背景的灯火虚化成暖色光斑”；用于夜景、回忆、抒情。
- 移焦：按官方写法写成“名词＋可观察的变化”，先试片（2.0 时执行不稳定，常改成两个镜头）。

## 七、运镜＝情绪运动

没有叙事收益时用固定机位。一个镜头先明确主导路径，兼容的移动或移焦可以组合，写清起点、过程与终点。具体写法见 `references/camera-movement-library.md`。

“固定”管的是单个镜头不运动，不是整段只用一个机位，也不是每个镜头都必须固定。一段里所有镜头都写成固定时，回头检查：揭示、施压、关键台词这些情绪落点，是否需要一次缓慢推近；对话是否已经切到说话人和倾听者。揭示句后的景别与是否停住按剧情决定；已有动作声或环境声可自然延续，不为静默预算强加动作（见 `references/seedance-2-5-adapter.md` 第五节）。（v1.29，经验）

- 固定：稳定、克制、客观。直接写。
- 缓慢推近：暗流涌动、压抑的紧张。直接写。
- 推近 / 急推：逼近真相、突然震惊。直接写；急推写成“镜头迅速推近到她的眼睛”，避免多处同时写“快速”。
- 缓慢拉远 / 拉远：抽离、孤独、揭示更大的环境。直接写。
- 摇：跟随视线、揭示空间。直接写，写明从哪里摇到哪里。
- 横移、跟拍：陪伴、追踪。直接写。
- 手持轻微晃动：不安、临场感。直接写。
- 升降：权力变化、全知视角。按“名词＋描述”写：摄影机竖直升高或降低，写明从哪里升到哪里（官方直接写清单里没有升降）。
- 环绕：审视、孤立、仪式感。可直接写（官方清单），写明方向和幅度，先试片。
- 剧烈晃镜：混乱、崩溃。交给剪辑或试片后再用，容易画面变形。
- 甩镜：快节奏转场。2.5 可作为段内转场写，写明时间点、方向和到达画面，如“第 9 秒镜头向左甩开，第 10 秒走廊完全清晰”。
- 希区柯克变焦：眩晕、现实崩塌。2.5 官方列为可直接写；写明作用于谁、从哪里开始、到哪里停，先试片。
- 一镜到底：沉浸、情绪连续积累。直接写“一个连续镜头，不切换”，时长以单次生成上限为准。

## 八、切点

按信息、情绪、动作或节奏需要切镜，不按时间平均分配：

- 情绪或立场转折时切。
- 动作到达最高点时切，把余韵留给下一镜；但剧情证据类动作（开瓶、摘手链）先让观众看到可见结果再切。
- 重要台词后可按观看作用切到听者反应；原稿锁定长镜头、不切镜或固定机位时保留，不强制切镜。
- 沉默、停顿本身就是切点，用镜头长度承载情绪。
- 视线匹配：上一镜看向画外，下一镜接他看到的东西。
- 动作匹配：上一镜动作的结尾，接下一镜同一动作的延续。

## 九、对话戏法则

- 听者反应：有听者且需要呈现台词影响时，可切到被骂或被揭穿的人；原稿锁定长镜头时保留，只在诊断中提示覆盖风险，单人独白不新增听者。
- 情绪递进＝景别收紧：中景 → 中近景 → 近景 → 特写。
- 权力不对等＝角度错位：强势方微仰近景，弱势方微俯中景。
- 关系亲近：共享画面或紧接的反应镜头。横屏用双人同框或过肩；竖屏用过肩或前后纵深，只有两人实际靠近时才让对方露出局部。
- 关系疏远＝分割画面：单人正反打，画面里没有对方。
- 说谎时逐渐失焦：模型执行不稳定，改为前景遮挡或切到手部小动作。

## 十、组合用法

组合配方是选项，不需要整套照搬。单个镜头只写核心参数，其余分配到相邻镜头、风格设定或剪辑：

- 紧张压迫：缓慢推近＋微仰；景别在相邻镜头逐步收紧，快切交给剪辑。
- 孤独：远景＋负空间；冷色由风格或场景光线承担，慢拉可作为下一镜。
- 权力反转：站位或道具归属的可见变化，需要时再加角度反转；景别收紧分布在连续几个镜头。
- 悬疑揭示：浅景深＋缓慢推近到关键道具；停顿由镜头时长承担。
- 悲伤离别：逆光＋全景；2.5 可在段内写慢镜头或淡出（写明时间点；淡出为推断，先试片），段与段之间的淡出交给剪辑。
- 平静日常：平视固定＋中景。
- 惊悚不安：手持轻微晃动＋底光（需有低处光源）；急推、跳切放在相邻镜头或交给剪辑，荷兰角先试片。
- 回忆梦境：柔光＋背景光斑；暖调低饱和由风格或调色承担。

## 十一、交给剪辑的部分

Seedance 2.5 可以写进提示词的：同一生成段内的转场（官方写法有擦除、叠化、横移转场、硬切；淡入淡出、闪白闪黑、匹配转场为推断，先试片；都写明时间点、方式和到达画面）、“画面定格 1 秒”、慢镜头、子弹时间、回弹变速。

仍交给剪辑的：

- 帧率类：快动作、抽帧、倒放。
- 段与段之间的转场默认交给剪辑；也可以用官方“视频无缝转场”任务或首尾帧桥接，见 `references/transition-routes.md`。下一段声音提前进入，见 `references/episode-hook-rhythm.md`。
- 节奏：快切加速、慢切减速、跳切、平行剪辑、交叉剪辑。
- 反常规：越轴（段内也可用中性镜头或环绕过渡，见 `references/scene-blocking-axis.md`）、长镜头硬切。景别跳级在同一生成段内按镜头分开写时，可以写进提示词（见第二节“景别组合”）。
- 色彩渐变：由调色完成，不在单段提示词里改色调。

## 十二、避坑

- 无动机运镜：不服务跟随、揭示、空间关系或情绪发展的推拉摇移。
- 有听者且需要呈现台词影响时，只拍说话者而忽略听者反应（检查项，不设反应镜头配额）；原稿锁定长镜头、不切镜或固定机位时保留，只在诊断中提示，单人独白不新增听者。
- 整场同一景别（作为检查项，不设配额）。
- 光线只写形容词，如“压抑”“温馨”。
- 没有情绪高潮时强加特写和慢动作。
- 参数堆砌：角度、运镜或光效彼此矛盾、重复，或争抢观看重点。
- 人物和环境割裂：只拍脸，不交代人在什么空间里。

## 十三、按画幅选构图

画幅确定后整部作品沿用。同一种关系任务，在不同画幅下写法不同：

- 两人对话：16:9 用双人同框中景、左右分立，正反打用单人近景；9:16 以单人发话镜头为主，谁说话拍谁，两人实际相邻时对方肩背或侧脸局部入画，需要同框时用前后纵深，不用左右并排。
- 交代多人站位：16:9 全景横向铺开；9:16 拉高机位或用前中后景纵深排列，人数多时分两镜交代。
- 结盟、亲近：16:9 双人同框中景；9:16 两人实际靠近时用过肩或前后贴近。
- 疏远、孤立：16:9 单人镜头，另一侧大片留白；9:16 单人镜头，头顶或脚下留出大片空白。
- 权力高低：16:9 用仰俯角度，同框时可加左右位置；9:16 只有两人同框且确有高低站位时，才用画面上下位置表达强弱。
- 负空间：16:9 人物偏左或偏右；9:16 人物偏上或偏下。
- 远景：16:9 适合交代横向空间；9:16 适合交代高度（楼梯、挑高大厅），横向空间多用摇镜或分镜交代。
- 插入镜头：16:9 道具居中或偏一侧；9:16 道具居中、纵向排列。

补充：

- 竖屏左右并排三人以上容易挤出画外或被压缩变形，多人场面优先用纵深。
- 前景局部入画、过肩、纵深同框，都要求人物在场景里真的离得近、机位放在那里合理，不能为了构图制造原分镜中不存在的近距离。
- 其他比例按最接近的一列处理：宽于 16:9 的按横屏，接近方形的兼用两列并以纵深为主。
- 2.0 指南提到竖屏更容易生成字幕，2.5 指南未提及；无论横竖屏，排除内容默认写“不要字幕、水印文字”（用户明确覆写的段除外）。

## 十四、选镜前的三个判断（经验，来自 v20 分镜模板）

先问“观众这一刻必须看到什么变化、变化落在谁或什么上”，再选景别、角度和运镜。

### 1. 观众知情与揭示时机

- 对剧情里的关键信息（凶手是谁、信里写了什么、门后有什么），先确定：此刻观众知道什么、每个人物各自知道什么；这条信息第一次能被看到或听到是哪一秒；由脸、手、物件、位置还是声音揭示。
- 揭示前，首帧、镜内过程和结束画面都不能提前露出：用已有的取景范围、朝向、遮挡或焦点挡住，例如“信纸背面朝向镜头”“门后保持黑暗”。不为挡住信息新增道具或动作。
- 声音同样遵守揭示时机：揭示前不提前出现关键声音。
- 揭示的那一秒必须看得清：写清画面里是什么、在哪、多大。
- 揭示顺序以剧本为准；剧本没写清时列为待确认槽位。

### 2. 先选拍谁，再选多近

- 镜头给“承载这一刻变化的人或物”，说话的人、主角、最激动的人都不自动拿特写。
- 话的意思已经由声音交代、真正的变化发生在听者身上时，拍听者；台词仍是说话人的，写“角色名画外音：……”。
- 改变局面的动作（递出、接过、打翻、松手）先让这一瞬间看清，再切到反应；切给反应会漏掉唯一的交接或接触时，留在原镜头。
- 进入特写前想清楚：要看清哪个局部变化、什么时候进、什么时候离开。没有观看目的的收紧可留在原景别；持续倾听或等待也可承载镜头，不以新信息数量作为切镜配额。

### 3. 主观视角和客观插入分开

（v1.34 补充，v1.35 改，参考）剧本写到手机录像、自拍、监控画面这类“设备视点”时，正文写“全程保持手机这一个连续视点”，“外部旁观机位”写进排除内容。手机前后摄像头切换要写明是哪一个摄像头；拿手机拍摄的人说话按画外音写。来源：社区案例 se-006、se-007，均为聚合站改编版，原帖未核对；官方没有对应写法；未实测。适用：只在剧本写到设备视点时。

- 物件特写先判断是“角色看到的”（主观视角：机位在角色眼睛的高度和方向，符合其朝向和遮挡）还是“拍给观众看的”（客观插入）。
- 观众看到不等于角色知道：客观插入让观众先知道的信息，角色仍按自己看到的反应，不提前变脸。
- 书页、照片、手机屏幕、文件先确认正面朝谁、谁在看；拍“角色在看”时，机位在角色肩后或侧上方，正面朝向角色。不为让观众看清而让人物把东西转过来，除非剧本有这个动作。
