# 单集开场、结尾钩子与声音转场

分镜是短剧某一集的第一个生成段或最后一个生成段，或者需要让声音跨切点衔接时读取本文件。

来源：用户提供的《极致开幕钩子生成器》skill（黄金 1 / 3 / 5 秒法则、J-cut / L-cut 声音转场、结尾钩子类型）。已对照《Doubao Seedance 2.5 提示词指南》（下称指南）和《Seedance 2.5 教程》核对：两份官方文档都没有“钩子”“开场节奏”“J-cut”这些概念，本文件的节奏规则属于创作经验；具体落到提示词时使用的时间点、定格、延长、首帧、画外音、声音标记是官方写法。

## 一、适用范围与时长原则

- 每一集的第一个生成段做开场检查，每一集的最后一个生成段做结尾钩子检查；集内中间的生成段不强制，按 `references/dialogue-scene-continuity.md` 写清关系变化落点和末帧状态即可。
- 剧本内容不删减（SKILL.md 核心原则 16）：本文件的开场和结尾检查只出诊断建议，不自动改动剧本：
  - 不做“前情回顾”；
  - 开场：在剧本已有内容的范围内，用景别、运镜、声音和表演让第一秒就有动作或异常；如果认为应把高能动作或台词前移、压短铺垫，只在诊断中提示，由用户决定；
  - 结尾：分集和切点以剧本为准，不把内容挪到下一集；认为别处更适合做钩子时，只在诊断中提示；
  - 原剧本在该位置没有可用的动作或台词时，把“需要补一个动作或一句台词（约 1–3 秒）”列为待确认槽位，不自动添加。

## 二、开场检查（每集第一段）

经验规则：

1. 第 1 秒：画面里已经有动作或异常（一只手、一声响、一个反常的画面），不从空镜慢慢铺垫。
2. 3 秒内：建立一个疑问或完成一次情绪冲击（一个巴掌、一句反常的话、一个被威胁的东西），并让观众知道时代和地点。
3. 第 5 秒左右：出现一个转折（新信息、新人物入画、局面反转）。
4. 第二集起：前几秒直接从上一集结尾的状态接上，先接住上一集的钩子，再抛出本集的新问题；不重新交代世界观。

落到提示词（官方写法）：

- 用时间点写关键事件：“第 1 秒，一只手把合同按在桌面上”（指南：“第 2 秒一道金雷能量自画面顶部破空直落”）。
- 前 1–3 秒只放一个事件。指南提醒时间段内容过多会导致“过度剪切或剧情遗漏”，不要为了抓人把多个事件挤在开头。
- 文戏不写“极速快剪开场”：官方文戏案例排除“快速剪辑、跳帧”。
- 第二集起的接续：把上一集最后一帧作为本段首帧（“图片 1 为首帧”），或用“向后延长视频 1”续写；输入 Seedance 2.5 自己生成的视频做延长，衔接效果更好（指南）。
- 开场靠动作和台词，不靠文字：黑板倒计时、合同金额、手机屏幕上的字都违反“不要字幕、水印文字”强制规则；需要观众读到的信息改成台词或画外音。
- 不写“推入瞳孔”这类眼部特效镜头（指南“情绪过度响应”会导致眼睛发光）。

### 冷开场（剧情开头太平时）

把本集稍后的一个高能画面提到最前面，再接正片。官方没有冷开场写法，建议：

- 冷开场画面单独生成一段（或直接从本集已生成的高能片段中截取），后期剪辑拼在最前面；不要在同一个生成段里写时间跳跃，模型容易混淆前后关系（推断）。
- 冷开场之后需要片名时，按 `references/opening-ending-title.md` 留出干净画面，片名在剪辑中加。
- 写“剪辑建议：第 X 集开头先放某段第 A–B 秒的画面，再接正片”。

## 三、结尾钩子（每集最后一段）

经验规则，三类钩子任选其一：

- 事件转折：答案揭晓前一刻切断（门被推开、来人刚要开口、信封刚撕开）。
- 异常场景：出现一个不合常理的画面（本该死去的人站在门口、空房间里有人说话）。
- 情感冲击：一句改变关系的台词刚说完，对方的反应还没出现。

落到提示词（官方写法）：

- 最后一个时间段写到钩子那一刻为止，并写“结束时……”的状态（官方案例写法）。
- 需要停在钩子画面上时写“画面定格 1 秒”（指南：“主角按下快门后画面定格 1 秒”）；“未完待续”等文字在剪辑中加，见 `references/opening-ending-title.md`。
- 钩子台词由人物说出或写成画外音，不靠画面文字。
- 钩子之后的内容写进下一集第一段，并在下一集的站位设定里复述这一集的末帧状态。

## 四、声音先入与声音后留（J-cut / L-cut）

官方没有 J-cut / L-cut 术语，但提供了声音标记（音乐 ()、音效 <>、台词 {} 或“角色台词（情绪）：内容”）和“画外音：”写法，可以在同一个生成段内实现：

- 声音先入：在切镜前 1–2 秒写下一镜的声音，例如“10-12 秒：近景，她盯着桌上的信，<门外传来敲门声>。12-15 秒：门口全景，门被推开，男人站在门口。”
- 声音后留：切到新画面后，上一镜的人声或环境声继续，例如“男人画外音：‘你知道我为什么回来吗？’”写在下一镜的反应画面里，一句台词放在一个时间段内说完（按 `references/dialogue-scene-continuity.md` 第六节）。
- 跨生成段的声音衔接：用延长任务（官方：延长时“可要求画面 / 音频无缝衔接”，输入输出用 mov 格式效果更好，音量可能略有变化），或写进“剪辑建议”由剪辑完成。
- 音乐桥接（一段音乐贯穿两场）属于背景音乐。背景音乐在本 skill 中是待确认项，用户没有确认需要音乐时不使用。

## 五、示例

第二集第一段（接住上一集结尾“门被推开”的钩子）：

```
素材指代：图片1是上一集最后一帧，作为首帧；图片2是林夏；图片3是陈屿。
一句话概述：深夜出租屋，门被推开，站在门口的是失踪三年的陈屿，林夏手里的信掉在地上，都市悬疑风格。
站位设定：林夏站在画面左侧桌边，面朝画面右侧的门，右手拿着一封拆开的信；门在画面右侧，刚被推开一半。
0-1秒：中景，平视，固定。门被完全推开，撞在墙上发出闷响<门撞墙声>。
1-3秒：近景，画面左侧的林夏手一松，信掉落在地上，她盯着画面右侧的门口，嘴唇微张，没有出声。
3-6秒：中景，门口，画面右侧站着的陈屿浑身湿透，雨水从发梢滴落。陈屿台词（沙哑，平静）：“信是我写的。”
贯穿要求：林夏在陈屿说话时自然闭口；保持两人的身份、空间方位和视线方向连续。
排除内容：不要字幕、水印文字；无背景音乐，只保留人声、雨声和门声；排除快速剪辑、跳帧、空间位置跳变。
```
生成参数：duration=6

开场检查：第 1 秒有动作（门撞墙），3 秒内有情绪冲击（信掉落），第 3–6 秒出现转折（来人是陈屿、信是他写的）。没有前情回顾。
