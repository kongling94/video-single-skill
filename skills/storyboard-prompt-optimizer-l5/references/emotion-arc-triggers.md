# 情绪弧、触发器与表演顺序

文戏一个生成段里主角的情绪要经历几次变化时读取本文件，用来安排变化的顺序、触发和强度。单个情绪的面部写法查 `references/emotion-quick-reference.md`。

来源：
- 用户提供的《文戏30S（情绪版）》：功能位、触发器、强度、第三角色、核心道具、台词。
- 用户提供的《影视镜头导演》：表演顺序。

每条已对照《Doubao Seedance 2.5 提示词指南》（下称指南）核对。主要依据是指南“台词复述引发字幕”中的周婆婆案例和“情绪过度响应”案例。标注“官方写法”“经验”或“调整”。核对全文见 `docs/优化记录-v1.15-动作焦点情绪弧.md`。

## 一、表演顺序

以下顺序适用于需要辨认、犹豫、判断后行动的表演，是从单个案例提炼的创作经验，不是每次情绪变化的必经流程：

刺激 → 本能反应 → 掩饰或判断 → 决定 → 动作

官方依据是周婆婆案例：
1. 认出林秀兰（刺激）；
2. “脚步短暂停顿，嘴唇轻颤”（本能反应）；
3. “先颤抖着扶正眼镜，再用一只手短暂揉一次自己的眼睛”（判断）；
4. “确认没有看错后，她才伸出双手”（决定和动作）。

写法规则：
1. 只展开本段实际发生的步骤；惊吓、冲动或剧本指定立即行动时，可从刺激直接到动作。官方案例要求其中动作依次发生，不等于禁止所有立即反应。（经验）
2. 避免默认对应：惊讶不一定倒吸气，愤怒不一定握拳，悲伤不一定流泪。按人物性格和情境选反应。例如：
   - 克制的人惊讶时可能只是手停住；
   - 愤怒的人也可能突然变得很安静。
   （经验）
3. 没有掩饰或判断过程时可以省略，不必额外声明。有掩饰时，写成两组相反的动作同时出现，见 `references/emotion-quick-reference.md` 使用规则第 5 条。

## 二、情绪弧的五个功能位

一个约 30 秒的文戏生成段，主角的情绪按功能排，不按情绪名称排（结构为经验，概念有官方依据：周婆婆案例 14 秒内从震惊到激动到落泪，是由事件推动的连续变化）。

| 功能位 | 剧情作用 | 必须看得见的东西 |
|---|---|---|
| ① 表面状态 | 建立关系、目标和谁占上风 | 视线落点、身体距离、核心道具在谁手里 |
| ② 第一偏差 | 新信息让原来的判断失效 | 笑意收住、视线改道、手停住或道具状态变化 |
| ③ 关系受压 | 误会、受伤、恐惧或羞耻加深 | 呼吸断开、话说一半、距离变化、动作没做完 |
| ④ 决定或最高压力 | 主角做出改变行动的决定 | 推回、抽走、转身、逼近、拒绝 |
| ⑤ 新的落点 | 澄清、决裂、和解、反转或留白 | 前面留下的痕迹还在，新的决定落到具体动作上 |

使用规则：
1. 时间不平均分。整数秒参考（经验，可调）：
   - ① 0–5 秒；
   - ② 5–10 秒；
   - ③ 10–16 秒；
   - ④ 16–23 秒；
   - ⑤ 23–30 秒。
   较短的段可以合并功能位，例如 15 秒只写 ①②④；这只适用于自己补充的情绪弧，剧本已写到的节点不省略。
2. 相邻功能位保留上一个的痕迹：泪痕还在时视线可以定住、不再眨眼，手还握着道具时可以从犹豫变成拒绝；有明确新信息触发时，可以迅速转为愤怒；无触发时不能只靠换镜头重置状态。
3. 用户已给的情绪可以放在起点、高峰或落点上，其余功能位只从已有剧情中找，不要求补齐。补出的新情节列为待确认槽位，不直接写进提示词。

## 三、触发器

每次情绪变化都要回答：什么新东西进入了局面，它改变了谁的下一步？

| 类型 | 写法 | 依据 |
|---|---|---|
| 台词 | 一句短台词改变信息或关系，不用长台词解释背景 | 官方案例 |
| 动作 | 递出、抽回、推开、转身、靠近、停止触碰 | 官方案例：“确认没有看错后，她才伸出双手” |
| 道具 | 打开、翻转、滑落、露出第二层内容、被夺走 | 官方案例：“低头看向车票目的地” |
| 沉默 | 该回答的人没有回答，并且有吞咽、避开视线等可见动作 | 官方多宫格案例：“少女微微低头沉默” |
| 声音 | 门响、提示音、脚步改变人物的下一步；同一段不反复用声音打断 | 经验 |
| 误会与澄清 | 后出现的画面证据推翻前面的判断，用画面或短句完成，不靠解释性独白 | 经验 |

- 一个生成段里，触发器尽量覆盖三种不同类型。（经验）这是写法上的提示，不是配额：剧本只提供一两种触发时照剧本写，不为凑类型新增台词、动作或道具（v1.30）。
- 只写“表情变了”不算触发器。（经验）
- 删掉这个节点后后面的动作完全不变，说明它也不算触发器。（经验）

## 四、强度

强度分四档（调整：按指南“表演细腻真实，不过度夸张”和“情绪过度响应”案例改写）：

| 档位 | 什么时候用 | 写法 |
|---|---|---|
| 轻 | “有点”“一丝” | 一个局部小动作，一个面部信号 |
| 中（默认） | 没有特别说明时 | 完整的姿态反应，面部加身体各一个信号 |
| 强 | “非常”“压不住” | 全身参与，写呼吸变化 |
| 极限 | “崩溃”“失控” | 只用身体和呼吸表现，例如瘫坐、僵住、呼吸断续、双手发抖 |

极限档的写法要求：
- 不写“怒目圆睁、瞳孔放大、青筋暴起、五官彻底扭曲”这类写法；
- 贯穿要求中加“人物为正常人眼、不发光”。（官方写法）

强度曲线（经验）：
- 高峰数量及是否回落由剧本决定，不强制 1–2 个高峰或至少一次假平静；
- 持续压抑、突然爆发、未恢复的结尾都可成立；
- 只延续已经产生的痕迹，例如既有泪痕或未平复的呼吸，不为表现余波新增哭泣、伤势或发抖。

换档时同时换动作幅度和呼吸，不只换形容词。

## 五、三人戏的第三角色

- 三人戏先定一名主情绪角色和一名关系对手。（经验）
- 第三角色可以负责揭示、打断、见证或推动决定，按剧情选择，不强制。（调整）
- 第三角色可以只做见证：官方周婆婆案例里，春丫、石头只负责搀扶，“全程自然闭口，只用眼神和表情回应”。
- 三个人不各演一整套情绪变化。不要求每个人都走完整情绪弧；配角也可按剧本承担自己的转变，分清观看重点和先后。

## 六、台词不直说情绪（只做诊断提示）

- 台词写成“我现在很伤心”“我很生气”这类直接说情绪的句子时，在诊断中提示用户：这种台词让表演空间变小，可以改成提供事实、施压、拒绝、试探或澄清的句子。
- 官方用“角色台词（情绪）：内容”承载情绪，对台词内容本身没有规定。所以本条只提示，不擅自改用户的台词；改不改由用户决定。

## 七、一镜到底的情绪渐进链（v1.34，参考）

来源：lanshu-awesome-ai-video-kit 仓库收录的第三方 Seedance 2.5 实测案例（se-001 出租车分手戏，中文原文完整）。官方依据：指南的变老案例写“眼神里的隐忍慢慢化开，泪光滑过眼角，嘴角一点点扬起，最后破涕为笑。全程一镜到底”，周婆婆案例写“双眼逐渐湿润”。

一个镜头里情绪要连续变化时，可以这样写：

1. **先写起始状态**，用正向描述：“一开始她脸上仍带着刚才的微笑”。不写“没有皱眉也没有哭”这种否定，需要的话放进排除内容。
2. **按剧本实际发生的可见变化，用连接词串联，不预设最低或最高步数**：慢慢地、接着、然后、终于。每一步只写一个可见变化，比如眉头轻皱 → 抿紧双唇 → 眼眶泛红 → 仰头忍泪 → 泪水落下。
3. **按实际起止状态总括**，例如确有对应剧情时写“整段从逞强微笑到忍不住落泪，一镜到底”；不要求经过压抑、外泄或爆发，也不补原稿没有的阶段。

注意：
- 每一步的触发器仍按第三节写。
- 强度按第四节控制，不要每一步都加码到最大。
- 节拍按剧本、语气和实际时长取舍。“约 2 秒一步”仅是估算示例（未实测），不作固定间隔；直接笑、哭或保持不动按原稿处理。
- 适用：一个镜头内情绪要连续变化的文戏；需要切镜表现的情绪变化仍按第一至四节写。
