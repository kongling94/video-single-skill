# 对话戏与跨段一致性

分镜以对话、倾听、情绪拉扯为主（文戏），或一场戏需要多个生成段拼接时读取本文件。

来源：用户提供的《剧本转视频提示词（文戏长剧情版）》。每条已对照火山方舟《Doubao Seedance 2.5 提示词指南》（下称指南）和《Seedance 2.5 教程》（下称教程）核对，标注“官方写法”或“经验”。经验条目官方未提及，但与官方写法不冲突，需要试片验证。核对全文见 `docs/优化记录-v1.12-文戏吸收.md`。

## 一、角色声线锁定

1. 首选音频参考（官方写法）：每个说话角色上传一段音色音频，在素材指代中绑定，例如“图片1是林夏，图片1使用音频1音色；图片2是陈屿，图片2使用音频2音色”。教程要求写明每份素材提供什么（外貌、动作、音色）以及不采用什么。
2. 没有音频时写文字声线（官方写法）：参照指南案例“周婆婆使用苍老沙哑、生涩蹩脚、带轻微异族口音但清晰可辨的普通话”，在“人物设定：”中为每个说话角色写一句：年龄性别、音色、口音、常态语速和音量、受压或亲近时的变化，以及需要排除的腔调（如“不用播音腔”）。不用秒数或拍数描述声音节奏。
3. 逐字复用（经验）：同一角色的声线句一旦确定，之后每个生成段逐字复制，不换词、不缩写；当前情绪只写在“角色台词（情绪）：内容”的括号里。
4. 只写本段实际说话的角色的声线，避免声线串位（指南“角色对应错误”“音频翻译语种混淆”）。
5. 不用 【角色名声线】 这类写法：教程规定 【】 表示字幕。

## 二、跨段复位：末帧状态清单

每个生成段结尾写“结束时……”（官方写法），下一段的站位设定从这个状态开始，不能只写“承接上一段”。从上一段最后一个镜头逐项提取（清单为经验）：

- 每名在场角色在画面左、中、右和前、中、后景的位置；
- 坐、站、倚靠还是在走动，身体朝向和视线落点；
- 已离场角色从哪一侧离开，原位置留下什么（空椅、空位）；
- 核心道具在谁手里、哪只手，或在桌面哪一侧，开合、液面、损耗状态；
- 椅子、门窗、手机、杯子等可移动物件的最终位置；
- 机位在两人连线的哪一侧，光线时段，主要环境声。

能用官方能力接续时优先使用：把上一段最后一帧作为下一段首帧（“图片3为首帧”），或用“向后延长视频1”续写；延长任务输入输出用 mov 格式保持声画一致（指南）。也可配合 `references/scene-blocking-axis.md` 第八节的结尾 1 秒技术全景。

## 三、本段道具清单（经验）

- 站位设定中出现的道具就是本段的起始道具清单；后续镜头用到的既有道具，必须已经在站位设定中写明位置。
- 新道具必须通过取出、端入、递入、掉落等可见过程进入画面，并写落点。
- 道具被带走或丢弃后，后续不再引用；需要再出现时写它怎么回来。
- 修改分镜删掉某件道具时，同步删掉所有依赖它的动作和结束状态。
- 与 `references/scene-prop-continuity.md` 的数量、绑定、排除规则合并使用。
- 核心道具状态表（经验）：
  - 一段 30 秒的文戏默认一个核心道具，最多再加一个次要物件。
  - 设计时先列下表，表格本身不写进提示词，只用来检查每个时间段的写法。
  - 每次交接写清开始、过程和落点；不写上一镜在甲手里、下一镜没有过程就到了乙手里。
  - 官方案例写过：“将纸质车票定义为去大城的火车票”“低头看向车票目的地”。

## 四、参考图分工

- 场景图只参考空间骨架：门窗、大件家具、前中后景、光线方向、主色（官方写法：“部分参考要写明参考哪一部分”）。
- 角色图只参考人物：脸、发型、服装、配饰；角色图的纯色棚拍背景不带进剧情场景，场景图里出现的人不当成本剧角色（经验，按官方“写明不采用什么”写进素材指代）。
- 参考图上的书脊、海报、包装、衣服印花有可读文字时，写“图片N中的文字只保留色块和形状，显示为不可辨认的图案”（经验）。这条与本 skill 的强制排除“不要字幕、水印文字”配合使用。
- 不在参考图上写人名做映射，映射写在文本里（官方写法）。
- 设定图（多视图拼图、平面图、服饰细节、图上文字）的详细处理见 `references/reference-asset-prep.md`。
- 主角在一段里情绪变化几次时，变化顺序、触发器和强度见 `references/emotion-arc-triggers.md`。

## 五、什么时候切镜（经验）

只在以下情况之一发生时切镜：

- 出现新信息；
- 说话权或关系中的强弱改变；
- 人物距离、朝向或行动目标改变；
- 道具被拿走、递出或状态改变；
- 一个声音让人物改变下一步；
- 情绪变化改变了动作；
- 台词需要转由倾听者、道具或环境来承载画面。

写法：

- 连续的短问答用侧面双人中景走完，到审视、受压、拒绝、离场的那一句再切近景，不逐句机械正反打。
- 镜头数没有官方标准，按戏的类型选两档参考：
  - 情绪文戏、长对白：30 秒约 6–10 个镜头，用较长的时间段。依据是官方周婆婆案例，14 秒 3 个时间段，排除“快速剪辑、跳帧”。
  - 多场景、快节奏的对白：每镜 1–2 秒，30 秒可到约 16–20 个镜头。依据是官方“角色对应错误”案例，13 秒 8 个镜头，写法如“镜头 3｜4 秒 - 5 秒”。
- 真正需要的运镜 1–2 次，其余镜头稳定机位直接切景别。
- 依据：指南指出时间段内容过多会导致“过度剪切或剧情遗漏”。负载检查见 `references/action-focus-crowd.md` 第四节。

## 六、台词、画外音与倾听回声

1. 一句完整台词放在一个时间段内说完，不在半句处拆到下一个时间段。官方案例排除“重复台词、漏词、口型错位和声画不同步”。（按官方排除项调整）
2. 说话人不在画面中时，写“角色名画外音：……”（官方广告案例用过“画外音：”）。可以让一整句台词在倾听者的反应镜头、手部道具镜头里播放。不使用“OS”这个标签。
3. 原作明确写出的内心独白保留，写成“角色名内心画外音：……”，一句完整放在一个时间段内（推断，需试片）；原作没有内心独白时不新增。
4. 同一时刻只有一人说话；不说话的人写“全程自然闭口，只用眼神和表情回应”（官方写法），排除“错误人物发声、多人同时说话”（官方写法）。
5. 倾听者要有可见回应，不只写“认真听着”：台词在倾听者的视线、眼睑、嘴角、呼吸、手部或坐姿上留下一个变化，并影响下一句或下一个动作。（经验）
6. 两人反应有先后：甲的台词或动作先完成，乙看见或听见后再反应，不同一帧无缘由地一起变脸。（经验）

## 七、插入镜头与空镜（经验）

官方文档没有空镜写法；指南提醒时间段内容过少，模型会自由发挥。所以每个无人画面都要写清画面里有什么、什么在动、听到什么。

- 插入镜头：画面切到手、杯子、手机等局部，人物身体可以入画，动作继续。
- 空镜：人物完全出画，但上一镜开始的动作、对白、声音在画外继续，下一镜接回时人物已经推进到新的状态。例如：“5-7秒：近景，桌面低机位，只拍柠檬水，杯中冰块沿上一镜的方向继续旋转，轻碰杯壁。苏晚画外音：‘房子车子我也在攒。’画外传来陈屿把杯子放回桌面的声音。”
- 过渡空镜：原作有时间流逝、换场、人物离场时才用。
- 空镜必须承接一个正在进行的动作、声音或物理后果，不凭空出现水纹、摆动、声响；找不到可承接的内容就不加空镜。

## 八、分段与台词密度（经验）

- 一段只承载一个主场景、一次主要关系变化和一个明确的结尾，在提问落点、决定、拒绝、离场、信息揭示处收尾。依据：指南“复杂任务拆成多个简单任务分次生成”。
- 不在一句完整台词中间切段。
- 30 秒参考 60–90 个汉字的有效台词；短促问答可略多，迟疑、压抑的表演应更少。超出时在关系转折处拆段，不靠加快语速硬塞。这是经验值，按生成结果校准。

## 九、身体接触动作链（经验）

拥抱、搀扶、接住、俯身这类接触动作按顺序写全，不从相隔几步直接跳到贴近：

起始距离 → 触发动作或台词 → 后退或失衡的原因 → 另一人的移动路径 → 接触点 → 支撑的手和身体落点 → 最终脸部距离。

例如接住时写清“一只手托住她的后腰，另一只手撑住沙发扶手，身体重量不压在她身上”。排除内容配合官方写法“手掌穿模、多余手指、手指粘连、手部畸形”。与 `references/scene-prop-continuity.md` 第二节握手规则一起使用。

## 十、修改后完整重发（经验）

用户要求修改任何镜头、台词、声线或道具时，重新输出该生成段的完整提示词（素材指代、人物设定、站位设定、全部时间段、贯穿要求、排除内容和生成参数），不只给修改的片段。用户明确说“只发修改部分”时除外。
