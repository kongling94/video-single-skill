# 人物位置关系库

分镜含两个及以上人物，或单人与环境、物件、观察者之间存在关系时读取本文件。

来源：用户提供的《AI 短剧提示词手册》位置关系提示词 P09–P12（第 73–108 条，共 36 条）。本文件把样例按规律重新归类，用本 skill 的写法重写，并补上视频需要的写法；不是手册原文。

## 一、从 36 条样例学到的规律

1. 位置就是关系。每条样例都是同一个三句结构：谁在画面哪里 → 空间如何把人连起来或隔开 → 由此产生什么情绪或权力关系。写镜头时先定关系，再选位置，不要反过来。
2. 36 条可归为六条轴：左右（平等、对立、距离）、前后纵深（主次、压迫、窥视）、高低（地位、权力）、框架遮挡（困住、隔离、阻断）、反射媒介（双重、暗流、隐藏信息）、封闭空间与群像（对质、孤立、局促）。
3. 手册的“AI 指令”只给构图标签，例如“对峙构图”“层次构图”。图片模型能靠标签猜，视频模型不够：视频必须写清画面左右、前后景、机位高度、焦点落在谁身上、谁在动谁不动、开场站位和结束站位。
4. 样例的共性是 9:16 竖屏、男主黑衣女主白衣、冷灰低饱和。这是手册的风格设定，不是位置规则，不得自动套用到用户分镜；宽高比仍走待确认槽位。

## 二、使用规则

- 先定关系再选模板：从叙事目标判断这一镜要表达的关系（对立、疏离、压制、窥视、隔绝、孤立……），选一条主轴，最多再叠加一条辅助轴（例如“前后景压迫 + 门框限制”）。叠加三条以上容易互相冲突。
- 方位一律写“画面左侧 / 画面右侧 / 前景 / 中景 / 后景 / 画面上方 / 画面下方”，不写“他的左边”这类以角色为参照的说法。
- 相邻镜头保持同一条视线轴：上一镜男主在画面左、看向右，下一镜正反打时仍保持他看向右，避免越轴导致人物左右跳位。需要越轴时写明过渡（环绕运镜或中性镜头）。
- 位置变化要写成走位：在时间节拍里写“从 A 处走到 B 处”，并写结束站位，不能只写起点。
- 高低关系必须和机位配合：强势者在高处时用低机位仰拍强势者、高机位俯拍弱势者；两者同框时写明机位高度在谁的视线水平。
- 纵深关系必须写焦点：哪一层清晰、哪一层虚化，焦点何时转移。
- 留白和距离要写成可见的东西：中间隔着什么（空地、桌面、门、玻璃、光带），而不是只写“有距离感”。
- 多人场面按人物首次出场顺序编号，与参考素材一一对应，并为每个人写一个能区分的外观锚点（服装颜色、发型、道具），防止换位后角色错位。

## 三、六条轴与模板

每条模板按“布局 / 关系 / 视频写法”给出。视频写法是本 skill 的补充。

### 轴 1：左右

- 左右分居：两人分立画面左右两侧，中间留出明确空间。关系是对峙、互不相让。视频写法：中间放一个可见隔断（桌面、空地、光带），两人视线隔空相接，镜头保持平视，可缓慢推近中间空隙。
- 并肩站立：两人同在画面中线附近并排，同向而立。关系稳定、同盟。视频写法：写清谁在画面左、谁在右，同一景深、同一焦平面，肩线基本平齐。
- 左右错位对话：两人分列左右，一前一后轻微错开。关系有层次，一人主导一人退半步。视频写法：写明前者在前景清晰、后者略后略虚，说话时焦点在两人之间转移。
- 中心夹击：一人居中，左右各一人向内逼近。关系是被围、被逼问。视频写法：中间人物面向镜头，两侧人物侧身朝向她，两侧人物略高或略近，可配合缓慢推镜收紧。
- 同侧拥挤：两人挤在画面同一侧，另一侧大片空白。关系是压迫、无处可退。视频写法：写明空白一侧是什么（墙、暗处、走廊尽头），人物不越过画面中线。
- 空位留白分隔：两人分处画面两端，中间是大面积空位。关系是冷战、情感距离。视频写法：用全景或远景，两人各自静止或背向，中间空位里有固定物（空椅、地毯、窗光）。
- 三分法对峙：两人分别位于画面左右三分线上，视线在中线交汇。关系平衡而紧张。视频写法：中近景，两人高度相近，镜头固定或极缓推进，不让任何一方越过中线。

### 轴 2：前后纵深

- 前后景压迫：强势者占据前景、体量大，弱势者在后景、体量小。关系是尺度压迫。视频写法：过肩或侧前景构图，前景人物轮廓压住画面一侧，焦点可落在后景弱势者的脸上。
- 一前一后错位：前景人物清晰，后景人物仍可辨认。关系疏离而克制，彼此知道对方在。视频写法：写明前景人物不回头，后景人物看向前景人物的背影或侧脸。
- 前景虚化窥视：观察者在前景、背对或侧对镜头且虚化，被看者在后景清晰。关系是窥视、监视。视频写法：前景人物只露肩背或头部轮廓，焦点固定在后景主体，后景主体不察觉或稍后察觉。
- 后景等待：前景人物在行动或出神，后景人物静止等待。关系是距离被拉长、情绪留白。视频写法：前景人物可浅景深虚化或清晰，后景人物保持站姿不动，结束时可让前景人物察觉回头。
- 焦点前后转换：同一构图内焦点在前后两个人物之间切换。关系是信息逐层递进。视频写法：按时间节拍写“X 秒焦点从前景 A 转移到后景 B”，写成画面描述，例如“前景 A 渐渐模糊，后景 B 逐渐清晰”。
- 长走廊纵深：人物沿走廊纵轴前后排列，距离拉开。关系疏离，有追随或离去感。视频写法：中心透视构图，写明走廊两侧的重复元素（窗、门、灯），谁在走、谁在等、朝哪个方向。

### 轴 3：高低

- 楼梯上下层级：一人在上层台阶，一人在下方抬头。关系是层级对比。视频写法：写明上方人物所在台阶与下方人物的相对高度，机位放在两人之间偏下，仰望者的视线方向要明确。
- 一坐一站：一人坐、一人站，视线高度差明显。关系立刻分出主动与被动。视频写法：站者可在画面一侧形成竖向轮廓，坐者抬头，写明坐具和站立距离。
- 高台俯视：强势者在高处（看台、阳台、二楼栏杆）向下看。关系是权力。视频写法：低机位仰拍高处人物，或高机位越过他的肩膀俯拍下方。
- 地面仰望：一人跌坐或跪在地面，另一人站立俯视。关系强弱极端。视频写法：站立者可只露出腿部或下半身作前景，地面人物抬头看向画面上方。
- 电梯内身高压迫：狭小空间里身高差和贴近距离同时存在。关系集中、紧张。视频写法：两人近景，高者低头、矮者抬头，背景是电梯金属壁，几乎没有活动空间。
- 阳台上下对视：一人在楼上阳台，一人在楼下抬头，视线上下相连。关系是距离与牵挂。视频写法：可用两个时间段正反打，上方镜头俯拍、下方镜头仰拍，视线方向前后一致。

### 轴 4：框架与遮挡

- 门框限制：人物被门框包围，空间收窄。关系是困住、退无可退。视频写法：门框作为画中画边界，人物手扶门框或半身探出，镜头位于门外。
- 窗框隔离：窗内窗外各一人，被玻璃和窗框隔开。关系疏离、无法接近。视频写法：写清谁在窗内、谁在窗外，玻璃上的反光或雨痕只作轻描，不抢主体。
- 玻璃门分隔：两人隔着透明门贴近，手几乎相触却无法接触。关系被切断。视频写法：两人手掌隔玻璃相对，写明玻璃位置在两人正中。
- 狭窄走廊夹击：人物被压在狭窄通道里，两侧墙体或书架靠近。关系压迫。视频写法：写明两侧障碍物离人物很近、延伸到画面边缘，人物身体侧转。
- 帘幕遮挡：前景纱帘半遮人物，人物若隐若现。关系是窥视、犹豫。视频写法：帘幕在前景，可写轻微飘动，人物在帘后半露脸。
- 车门框住人物：打开的车门形成画框，人物被完整包住。关系是封闭、登场。视频写法：机位在车外，车门边框和车窗形成框中框，车外人物可作前景侧影。

### 轴 5：反射与媒介

- 镜中双重：现实人物与镜中倒影同时出现。关系是双重信息、内外不一。视频写法：写明镜子位置和镜中显示的是谁，倒影动作与真人同步。
- 后视镜视线：通过车内后视镜建立前后排视线。关系是暗流、互相观察。视频写法：后视镜在画面上方，镜中露出后排人物的眼睛，前排人物在前景。
- 橱窗反射：橱窗玻璃同时映出人物和街景。关系是现实与倒影并置，故事感强。视频写法：写明主体在玻璃内侧还是外侧，反射层只写街灯、行人等轮廓。
- 电梯镜面多人：电梯镜面同时显示多人的正面和背面。关系是信息量大、各怀心思。视频写法：写明镜中人数与现实人数一致。
- 水面倒影：雨后积水映出人物，现实与倒影互文。关系带隐喻。视频写法：写明倒影人物与现实人物的上下位置关系。
- 手机屏幕映射：人物表情映入手机屏幕，用小物件放大情绪。关系是细节集中。视频写法：微距或特写，写明屏幕是黑屏反光还是亮屏，屏幕内容不写具体文字。

### 轴 6：封闭空间与群像

- 圆桌对角：两人坐在圆桌两端，桌中道具清晰。关系是谈判。视频写法：写明桌上道具和两人的相对方位，可在两人之间正反打。
- 车内前后座：前排与后排分层，通过镜面建立视线。关系封闭、有张力。视频写法：写明谁在驾驶位、谁在后排哪一侧，车窗外光线随车移动。
- 三角站位：三人形成稳定三角形，前后左右关系清楚。关系一眼看懂。视频写法：写明三角的顶点是谁（通常最近镜头或居中），另外两人在后方两侧。
- 群体中心孤立：主角独自位于中心，外围人群形成包围。关系是孤立。视频写法：主角清晰、外围人群可略虚或背对镜头，人群与主角之间留出一圈空地。
- 电梯角落压缩：多人被分配到电梯各角落，空间局促。关系尴尬而紧张。视频写法：写明每人所在角落，彼此视线回避或交错。

## 四、目标 AI 为 Seedance 2.5 时的注意事项

- 位置关系写在时间戳情节里，每个时间段开头先交代站位，再写动作和表情。
- “9:16”“竖屏”是 ratio 参数，写在生成参数行，不写进提示词。
- 水面倒影属于 `references/seedance-2-5-adapter.md` 提到的水相关描述，可能引出音频噪声；使用时在诊断中预警，并在排除内容中写明不要水声以外的杂音。
- 反射类构图（镜面、后视镜、橱窗、电梯镜面）中倒影人数、动作、方向容易出错，这一判断是推断，官方文档未专门说明；写明“倒影与真人动作同步、人数一致”，复杂时拆成两个简单镜头。
- 手机屏幕、橱窗里出现文字时，按适配模块的文字规则处理。
- 多人位置关系依赖参考图时，按人物首次出场顺序上传，提示词编号同步。
- 样例中的真人形象不能直接作为参考图上传，真人人脸合规按适配模块执行。
