# 场面调度与轴线

分镜含两个及以上人物的对手戏（对话、争吵、对峙、打斗）时读取本文件。它把一场戏从“导演逻辑”拆到“机位和正反打”，与 `references/position-relationship-library.md`（站位）、`references/camera-grammar.md`（景别、角度的选择）、`references/camera-movement-library.md`（运镜写法）配合使用。

来源：用户提供的 4 张《AI 短剧镜头语言必修课》案例图（古寺山门雨夜高手对打、古代爱情戏廊下灯火眼神拉扯、客厅家庭争吵爆发戏、城阙高台多人三角对峙）。方法用本 skill 的话重新整理。第五、六节依据火山方舟《Doubao Seedance 2.5 提示词指南》与《火山方舟 Seedance 2.5 教程》中的站位、多人、过肩和一致性相关内容写成。

## 一、五步拆解法

四个案例用的是同一套拆法，写对手戏前按顺序想清楚：

1. 导演逻辑：用一句话说出这场戏靠什么成立。例如“用交手瞬间制造冲突，动作方向决定节奏”“不用拥抱，用回头、停顿、眼神完成暧昧感”“站立争吵，肢体动作放大冲突”“三角站位实现多方博弈”。
2. 景别链：从大全景到最终特写排出递进顺序，先交代空间，再切进细节。
3. 关系轴线：在两个对手之间画一条线，确定每个人在画面左还是右、面朝哪边、动作朝哪个方向。
4. 机位图：所有机位放在轴线同一侧，标出机位 1、机位 2 分别拍谁。
5. 正反打：机位 1 越过甲的肩膀拍乙，机位 2 越过乙的肩膀拍甲，两镜中人物的左右位置和视线方向保持一致。

导演逻辑和机位图只在内部规划用，不写进提示词；提示词里写的是它们的结果：画面左右、朝向、视线和越过谁的肩膀。

## 二、关系轴线规则

- 两人戏：轴线是两人之间的连线。机位只在轴线一侧，镜头切换时甲始终在画面左、乙始终在画面右（或相反），视线方向不翻转。
- 视线匹配：甲看向画面右侧，接乙的镜头里乙就看向画面左侧。
- 动作方向：打斗中出拳、推搡、追赶的方向必须与轴线一致。上一镜甲从左向右出拳，下一镜仍是从左向右，否则观众会以为换了攻击方。
- 爱情、文戏同样要锁轴线，防止对望的视线方向错乱；情绪越激烈的戏越不能越轴。
- 多人戏：每两人之间都有一条关系线。先用全景交代整体站位，再切某一对人物的正反打；切到哪一对，就以那一对的关系线为准，机位放在它的同一侧。
- 需要越轴时，按 `references/camera-grammar.md` 的规定交给剪辑，或在两镜之间用一个中性镜头（正对轴线的镜头、环绕过渡）。

## 三、景别链按戏的类型选终点

四个案例都是“大全景 → 中景 → 近景 → 特写”，区别在最后一镜落在哪里：

- 打斗戏：落在动作细节，再到人物表情特写（拳掌相交 → 咬牙的脸）。先交代空间，再快速切进动作细节。
- 爱情戏：落在眼神特写。两人距离越远，眼神越要成为情绪中心。
- 争吵爆发戏：近景是爆发的脸，最终特写可以是情绪化的手部动作（摊开、指向对方的手）。先用全景交代环境，再快速切近景放大情绪。
- 多人对峙：大全景交代三人站位，中景三人同框，近景切到其中两人的局部冲突，最后落在一人的微表情特写。

景别链不是配额，按剧情需要可以跳过某一级；对应规则见 `references/camera-grammar.md` 第二节。

## 四、四种对手戏的写法要点

### 1. 打斗对峙（雨夜对打）

- 导演逻辑：交手瞬间制造冲突，动作方向决定节奏。
- 站位：两人分立画面左右，攻击方向沿轴线。
- 正反打：越过守方肩膀拍攻方出拳，越过攻方肩膀拍守方格挡，两镜中出拳方向一致。
- 与打斗质感引擎衔接：交手瞬间写力量传递和打击反馈（雨水被震散、衣摆甩动）。
- Seedance 2.5 风险：雨、积水属于水相关描述，可能引出音频噪声，需在诊断中预警，并在排除内容里写明不要杂音。

### 2. 情感拉扯（廊下眼神）

- 导演逻辑：不靠拥抱，用回头、停顿、眼神完成暧昧感。
- 站位：一人在廊外、一人在廊内，斜向对望，留出距离。
- 正反打：越过男方肩膀拍女方回头，越过女方肩膀拍男方注视。
- 景别链终点：眼神特写；停顿用镜头长度承载，不用台词填满。
- 光线：写实际光源，如廊下灯笼的暖光照亮侧脸。

### 3. 争吵爆发（客厅家庭）

- 导演逻辑：站立争吵，肢体动作放大冲突。
- 站位：两人隔着茶几或沙发站立对峙，轴线穿过两人。
- 正反打：越过男方肩膀拍女方怒吼，越过女方肩膀拍男方回吼；关键台词后切听者反应。
- 景别链终点：爆发的脸或情绪化的手部动作。
- 与微表情引擎衔接：写眉头、嘴角、颈部青筋、呼吸急促等可见变化。

### 4. 多人三角对峙（城阙高台）

- 导演逻辑：三角站位实现多方博弈，多条关系线同时成立。
- 站位：三人形成三角形，写明谁在顶点、谁在两侧；竖屏时用前后纵深。
- 镜头顺序：先锁空间（大全景、三人同框中景），再切其中一对的正反打。
- 正反打：切哪一对就以那一对的关系线为准，机位不越过这条线。

## 五、官方文档里与场面调度相关的内容

官方文档没有使用“180° 轴线”“越轴”“正反打”这些术语，但给出了实现同一目标的写法和案例。以下逐条列出，均来自《Doubao Seedance 2.5 提示词指南》（下称指南）和《火山方舟 Seedance 2.5 教程》。

1. 站位要单独成段写清：指南“情绪过度响应”案例的提示词有一段“站位设定”，先指定参考图提供空间（“参考图 1”），再逐人写“站在画面右边，面朝画面左侧”“坐在画面左侧过道椅子上，面朝画面右侧”“站在高砚右边，看着高砚”。每人都写了画面左右、朝向、相对位置和看向谁。
2. 每个镜头重复交代左右：同一案例的镜头 1 写“画面左侧是患者甲，画面右侧是站着的高砚和周晚星”，后续镜头写“保持仰角”。也就是第一镜锁定左右，后续镜头声明保持。
3. 身高关系用参照物写：同一案例写“高砚比走廊画面中的门低一个头的距离；周晚星比高砚低”；附录案例写“身高只及机器人胸口”。高低关系不写厘米，写相对参照。
4. 人物关系和贯穿位置写成规则：指南“台词复述引发字幕”案例的“主体与关系”写“全程只有四人；春丫与石头分别搀扶周婆婆左右两侧；林秀兰始终站在周婆婆前方；保持参考人物的身高关系”。
5. 显式要求空间方位和视线方向连续：同一案例的“保持一致”写“保持四名角色的身份、数量、外貌、服装、身高关系、空间方位和视线方向连续”。这是官方文档里与“不越轴”最直接对应的一句。
6. 排除空间跳变：同一案例的“排除内容”写“排除人物换脸、年龄或服装变化、身高突变、角色增减、空间位置跳变和动作顺序混乱”，以及“错误人物发声、多人同时说话、口型错位”。
7. 不说话的人要写明闭口：同一案例写“林秀兰、春丫和石头全程自然闭口，只用眼神和表情回应”，防止对手戏中错误的人开口。
8. 每个时间段写结束状态：同一案例每段结尾写“结束时周婆婆在林秀兰面前站定，春丫和石头仍扶住她”“结束时两人面部清晰可见”。下一段从这个状态接上，站位就不会跳。
9. 过肩镜头的官方写法：指南“多宫格分镜”案例写“中景过肩镜头：少女后背作为前景，男子转头温和看向少女，少女微微低头沉默”。即写清谁的后背作前景、谁看向谁。
10. 镜头行的官方写法：指南“角色对应错误”案例每个镜头写成“镜头 1｜0 秒 - 2 秒：以人物为中心构图，近景，平视，正面机位，日、内，固定。场景。人物动作与台词”。机位用“正面机位”“斜 45 度侧面机位”“侧面机位”描述，构图用“以人物为中心”“三分法”“对称”“局部”“对角线”“斜向”描述。
11. 多人参考素材：按人物首次出场顺序上传并编号，每个素材在文本中绑定（“将图片 1 中的角色定义为秦秀莲”），人多时用清单；不要只在图片上写名字。指南还在约束里写“禁止生成同款分身、双胞胎效果，同一画面中仅保留单个对应角色”。
12. 人数上限：指南建议主体图 1–8 个效果较好，9–12 个稳定性下降；超过 5 个主体时单视图更稳定，多视角要拆成多张图输入。
13. 严格按机位调度生成：分镜图只作大致参考；需要严格时用关键帧（“以图片 x 至图片 x 的顺序作为关键帧”），或用白模视频作为“唯一的运镜、景别变化、主体运动轨迹和镜头调度参考，严格保持镜头顺序、机位变化”。站位和机位要求很严格的对手戏，可以先做白模或关键帧。
14. 复杂任务拆分：指南“复杂任务效果不稳定”写明，一次生成同时承担多项要求时效果不稳定，应拆成多个简单任务分次生成，再后期剪辑。多对人物轮流交锋、站位变化很多的戏应拆段。

## 六、Seedance 2.5 写法

按官方结构写，把上面的规则放进对应位置：

- 素材指代：按人物首次出场顺序编号绑定，并写场景参考图。
- 一句话概述。
- 人物设定：外观锚点和身高关系（用参照物）。
- 站位设定：每人写画面左右、朝向、相对位置、看向谁；写全程不变的关系（谁始终在谁前方）。
- 时间戳情节：每个镜头写成“景别，角度，机位，构图，固定或运镜”，再写站位、动作、表情、台词；过肩镜头写清谁的后背或肩膀作前景；每段写结束状态。
- 贯穿要求：写“保持角色身份、数量、外貌、服装、身高关系、空间方位和视线方向连续”，并写不说话的人闭口。
- 排除内容：空间位置跳变、角色增减、身高突变、错误人物发声、多人同时说话、字幕、背景音乐。

段落标签沿用本 skill 的冒号写法，不用 【】（理由见 `references/seedance-2-5-adapter.md`）。

## 七、姿态与站位锁定（坐 / 站在切镜后错乱）

现象：两人在桌边一站一坐对话，下一镜变成都站或都坐；或站着的人原本在画面左侧，下一镜跑到右侧。

原因：近景、特写只拍到脸和肩，画面里看不出谁坐谁站，模型切镜后会按自己的理解重画姿态和位置；提示词如果只在第一镜写过一次，后面的镜头就没有约束。

官方依据（《Doubao Seedance 2.5 提示词指南》）：

- “情绪过度响应”案例把姿态写进站位设定：“患者甲坐在画面左侧过道椅子上，面朝画面右侧”“高砚站在过道的椅子旁边”；镜头 1 又写“画面左侧是患者甲，画面右侧是站着的高砚和周晚星”。即“姿态＋画面位置＋朝向＋所靠的物体”一起写，并在镜头行里重复“站着的”。
- 同一案例的视频约束写“人物轨迹符合脚本描述”“避免近景变全景”。
- “台词复述引发字幕”案例中姿态变化写成动作：“春丫与石头小心搀扶周婆婆起身”，并写结束状态“结束时周婆婆在林秀兰面前站定”；保持一致要求“空间方位连续”，排除“空间位置跳变和动作顺序混乱”。

解决，按优先级：

1. 站位设定里每个人写四项：姿态（坐 / 站 / 跪 / 靠）、画面位置、朝向、所靠的物体。例如“女人坐在画面右侧的椅子上，面朝画面左侧，双手放在桌面；男人站在画面左侧桌边，面朝画面右侧，一只手撑在桌沿”。（官方写法）
2. 每个镜头行重复姿态，不只写人名：写“画面左侧站着的男人”“坐在椅子上的女人”，近景也写。（官方写法）
3. 用视线高度和机位角度固定姿态：坐着的人看站着的人要抬头，站着的人看坐着的人要低头。正反打时，拍坐着的人用略俯的机位（从站立者的视线高度看下去），拍站着的人用略仰的机位（从坐者的视线高度看上去）。机位角度本身就告诉模型谁高谁低。（推断，与 `references/camera-grammar.md` 的角度规则一致）
4. 过肩镜头利用前景轮廓：越过站着的人的肩膀拍坐着的人时，前景是站立者的腰侧或手臂；越过坐着的人的肩膀拍站着的人时，前景是坐者的头顶和肩膀，镜头略仰。前景露出的身体部位就是姿态证据。（推断）
5. 近景里留一个姿态线索：坐着的人近景带到椅背或桌面，站着的人近景带到身后的门框或墙面高处。（推断）
6. 姿态变化必须写成动作，并写结束状态：“6-9 秒：女人扶着桌沿站起身。结束时两人都站着，女人仍在画面右侧。”没有写这个动作，就不允许下一镜姿态改变。（官方写法）
7. 贯穿要求写“两人的姿态、空间方位和视线方向保持连续”；排除内容写“空间位置跳变、坐站姿态突变、左右位置互换”。（前半为官方写法，“坐站姿态突变”是推断补充）
8. 姿态差异大的正反打放在同一个生成段内完成，不要拆到两段；必须跨段时，用上一段最后一帧作为下一段首帧，或用延长任务接上。（官方能力）

示例（演示写法）：

```
站位设定：男人站在画面左侧的桌边，面朝画面右侧，左手撑在桌沿；女人坐在画面右侧的椅子上，面朝画面左侧，双手交叠放在桌面。两人隔着桌子。
0-3秒：中景，平视，侧面机位，固定。画面左侧站着的男人俯视画面右侧坐着的女人，女人抬头看他。
3-7秒：近景过肩镜头，略俯拍。男人的手臂和腰侧在画面左侧作为前景，坐在椅子上的女人在画面右侧抬头看向画面左上方，椅背在她身后可见。女人台词（克制）：“你到底想说什么？”
7-11秒：近景过肩镜头，略仰拍。女人的头顶和肩膀在画面右侧作为前景，站着的男人在画面左侧低头看向画面右下方，身后是墙面高处的挂画。
贯穿要求：男人全程站着、在画面左侧；女人全程坐着、在画面右侧；保持两人的姿态、空间方位和视线方向连续。
排除内容：排除空间位置跳变、坐站姿态突变、左右位置互换。
```

## 八、正反打的锁轴写法、切镜时机与分段拼接

来源：用户整理的三个短视频教程（“AI 短剧漫剧 180 度轴线”、野生小四“视线轴锁定提示词”、周知遥“1 秒钟解决人物场景一致性”）。这些是创作者经验，不是官方文档；能和官方写法对应的地方已注明。

### 1. 过肩前景按画面位置写，不写左肩右肩

- 反打不是机位跑到另一边，而是在轴线同一侧换观察对象。
- 正反打两镜里，前景肩膀始终留在这个人自己的那一侧：甲在画面左，拍乙时甲的肩膀在画面左侧作前景；乙在画面右，拍甲时乙的肩膀在画面右侧作前景。
- 写成“甲的肩膀和后脑在画面左侧作为前景”，不写“甲的左肩 / 右肩”。哪只肩膀入画取决于人物朝向和机位，写错就会诱导模型把人物转向或镜像。本 skill v1.5–v1.8 示例原先写了左肩、右肩，其中有方向写反的，已改为画面位置写法。

### 2. 空间锚点

- 在两人之间放一个固定物件作为锚点（桌面中央的镇纸、茶杯、棋盘），写明它在画面中的位置，并要求每个镜头都能看到它的一部分，全程不移动。
- 锚点和两人连线一起锁住左右：模型重画镜头时，可以借锚点判断人物在哪一侧。
- 锚点按 `references/scene-prop-continuity.md` 写数量和位置（“画面中始终只有一个镇纸，位于桌面中央”）。锚点只是辅助，仍要每个镜头重复站位。（推断）

### 3. 动作先行，反应完成后再切

- 时序写成“甲做动作 → 乙看动作 → 乙抬眼看甲 → 切镜”，切镜放在反应完成之后，不在动作中途切。
- Seedance 2.5 时间戳只用整数秒，教程里的“停顿 0.4 秒”写成“停顿片刻”或“短暂停顿”，放在同一个时间段内。
- 每段结束状态写到反应完成为止，例如“结束时乙抬眼看向画面左侧的甲”。这与官方案例逐段写结束状态的做法一致。

### 4. 提示词里的“180 度轴线”

- 可以写“机位始终在两人连线的同一侧，正反打切换时不交换人物位置，不镜像画面”，但官方文档没有“180 度轴线”这个术语，模型未必理解它。这句话只作补充，起作用的仍是每个镜头写清的画面左右、朝向和视线方向。（推断）

### 5. 分段拼接：结尾 1 秒技术全景

适用于一场戏需要多个生成段拼接、人物站位在段与段之间漂移的情况，属于批量生产的经验方法，不保证每次成功。

1. 除最后一段外，每段结尾多生成 1 秒全景：所有在场人物同框，站位、姿态、朝向清楚可见，固定机位，无对白、全员闭口。
2. 截取这 1 秒中的一帧静帧，作为下一段的参考图，在素材指代中写“图片 N 只参考人物站位、姿态、朝向和空间关系，不参考景别和构图”。如果担心静帧画质拉低下一段，可以先转成黑白线稿再上传。
3. 剪辑时剪掉每段结尾这 1 秒，再拼接。
4. 下一段第一个镜头的景别要和上一段最后一个非全景镜头不同，避免拼接处跳帧。
5. 官方能力里的对应做法：把上一段最后一帧作为下一段首帧，或用“向后延长”续写（见第七节第 8 条）。技术全景的区别是专门留出一帧信息完整的全景，用作参考图而不是首帧，下一段可以从任何景别开始。

写法：

```
……
14-15秒：全景，平视，正面机位，固定。画面左侧站着的丈夫、画面右侧站着的妻子隔着茶几对视，两人保持不动。无对白，两人自然闭口。
```
生成参数：duration=15（成片使用前 14 秒）
