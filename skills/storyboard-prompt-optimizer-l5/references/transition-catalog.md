# 转场素材库：案例拆解与扩展

需要设计具体转场、写 A 段结尾和 B 段开头时读取本文件。先按 `references/transition-routes.md` 第零节判断这个接缝要不要转场；本文件只提供做法和写法，不决定要不要用。

来源：用户提供的《自制电影转场小教程（5 种电影级转场）》视频总结和用户补充的例子（推拉对接、闪白、画中画、推进入黑等）。逐条对照《Doubao Seedance 2.5 提示词指南》和《Seedance 2.5 教程》。标记：✅ 官方文档有原文或案例；🟡 经验或推断，官方没写，需要试片。

## 一、先看结构：每个无缝转场都是三段

```
A 出口 ──→ 桥 ──→ B 入口
```

- **A 出口**：上一段最后 1–2 秒，画面朝“桥”的状态走：被盖住、变模糊、变暗变亮、形状对准。
- **桥**：切点那一刻的画面。这一帧信息最少（全黑、全白、全火光、全水花、全模糊），或者 A、B 在这一帧里有某个东西完全一样（形状、位置、方向）。
- **B 入口**：下一段开头 1–2 秒，画面从“桥”的状态退出来，是 A 出口的反向动作：A 被盖住，B 就从盖住到露出；A 越甩越快，B 就越来越慢、停稳。

剪辑点一定放在“桥”的那一帧。观众在这一帧没东西可比较，或者看到的东西前后一样，就察觉不到画面换了。

## 二、转场案例逐个拆

### 01 遮挡（暗巷：人物或墙面挡住镜头）

| | 画面 |
|---|---|
| A 出口 | 镜头横移跟拍，前景的墙或路过的人从画面一侧进来，越来越大，盖满画面 |
| 桥 | 一帧全暗、没有细节的画面 |
| B 入口 | 一个颜色、亮度相近的前景物（可以是另一面墙、另一个人的背影）向同一方向移开，露出新场景 |

无缝的原因：
- 遮挡物的**颜色和亮度**前后一致：暗接暗，观众看不出换了东西。
- 遮挡物的**移动方向和速度**前后一致：A 里从右往左盖过去，B 里继续从右往左移开。
- **镜头运动不停**：A 在横移，B 也在同方向横移。
- B 的遮挡物不需要和 A 的是同一个东西，只要颜色和运动对得上。

### 02 火光（城墙篝火 → 山间行军）

| | 画面 |
|---|---|
| A 出口 | 镜头推向篝火，或火焰被风卷向镜头，橙色火光盖满画面 |
| 桥 | 一帧过亮的橙色画面 |
| B 入口 | 画面前景还有橙色光（火把、夕阳、余烬），亮度回落，露出行军的队伍 |

无缝的原因：
- **亮度和色调**前后一致：A 结束是橙色高光，B 开头也是暖色高光，再慢慢降下来。
- B 里有一个**有来由的暖光源**（火把、夕阳）接住这个颜色，不是凭空变亮。
- **意义上的延续**：火从城墙“烧”到了行军路上，把危机感带进下一场。

### 03 形态变换（舞台上长裙舞者 → 翻卷的海浪）

| | 画面 |
|---|---|
| A 出口 | 舞台上，穿长裙的女生旋转、挥动裙摆。裙摆随着舞动越甩越大，从只占画面一部分，到撑满整个画面 |
| 桥 | 画面被翻动的裙摆布面占满，裙摆甩出的弧线和褶皱，正好是浪头翻卷的形状 |
| B 入口 | 同样位置、同样方向翻卷的浪头，布料的褶皱变成水的浪花，浪头落下后露出整片大海 |

无缝的原因：
- **动态轮廓相似**：对上的不只是静态形状，而是**运动轨迹**。裙摆甩出的弧线和浪头翻卷的弧线，方向、弧度、速度都一致。
- **先盖满，再变形**：裙摆先撑满画面，舞台和人物都看不见了，只剩一块翻动的“面”。这时换成浪头，观众没有别的参照物，就看不出换了东西。
- **位置和大小对应**：裙摆的弧线在画面哪里，浪头就从哪里卷起，大小相同。
- **颜色和质感接近效果最好**：例如蓝色或白色的长裙接海浪，柔软的布料接流动的水。
- **意义上的延续**：舞者的情绪像浪一样翻涌出去，用画面代替一句台词。

这一类可以叫“**动态轮廓变形**”：A 里一个在动的东西（布料、头发、烟、沙），轨迹和 B 里另一个在动的东西（浪、火、云、风沙）一致，先撑满画面，再在同一轨迹上换成另一种形态。

### 03-2 粒子解体与重组（战场 → 山谷枯树开花）

| | 画面 |
|---|---|
| A 出口 | 古代战场，两军冲锋拼杀，最后一个士兵被古火炮击中，身体化成一团红雾，红雾散成粒子，向画面左右两侧飞去 |
| 桥 | 不是某一帧，而是一段**跟随运镜**：镜头跟着飞散的粒子移动，画面前景一直是粒子在飞，背景在运镜过程中从战场换成山谷和枯树 |
| B 入口 | 粒子落到枯树的树枝上聚集，重新组成花朵，枯树开花 |

无缝的原因：
- **粒子是贯穿两场的主体**：观众的视线一直跟着粒子，前后有同一个东西在动，注意力不在背景上。
- **运镜过程中换背景**：镜头在动、背景有虚化和位移时，背景从战场变成山谷，观众察觉不到切换点。这和遮挡一样是“盖住”，只是盖住的方式不是挡满画面，而是**把注意力引到前景**。
- **解体和重组是一对反向动作**：A 里一个形态拆散（士兵 → 红雾 → 粒子），B 里粒子聚合成新形态（粒子 → 花朵），符合“B 入口是 A 出口的反向动作”。
- **颜色一路延续**：红雾、红色粒子、红花（红枫），颜色没断过。
- **意义上的转换**：死亡化成花开，把“消逝”转成“传承”或“祭奠”，转场本身在讲故事。

这一类可以叫“**载体跟随转场**”：一个在飞的东西（粒子、花瓣、落叶、飞鸟、火星）当载体，镜头跟着它从 A 场景飞到 B 场景，背景在跟随过程中换掉，载体最后落在 B 场景里，停住或聚合成新东西。

### 04 甩镜

| | 画面 |
|---|---|
| A 出口 | 镜头向一个方向快速甩动（例如向画面右侧），越甩越快 |
| 桥 | 运动模糊最强的那一帧：画面只剩横向拉长的色带，看不清任何东西 |
| B 入口 | 镜头沿同一方向、以相近速度继续甩动，逐渐减速，露出新场景并停稳 |

无缝的原因：
- **在模糊最强时切**：这一帧没有可辨认的细节，等于被模糊“盖住”了。
- **方向和速度一致**：A 向右甩，B 也向右甩，速度接近，模糊拉长的方向相同，观众感觉是同一次甩动。
- **B 入口是 A 出口的反向**：A 加速进入模糊，B 从模糊中减速停稳。
- **颜色接近更好**：两边模糊色带的主色调相近（暖接暖、暗接暗），切点更难察觉。
- 适合：节奏快的场景切换、两地同时发生的事、紧张追逐、喜剧的反差。

写法要点（skill 已有，见 `transition-routes.md` 第三节“甩镜”）：
- 写摄影机的转动方向，例如“摄影机快速向画面右侧转动”，不同时写“背景向左滑动”。
- 跨段时 A 段结尾停在甩动中，B 段开头以同方向的模糊开始，再减速停稳。

### 05 水幕冲刷（洪水中的橡皮艇 → 平静水面上的橡皮艇）

| | 画面 |
|---|---|
| A 出口 | 橡皮艇破浪冲向镜头，浪花扑上镜头，白色水花盖满画面 |
| 桥 | 一帧白色的水花 |
| B 入口 | 水珠从镜头上滑落或水花散开，露出平静水面上的同一艘橡皮艇 |

无缝的原因：
- **同一个主体**（橡皮艇）和**同一种元素**（水）前后都在，只有状态变了：急流变平静。
- 水花朝镜头扑来，B 里水花散开、水珠滑落，**运动方向前后接上**。
- **意义上的转折**：一冲之后，紧张变平静。这是转场在讲故事，不只是换场。

### 05-2 镜头表面覆盖与清除（犯罪片：血溅镜头 → 水冲 → 戴手套的手擦净）

| | 画面 |
|---|---|
| A 出口 | 黑帮处决，杀手近距离开枪，血溅到镜头上，盖住大部分画面，血顺着镜头玻璃慢慢往下流 |
| 桥 | 一层覆盖在镜头表面的东西：先是血，再是一股水流冲上来，血被冲淡冲开 |
| B 入口 | 一只戴橡胶手套的手从远到近伸向镜头，擦拭镜头，镜头变干净，露出清晰的画面，这时人物和场景都已经换了 |

无缝的原因：
- **覆盖层贴在镜头上，不在场景里**：血、水、手都在镜头最前面那一层。只要这一层连续，背后的场景换了，观众也只会觉得“镜头一直在这里”。
- **两次覆盖，层层递进**：血盖住画面，水再把血冲开，镜头始终没有完全露出来，切点可以藏在血和水交替的那一下。
- **清除动作就是 B 的揭示**：手从远到近伸过来，擦一下露出一块干净画面，擦的方向就是揭示的方向，和遮挡转场的“移开露出”是同一个原理。
- **清除动作有来由，还在讲故事**：戴橡胶手套的手像是在“清理现场”，暗示时间过去、事情被掩盖，转场自带剧情信息。
- **情绪反差**：暴力之后接一个干净、平静的画面，冲击力更强。

这一类可以叫“**镜头表面转场**”：东西落在镜头或玻璃上盖住画面（溅、落、起雾、结霜），再用一个动作清除（冲、刮、擦、抹），清除后露出已经换了的场景。

更稳的做法：Seedance 2.5 不一定能理解“镜头表面”。场景里本来有玻璃（车窗、挡风玻璃、窗户、镜子、相框）时，让东西落在这块玻璃上，比写“溅到镜头上”更容易生成正确。（推断，需试片）

### 06 动作匹配：跟拍中换场景（屋顶跳跃 → 林间溪水 / 月球宇航员）

| | 画面 |
|---|---|
| A 出口 | 侧面中远景跟拍，人物在屋顶上奔跑跳跃，始终在画面中间，镜头和人物同速横移 |
| 桥 | 人物跳起后在空中的那一下，或落地踩实的那一下 |
| B 入口 | 同样的景别、机位高度和横移速度，人物落在林间溪水的石头上继续跑；或者换成宇航员在月面上同样跳起、落下 |

无缝的原因：
- **主体锁在画面同一位置**：人物始终在画面中间，大小不变，观众盯着人物看，背景成了“陪衬”，换掉也不突兀。
- **运动不断**：镜头横移的方向和速度、人物跳跃的弧线前后完全一致，动作没有中断。
- **切点选在动作的节拍上**：
  - 空中最高点：人物悬在空中、身体舒展，背景因为横移有动态模糊，最适合换背景；
  - 落地瞬间：脚踩实地面是一个重拍，适合配合脚步声做硬切。
- **可以换背景，也可以连人一起换**：
  - 同一个人换地点（屋顶 → 溪水）：讲赶路、穿越距离；
  - 换成另一个人做同一个动作（跑酷少年 → 宇航员）：姿态和轮廓对上就行，讲对照、想象或幽默。
- **速度差可以变成效果**：宇航员在月球低重力下落得更慢，起跳和 A 一样，落地变慢，这个反差本身就有趣。

#### 例子二：进球后空翻 → 校门口蹲下系鞋带

| | 画面 |
|---|---|
| A 出口 | 镜头跟拍球员带球过人、射门、进球、庆祝，球员起跳后空翻；人在空中时，镜头跟着人物一起旋转 |
| 桥 | 旋转中的那一下：画面整体在转，背景是一片动态模糊 |
| B 入口 | 旋转停下，人物落地屈膝蹲下，这时已经在学校校门口，蹲着系鞋带 |

这个例子比跳跃多了两层：
- **镜头跟着旋转**：背景整个转成模糊，比横移更“盖得住”，换场景完全看不出来（盖住 + 运动，同第四节第 12 种“旋转接旋转”）。
- **落地姿态接上新动作**：后空翻落地是屈膝下蹲，系鞋带也是蹲着，**两个不同的动作共用同一个姿态**，所以动作没有断。这叫“姿态对接”：找 A 动作的结束姿态和 B 动作的起始姿态一样的地方来切。
- **意义上的反差**：赛场的高光一落地变成普通的上学日常，可以是白日梦醒来、回忆起点，或“多年以前”。

和 skill 已有的动作匹配的区别：已有写法是“下一镜从上一镜动作的同一阶段接着做”，主要用于同一场景换景别；这一类是**主体和动作锁住，只换背景（或换人）**，用于换场景。

### 07 推近与拉远对接（旋转的唱片 → 飞驰的 F1 车轮）

| | 画面 |
|---|---|
| A 出口 | 唱机上一张唱片在旋转，镜头慢慢推近，直到旋转的唱片盖满整个画面 |
| 桥 | 一帧被旋转的圆形纹路占满的画面：只能看到一圈圈在转的纹理和反光 |
| B 入口 | 画面里还是同样在转的圆形纹理，镜头拉远，才发现是赛道上 F1 赛车的车轮，最后拉出整辆赛车在飞驰 |

无缝的原因：
- **推近和拉远是一对反向动作**：A 推到底，B 从底拉出来，正好对上“B 入口是 A 出口的反向动作”。
- **桥那一帧只有“局部”**：推到盖满时，观众看不到唱片的边缘和唱机，只剩旋转的纹理，分不清是唱片还是车轮。
- **形状、运动、质感三项都对上**：都是圆形；都在旋转，方向和速度一致；唱片的纹路和反光接轮毂、轮胎的纹路和反光。
- **尺度反差制造惊喜**：从桌上的小物件拉成飞驰的大赛车，观众“以为是 A，其实是 B”，这一下的意外就是看点。
- **节奏也能接上**：唱片的音乐可以继续，接上引擎的轰鸣，或者音乐节拍对上换挡声（声音跨过切点）。

这一类可以叫“**推拉对接**”：A 推近到某个局部盖满画面，B 从一个形状、运动、质感都相似的局部拉远，揭开完全不同的东西。

注意：推近有两种拍法，一种是镜头真的往前移（推镜），一种是镜头不动、只变焦。两种都可以，但一段里只写一种，不混用（skill 已有规则）。

### 07-2 推进入黑（吼叫的嘴 → 黑场 → 拉出新场景）

| | 画面 |
|---|---|
| A 出口 | 中景或近景，正面拍人物仰头嘶吼；镜头持续推进，越过脸部，推到张大的嘴，再推进嘴里；嘴里没有光源，画面随推进越来越暗，直到全黑 |
| 桥 | 一帧全黑：没有任何细节 |
| B 入口 | 从全黑开始，镜头向后拉远，黑色是新场景里一个暗的开口（隧道口、山洞、井口、黑暗的门洞、深夜的窗），拉出后露出新场景；或者新场景里的灯一盏盏亮起 |

无缝的原因：
- **推进和拉远是一对反向动作**：和 07 一样，A 推到底，B 从底拉出来，B 入口是 A 出口的反向动作。
- **黑就是“盖住”**：和 01 遮挡一样，全黑时观众什么都看不到，剪辑点藏在黑里。
- **黑有来由**：嘴里本来就没有光，推进去变黑是“合理的黑”，不是凭空淡出；B 那边从暗处拉出来，黑也有来由。
- **它是 08 闪白的反面**：闪白用强光盖成全白，这里用无光盖成全黑，前后两边的黑一样深。
- **情绪有出口**：吼叫推到最满时戛然变黑，情绪被“吞掉”，再拉出的新场景往往是情绪的后果（被困的人、空荡的街、多年以后），落差就是看点。
- **声音可以跨过切点**：吼声延续到黑里再衰减，或在全黑那一下突然静音，B 段从安静或新场景的环境声起。

写法要点：
- 推进有两种：镜头真的往前移（推镜），或镜头不动只变焦。一段里只写一种，不混用。
- 写清全黑的秒数和到达画面，用整数秒：“第 5 秒镜头推进嘴里，画面完全黑场；第 6 秒镜头从隧道口向后拉出，露出……”。全黑不写持续好几秒。
- A 段结尾写“结束时画面完全黑场”，B 段开头写“画面从黑暗中开始，镜头向后拉出”，两段桥上的画面写成一样的句子。
- B 段第一帧要求“全黑”不一定能生成准确。更稳的做法是：B 段开头写镜头在隧道、山洞这类暗处，再向外拉；或者由剪辑在两段之间加几帧黑，写进“剪辑建议”。（推断，需试片）
- 也可以用方式 3（视频无缝转场任务）把两段接起来。

风险：
- **写实画风推进嘴里风险高**：牙齿、舌头、口腔内部容易生成得怪异甚至恐怖。动漫、二次元风格更自然。写实剧的替代做法：推进到人物身后的门洞、衣服的暗处、人物用手捂住脸的掌心，同样推到全黑。（推断，需试片）
- **不推进眼睛**：同理不要改成推进瞳孔，容易让眼睛发光变形；情绪相关防护按 seedance-2-5-adapter.md 第六节。
- 嘴张得过大、下巴变形属于人物形变：写成“张大嘴嘶吼，面部五官比例正常”。（经验）
- 甲方剧本：剧本有嘶吼、崩溃，且两场之间需要转场时才用；剧本没写转场默认硬切，用这个只能作为建议。

### 08 闪白

| | 画面 |
|---|---|
| A 出口 | 场景里的强光（车灯、闪光灯、窗外的太阳、闪电、爆炸的火光）迅速亮起，把画面照到全白 |
| 桥 | 一帧全白：没有任何细节 |
| B 入口 | 从同样的全白开始，曝光逐渐恢复，露出新场景 |

无缝的原因：
- **全白就是“盖住”**：和黑场一样没有细节，只是方向相反，用亮来盖。
- **前后的白一样**：A 结束的全白和 B 开始的全白亮度相同，观众感觉是同一次闪光。
- **B 入口是 A 出口的反向**：A 越来越亮，B 越来越暗回正常曝光。
- **光有来由**：强光必须是场景里本来就有的光源，不是凭空变白。

写法要点：
- 全白要短，用整数秒写成“第 5 秒强光把画面照成全白，第 6 秒曝光恢复，露出……”，不写持续好几秒的白。
- 只闪一次，不频闪：排除内容写“频闪、反复闪烁”。
- 光从光源照过来，不从人物身上发出：不写“人物发光”，情绪相关防护按 seedance-2-5-adapter.md 第六节。
- B 段第一帧要求“全白”不一定能生成准确。更稳的做法是：B 段开头写镜头对着强光、过曝，再恢复；或者由剪辑在两段之间加几帧白，写进“剪辑建议”。（推断，需试片）
- 适合：惊醒、闪回开始或结束、爆炸冲击、拍照定格、车祸、强烈的情绪冲击。

### 09 画中画（拉出屏幕）

| | 画面 |
|---|---|
| A 出口 | A 的视频内容铺满整个画面，正常播放 |
| 桥 | 镜头开始连续后拉，屏幕边框从画面四周慢慢露出来 |
| B 入口 | 继续后拉，露出屏幕周围的新场景（客厅里看电视的人、监控室、手机拿在谁手里），屏幕里的 A 仍在播放 |

无缝的原因：
- **A 一直没停**：屏幕里的原视频持续播放，不定格、不变形，观众感觉画面没被切断，只是“退后了一步”。
- **后拉是连续的一个动作**：没有切点，揭示是一点点完成的，先看到边框，再看到屏幕外的世界。
- **意义上的翻转**：观众以为在看 A 这件事本身，拉出来才发现是有人在看 A。A 变成了 B 里的“证据、新闻、回忆或监控”。

写法要点：
- 屏幕里只写画面，不写任何文字、台标、进度条或界面按钮（默认规则“不要字幕、水印文字”；用户明确要求出字时按 SKILL.md 覆写该段）。
- 写明“屏幕里的画面持续播放，不定格，不变形”，并写屏幕的形状和位置（例如“画面中央的电视屏幕”），防止屏幕被拉成歪斜的梯形。
- 后拉写成整数秒的连续过程，例如“0-2 秒画面被监控画面铺满，2-5 秒镜头连续后拉，第 3 秒露出显示器边框，第 5 秒露出监控室和坐在屏幕前的陆远”。
- 屏幕里要放和 A 完全一样的内容，最稳的做法是剪辑合成：B 段生成一块播放着画面的屏幕，剪辑时把 A 的视频贴进屏幕。Seedance 2.5 能否直接把参考视频 1 放进屏幕里播放，官方文档没写，需要试片。（推断）
- 适合：新闻、监控、视频通话、录像证据、看回放、回忆被打断。

## 三、归纳：让剪辑点消失的六个“对得上”

一个转场至少要有一项对得上，越多越无缝：

| # | 对得上什么 | 例子 |
|---|---|---|
| 1 | **盖住**：桥那一帧没有细节 | 遮挡、火光、水花、黑场、闪白、全模糊 |
| 2 | **运动**：方向和速度前后一致 | 横移接横移、甩镜接甩镜、人物向右出画接向右入画 |
| 3 | **形状和位置**：轮廓相似，画面位置和大小相同；在动的东西还要**运动轨迹**相同 | 裙摆的弧线接浪头翻卷、圆饼干接满月 |
| 4 | **亮度和颜色**：桥两边的明暗和色调相同 | 橙色火光接夕阳、暗墙接暗背影 |
| 5 | **元素或主体**：同一种东西前后都在 | 同一艘船、同一种水、同一个杯子 |
| 6 | **声音**：声音跨过切点 | 声音先入、声音后留（skill 已有） |

另外几条规律：
- **B 入口是 A 出口的反向动作**：盖住对应露出，加速对应减速，推进对应继续推进或拉出。
- **桥要有来由**：遮挡物、火、水、雾在 A 或 B 的场景里本来就有。
- **转场带意义更好**：火把危机带到下一场，水把紧张冲成平静，裙摆变海浪把情绪“甩”出去。
- **形状差太多时加一层介质**：雾、烟、尘、粒子、虚焦，只留轮廓，盖掉细节。
- **姿态对接**：A 动作的结束姿态和 B 动作的起始姿态一样时，两个不同的动作也能接上（空翻落地的蹲姿接系鞋带）。
- **用载体带走视线**：前景有一个一直在动的东西，镜头跟着它走，背景就可以在运镜过程中换掉。

## 五、在 Seedance 2.5 里怎么实现

| 方式 | 做法 | 依据 |
|---|---|---|
| 1. 同一生成段内 | 两个场景都在这一段里时，写清时间点、方式和到达画面，例如“第 8 秒篝火的火焰被风卷向镜头，盖满画面；第 9 秒火光散开，山道上行军的队伍完整可见” | ✅ 官方“第 5s 快速向左横移转场”的写法；元素遮挡是 🟡 |
| 2. 两段在桥上切（推荐） | A 段最后 1 秒停在桥的最满状态（火光盖满、水花扑满）；B 段第 0–1 秒从桥的最满状态退出来。剪辑时在两段的桥上对接 | 🟡；B 段开头的“全火光、全水花”可能生成不满，需要试片 |
| 3. 视频无缝转场任务 | 上传 A、B 两段，写清 A 怎么离开、用什么过渡、B 怎么到达 | ✅ 官方案例“麻将牌慢慢变成高楼”，最适合形态变换 |
| 4. 首尾帧桥接 | A 段末帧作首帧，B 段首帧作尾帧，生成一段短过渡 | ✅ 官方首尾帧能力；两张图画幅必须一致 |

动态轮廓变形（03 类）更适合方式 3 或方式 4，写法示例（方式 3）：

```
将视频1和视频2衔接起来，视频1中舞者旋转时长裙的裙摆越甩越大，第 2 秒裙摆的布面撑满整个画面，裙摆甩出的弧线沿同一方向翻卷，布料的褶皱逐渐变成浪花，无缝自然地衔接转场到视频2中翻卷的浪头。同时不要改变上传的两个视频。
```

载体跟随（03-2 类）写法示例（方式 3，两段分别生成后用无缝转场任务衔接）：

```
将视频1和视频2衔接起来，视频1中士兵被炮火击中后化成一团红色的雾气，雾气散成红色粒子向画面左右两侧飞去，镜头跟随粒子向画面右侧移动，跟随过程中背景从战场无缝自然地衔接转场到视频2的山谷，粒子飞到枯树的树枝上聚集，变成红色的花朵。同时不要改变上传的两个视频。
```

- 粒子要写成“红色粒子、红色的雾气”这类可见的东西，不写“发光的光点”，以免整片画面泛光。（经验）
- “血雾”“炸碎”这类写法可能触发平台审核，写成“红色的雾气”。剧本原文的情节保留，只换提示词里的描述方式。（推断，需试片）

动作锁定换背景（06 类）写法示例（方式 2，两段分别生成，剪辑时在空中最高点对接）：

```
A 段 10-12秒：中远景，侧面机位，镜头与人物同速向画面右侧横移跟随。林川在屋顶上奔跑，第 11 秒踩着屋檐起跳，身体在空中舒展，始终在画面中间，结束时人物仍在空中最高点。
B 段 0-2秒：中远景，侧面机位，镜头与人物同速向画面右侧横移跟随。林川在空中最高点，身体舒展，始终在画面中间，第 1 秒落在林间溪水中的石头上，溅起水花，继续向画面右侧奔跑。
```

- 两段的景别、机位高度、横移方向和速度、人物在画面中的位置和大小写成一样的句子。（经验）
- 两段的光线方向尽量一致；想要反差（白天屋顶接夜晚月面）时，用落地瞬间硬切，不在空中慢慢换。（经验）
- 同一生成段内写“空中背景从屋顶变成溪水”风险高，模型可能把两个场景混在一起，优先分两段生成再剪辑。（推断，需试片）

推拉对接（07 类）写法示例（方式 2）：

```
A 段 10-13秒：特写，正面俯视机位，镜头缓慢向前推近唱机上顺时针旋转的黑色唱片，第 12 秒唱片盖满整个画面，只看得到一圈圈旋转的纹路和反光，结束时唱片仍在顺时针旋转并盖满画面。
B 段 0-4秒：特写，侧面机位，画面被顺时针高速旋转的黑色车轮盖满，纹路和反光在转动，镜头快速向后拉远，第 2 秒看清是赛道上 F1 赛车的车轮，第 4 秒拉出整辆赛车向画面右侧飞驰。
```

- 两段桥上的画面写成一样的句子：颜色、旋转方向、盖满画面的状态。（经验）
- 唱片的旋转方向和车轮的旋转方向要一致，否则切点处会“倒转”一下。（经验）

推进入黑（07-2 类）写法示例（方式 2，动漫风格）：

```
A 段 8-11秒：近景，正面平视机位，林川仰头张大嘴嘶吼，面部五官比例正常，人物为正常人眼、不发光。镜头匀速向前推进，第 9 秒嘴部盖满画面，第 10 秒镜头推进嘴里，画面逐渐变暗，结束时画面完全黑场。
B 段 0-3秒：画面从黑暗中开始，镜头匀速向后拉出，第 1 秒看清是废弃隧道的出口，第 3 秒拉出隧道外空荡的雨夜街道。
```

- 两段的推、拉速度写成一样的“匀速”。（经验）
- 吼声可写在 A 段的 {} 台词或 <> 音效里，B 段开头写“<安静>”或新场景的环境声。（经验）

提示词写法示例（方式 2，A 段结尾和 B 段开头）：

```
A 段 13-15秒：近景，镜头缓慢推向城墙上的篝火。第 14 秒一阵风把火焰卷向镜头，橙色火光盖满整个画面，结束时画面完全被火光占满。
B 段 0-2秒：全景，画面前景是行军队伍举着的火把，橙色火光从画面前景向两侧散开，第 1 秒山道上行军的队伍完整可见，镜头继续缓慢向前推。
```

## 六、用在甲方剧本上的限制

- **桥必须是剧本里本来就有的东西**：剧本写了篝火，才能用火光转场；剧本写了下雨，才能用水面转场。剧本没有的火、浪、烟、倒影，不能为了转场加，否则等于新增剧本内容，审片对不上。只能在诊断里写成建议，由用户决定。
- **剧本没写转场时默认硬切**，不为炫技加转场。
- **暴力画面要换描述方式**：“爆头”“血液飞溅”可能触发平台审核，提示词里写“枪声响起的同时切走，红色液体溅满镜头”，不拍中弹的瞬间。剧本里的情节保留，只换提示词的描述。戴手套擦拭这类清除动作，剧本没写的属于新增内容，只能作为建议。
- **粒子解体、花开这类特效是拍法上的加工**：剧本写了士兵阵亡，用粒子表现可以算拍法；但“枯树开花”如果剧本没写，就是新增内容，只能作为建议，由用户确认后再用。
- **不打乱剧本顺序**：转场只改两场之间怎么接，不改哪场在前。
- **屏幕、照片、纸面上默认不出现文字**：排除内容默认保留“不要字幕、水印文字”，屏幕推入时屏幕里只写画面；用户明确要求某段出字时，按 SKILL.md 的覆写规则只改该段这一条。参考图上的字在出场景图、道具图时管控。
- **不推进人物眼睛**：“推进瞳孔转到回忆”这类写法容易让眼睛发光变形，改用虚焦或倒影。
- 两段的画幅、光线时段、镜头运动方向要一致。
