# 常用制作核心

来源：将既有项目规则和制作经验收拢为普通任务的工作集；不是新增模型硬限制。确认、剧本覆盖和交付范围只按 SKILL.md。下述方法足够解决时不再读详细库；具体困难按入口路由查对应章节。模型参数、素材绑定、时间戳、声音符号与排除注入只按适配模块。

## 选镜、运镜与光影

- 先确定本镜主要观看任务、关系和观众何时知道信息，再选拍谁、多近、从哪里拍。允许已有对白、动作、反应同时发生；不按信息条数强制拆镜。说话者、倾听者或已有道具均可承载镜头，单人独白不新增听者。原稿锁定的镜头意图优先。
- 普通镜头一个主导运镜，写清起点、剧情触发、方向/速度、终点与切点状态。变焦可以选用：固定观察位置、焦距改变、取景收窄或放宽；推拉是摄影机移动并改变前后景透视，移焦是清晰主体交换。不要混称。原稿明确的希区柯克变焦、组合或一镜到底保留，按复杂运镜路由写清连续路径与先后，不能注入相反的排除句。景别随连续推近/变焦自然变化不等于多景别跳切。
- 写实机位路径检查墙、家具、层高和退路；特殊穿梭按授权风格写清进出。手持/无人机只是设备，仍需路径。静止人物且焦距不变时，推近不能同时要求人物大小不变。
- 光线写物理事实：场景光源在哪里、照亮哪里、阴影落在哪里；根据光源高低和软硬描述阴影及接触阴影，不堆形容词。场景光源固定，镜头反打后画面受光方向按机位换算。贯穿状态只写一次，各镜只补变化或不同机位的光向。
- 画幅参与构图；不要在窄竖屏并排挤多人。浅景深、透视和背景虚化写可见效果。剪辑叠字、音轨移动等后期事项放框外。

## 空间、人物与道具

- 两人以上先在内部定导演逻辑、景别链和关系轴，普通正反打机位保持在关系轴同侧。每人明确姿态、画面左右、房间地标、朝向与看向谁；过肩说清谁的哪侧背肩在前景，保留坐站的可见线索。
- 一场戏多个生成段时，场景空间锁逐段复用，只写实际空间与地标，不写画面左右。多机位另列本段机位，用地标确定观察方向，再为该镜换算画面左右、视线和光向。文字必须与参考图一致；无法从进入状态走到的终点不可直接写成已到达。
- 每段维护进入→变化→离开状态，覆盖位置、姿态、视线、占手、道具持有者及声音。下一段直接复述本段需要的进入事实，不写“承接上一段”。计划尾帧与实际验看的尾帧分开；返修或跨集依赖按 project-state.md 记录。
- 场景图已有的道具绑定为同一物体，不再生一件；多个同类物体用地标/特征命名。交接写谁先持有、哪只手、接触/释放过程和最终持有者，避免同一只手同时做两件事。首帧没有的必要物体交代何时从哪入画；静物只在有风险时说明保持原位。
- 实际空间、画面左右、人物自身左右各有参照；手别不能拿画面左右代替。移动写路线和结束位置。保持已在场、在场画外、已离场的区别；揭示前不提前让观众或角色看到信息。
- 制作资产或使用复杂参考才查资产库；已有简单角色和场景图可直接按适配模块绑定。不能假称已看过未提供的素材，空间冲突不得靠隐藏切点掩盖。

## 表演、声音与时间负载

- 表演从已有目标和策略转为可见行为；近景通常取视线、呼吸和一处细小变化，不堆全部情绪信号。变化要有已有剧情触发；原稿的爆发、僵住、沉默、持续状态照做，不强制渐变、回落、流泪或流汗。倾听反应随信息到达发生，不统一延到整句结束。
- 动作有与材质、重量、方向相容的物理反馈，不等于一律增加疼痛表情、尘土或火花。关键交接和改变局面的动作写清动作前事实、发起/触发、接触与结果；普通动作不逐项展开。跨镜头接着已有动作阶段做，不从头起手。
- 普通对白防错误角色发声，原稿的交叠、齐喊、抢话保留。声线优先绑定音频；没有音频按入口的文字设计政策；同一角色跨段复用同一句声线，当下语气写在台词标签。段内切镜可以不断声，画外说话标人名画外音，不复述台词。
- 先算台词、动作和表演时长，可同时发生的不重复计时，再加转场与空镜。普通语速约每秒4字、舒缓约3字是估算，不是硬上限。余量为正且保留剧情停顿为“够用”；需压缩自己加的停顿为“勉强”；原稿放不下为“不够”，后两者查时长参考文件。不能靠加速吞词或删停顿凑时长。
- 接缝默认连续或硬切；从原剧本已有的位置、姿态、动作阶段、地标和声音衔接，不能自动新增特殊桥接。原稿特殊转场照做，新增技术全景、关键帧或升级转场须先授权。长镜头与切点保留；长台词覆盖、复杂跨段音轨难题再查专项。

## 交付前内部检查

对实际稿件核对：原稿逐次覆盖、未授权新增与模型额外重复、全部段号及范围、参数有效、时间戳连续、台词字序与时长、素材映射、空间/机位/光向、动作起终状态及物理反馈、声线与说话人、相邻段接续、适用排除条目。特殊任务按已读取的专项做检查。只报告查出的缺陷、处理与未决项，不因无问题而生成整份诊断。
