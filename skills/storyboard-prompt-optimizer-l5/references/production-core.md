# 常用制作核心

来源：既有项目方法，非模型硬限制。政策按 SKILL.md；基础方法够用不读详细库，具体困难查命中章节。参数、绑定、时间戳、声音格式、排除注入按适配模块。

## 选镜、运镜与光影

- 先定观看任务、关系和揭示时点，再选主体、景别与机位。已有对白、动作、反应可并行，不按信息条数拆镜。说话者、听者或已有道具可承载镜头，独白不加听者；原稿镜头意图优先。
- 普通镜头一个主导运镜，写起点、触发、方向/速度、终点与切点状态。变焦固定观察位置、改变取景；推拉移动摄影机、改变透视；移焦交换清晰主体，不混称。原稿希区柯克变焦、组合或一镜到底保留，按复杂运镜路由写路径与先后，不注入相反排除。连续推近/变焦导致景别变化不算跳切。
- 写实机位路径检查墙、家具、层高和退路；特殊穿梭按授权风格写清进出。手持/无人机只是设备，仍需路径。静止人物且焦距不变时，推近不能同时要求人物大小不变。
- 光线写光源位置、照亮处与阴影落点，按高低、软硬描述阴影及接触阴影。光源在场景中固定，反打按机位换算光向；贯穿只写一次，各镜补变化，不堆形容词。
- 画幅参与构图；不要在窄竖屏并排挤多人。浅景深、透视和背景虚化写可见效果。剪辑叠字、音轨移动等后期事项放框外。

## 空间、人物与道具

- 两人以上先在内部定导演逻辑、景别链和关系轴，普通正反打机位保持在关系轴同侧。每人明确姿态、画面左右、房间地标、朝向与看向谁；过肩说清谁的哪侧背肩在前景，保留坐站的可见线索。
- 一场戏多个生成段时，场景空间锁逐段复用，只写实际空间与地标，不写画面左右。多机位另列本段机位，用地标确定观察方向，再为该镜换算画面左右、视线和光向。文字必须与参考图一致；无法从进入状态走到的终点不可直接写成已到达。
- 每镜从当前状态写触发→动作→结果：位置、坐站、身体朝向、头向/视线、占手与持物分开；转头不自动带动椅子或换位。对象变化后决定保持、回转或转向新目标，按几何写必要动作，不统一复位。切镜只换观察；非主体与画外人物仍按事件更新，重新入画复述关键状态。转向、进出场或多人变化读 execution-flow.md 第八节。跨段复述进入事实，不写“承接上一段”；计划与实际尾帧分开，返修按 project-state.md。
- 场景图道具绑定为同一物体；多个同类物用地标/特征区分。交接写递出者、接收者、接触、谁释放及最终持有者；交互换主语时写人名，单义代词可留。手别按已定站侧设计，不把可自定制作项交用户，不让同一手同时做两事。首帧缺少的必要物体写何时从哪入画；静物只在有风险时锁原位。
- 手机、平板、照片、信件、文件、证件这类有正反面或可被展示的物件，原稿需要展示时照做；不需要时写清屏幕或正面朝向谁、观众能看到多少，不自行加特写、推近、翻面或界面内容；正反面关系不明时不自选（v1.39，由 camera-grammar.md 揭示一节“书页、照片、手机屏幕先确认正面朝谁”提升到默认核心，并参考防污染 skill v0.1.3 RC）。
- 方位按三原则核对：参照明确、图文一致、时序可达。实际空间、画面左右、人物自身左右各有参照；手别不能拿画面左右代替。移动写路线和结束位置。保持已在场、在场画外、已离场的区别；揭示前不提前让观众或角色看到信息。
- 复杂资产才查资产库；简单角色和场景图按适配模块绑定。未提供的素材不称已看。结构冲突不靠切镜掩盖；省略剪辑可省非关键路程，需起点、同一通路与到达落点可辨，不能把连续镜头瞬移解释成省略。

- 场景图控制固定结构：按图中墙、门洞、窗、柜台和通道建立对应，再换算机位左右。门洞、门叶与面板分格分开识别，不凭旧稿定门型/开向。正反图先统一方向；俯视图只推导已有结构。画外或遮挡处保持未知，不为动作补门窗、出口或通道。修复图与旧图冲突时，结构以用户确认的修复图为准，人物/构图按各自有效参考，上传清单同步版本。（v1.41 项目约定，分支补充设施识别，非模型能力保证）
- 操作固定设施按“起点→通路→到达目标→接触施力→结果”；绕柜端只是进入通路，不等于到达。运镜沿用已定结构，不把画外手势变成新门窗。按已见把手定操作目标，写操作者到位、手、接触、避让与停稳；未操作且无外力的门叶保留原态。连续拍摄按距离估时；省略剪辑明确切点、去向与到达状态。容量不足调整节奏或拆段，不借瞬移或新增近处目标省时。（v1.41 项目约定，分支修正）

## 表演、声音与时间负载

- 表演从已有目标和策略转为可见行为；近景通常取视线、呼吸和一处细小变化三选一，不堆全部情绪信号。变化要有已有剧情触发；原稿的爆发、僵住、沉默、持续状态照做，不强制渐变、回落、流泪或流汗。倾听反应随信息到达发生，不统一延到整句结束。微表情只写在已有触发之后的一个细小变化里，不单独占一个时间段，不连续多个时间段都用微表情拖时间，不用来填补台词和动作之间的空档；没有触发、没有台词、没有动作的纯表情段视为无来源时长，须缩短本段或标待确认，不得直接写入提示词。
- 普通问答中，倾听时完成自然抬眼、转向与理解反应；对方完整说完后正常换气接话，切镜可跟随开口，或由既有动作承载，不默认先给接话者一段无声凝视。稳重、克制、电影感不自动转成慢抬头、长停顿或句后定住；逐句按实际语速与动作估时，缩短无依据的等待，不为填满时长拉长反应。原稿明确的沉默、迟疑、抢话、爆发、固定机位及长镜头分别保留，不能用统一的“立即接话”覆盖。（v1.41，用户2026-11-02节奏反馈；文本方法尚非出片保证）
- 动作有与材质、重量、方向相容的物理反馈，不等于一律增加疼痛表情、尘土或火花。关键交接和改变局面的动作写清动作前事实、发起/触发、接触与结果；普通动作不逐项展开。跨镜头接着已有动作阶段做，不从头起手。
- 普通对白防错误角色发声，原稿的交叠、齐喊、抢话保留。声线优先绑定音频；没有音频按入口的文字设计政策；同一角色跨段复用同一句声线，当下语气写在台词标签。段内切镜可以不断声，画外说话标人名画外音，不复述台词。普通短语气继续写在台词标签里；一句台词内有复杂变化（渐快、渐尖、由颤到稳）、跨镜续说，或已知同类说明被念出时，才拆成与台词分开的短控制，例如“声线控制（苏青，5-18秒）：起句轻颤，语速渐快”，不写成紧挨台词的叙述句，也不和标签重复描述；原稿台词里本来就有的字照原样保留（v1.39，项目实测：第60场“越来越急、越来越尖”被念出；官方指南：台词后复述并追加语气易诱发字幕）。
- 先算台词、动作和表演时长，可同时发生的不重复计时，再加转场与空镜。普通语速约每秒4字、舒缓约3字是估算，不是硬上限。余量为正且保留剧情停顿为“够用”；需压缩自己加的停顿为“勉强”；原稿放不下为“不够”，后两者查时长参考文件。不能靠加速吞词或删停顿凑时长。
- 接缝默认连续或硬切；从原剧本已有的位置、姿态、动作阶段、地标和声音衔接，不能自动新增特殊桥接。原稿特殊转场照做，新增技术全景、关键帧或升级转场须先授权。长镜头与切点保留；长台词覆盖、复杂跨段音轨难题再查专项。首尾帧难直连且拟采用反应补镜时，按 transition-routes.md 路线 5 判断适用、授权及两侧接缝验收；不作为普通接缝默认做法。
- 第二集起，原稿连续接续时直接接住上集结尾，不自行添加前情回顾；原稿已有回顾、跳时或另起场景仍按原稿保留，不强行改成连续。

## 交付前内部检查

对实际稿件核对：原稿逐次覆盖、未授权新增与模型重复、段号及范围、参数、时间戳、台词字序与时长、素材映射、空间/机位/光向、动作起终及物理反馈、声线与说话人、接续、适用排除。逐镜核对所有影响接续的人物，再核跨段；对象变化后的头身朝向、重新入画状态、入场起点/门槛/落点、交接主体、全程锁与局部动作是否矛盾，按 execution-flow.md 第八节检查。另核问答拖慢、门窗图文对应、素材版本同步；文本与视频分别记录。只报告缺陷、处理与未决项，不列无问题诊断。
