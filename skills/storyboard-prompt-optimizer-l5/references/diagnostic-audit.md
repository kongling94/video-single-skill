# 完整诊断分类

仅在用户要求完整诊断、评分或规则审计时读取。普通交付按 SKILL.md 和 production-core.md 核对并只报告实际问题。这里是风险检索目录，不另设槽位、交付或删改规则；遇到缺失参数按入口的确认政策处理。评分只在用户要求时输出，按适用维度评分，不适用项不评分。


按任务适用性检查原始分镜：

1. 已有优点
2. 缺失参数
3. 模糊表述
4. 目标 AI 适配风险
5. 版权 / 肖像权 / 合规风险
6. 模型常见硬伤风险
7. 流畅性风险
8. 物理自洽风险
9. 光影阴影风险
10. 微表情风险：是否存在缺少必要表演依据、无理由呆滞、无触发的情绪跳变、情绪与动作矛盾、眼神无焦点、呼吸不匹配、无依据的泪液汗液、声音表情错误
11. 打斗质感风险：是否存在攻防无逻辑、击中无反馈、力量传递缺失、呼吸不匹配、脚步不动、衣摆静止、兵器无重量、格挡无后坐力、闪避像平移、倒地无尘、节奏匀速、无停顿、无眼神、无收招
12. 诊断评分：结构 / 镜头语言 / 主体细节 / 光影 / 阴影 / 微表情 / 打斗质感 / 音频 / 反提示词 / 流畅性 / 物理自洽，各 0-10 分
13. Seedance 2.5 专项风险（目标 AI 为 Seedance 2.5 时）：时间戳是否为连续整数秒、单段内容密度是否与时长匹配、是否用时间戳控制频率、素材指代与出场顺序是否一一对应、任务类型与 ratio/duration 是否冲突、台词写法是否容易诱发字幕、是否含水/波浪/回音等易致音频噪声的描述、是否有强烈情绪词落到眼睛上导致发光、是否含真人人脸参考素材、画面文字是否有拼写风险、时间段里是否单独用“图片 N”当主语、多素材时是否缺本段参考图标注、同一人物多图是否缺“同一个人”说明、线稿分镜或白模画风是否会带进成片、参考视频作运镜依据时是否缺“不新增镜头”、动作描述里是否有带引号的话、转场是否缺完成秒数和到达画面、延长是否先写衔接画面、打斗和细腻表演是否挤在同一段、正文是否用关系称谓代替人名、台词前是否缺说话人名字、正文是否写了“承接上一段”这类跨段说明、光线是否缺光源方向和阴影落点、音频目标与所选官方方案或项目替代经验是否一致，静默是否有剧本依据及需提示的音轨风险，是否为填声新增事件、正文是否混入讨论用的其他图号
14. 位置关系风险（多人镜头；方向和出场写法单人镜头也查）：人物站位是否只写了构图标签、画面左右是否明确、相邻镜头是否越轴、高低关系是否缺少机位配合、纵深关系是否缺少焦点、走位是否缺少结束站位、多人换位后是否可能错位、单人镜头的移动或转向是否缺“画面”参照、人物到来是否缺入画过程、开场人物是否只写“位于”没有姿态
15. 运镜风险：运镜是否缺起点、触发、终点；摇摄与横移、俯仰与升降、变焦与推拉是否混用；是否有互相冲突的约束（如推近又要求人物大小不变）；“向左/向右”是否缺参照；是否只写了设备（手持、稳定器、无人机）没写路径；镜头是否完成了观看任务或有依据的状态延续
16. 镜头语法风险：是否有无动机运镜、只拍说话者没有听者反应、整场景别不变、整段只用一个机位、有台词的固定镜头过长（约 8 秒以上）、光线只写形容词、没有情绪高潮却强加特写或慢动作、角度运镜光效互相矛盾或堆砌、人物与环境割裂、标为“交给剪辑”的手法被写进提示词、构图与画幅不匹配（如竖屏左右并排三人以上）
17. 轴线风险（对手戏）：正反打是否越轴、甲乙在画面中的左右位置和视线方向是否前后一致、打斗动作方向是否与轴线一致、多人戏是否先交代整体站位再切某一对、过肩前景是否按画面位置写且前景人物留在自己那一侧、是否有空间锚点、切镜是否在反应完成之后、坐站等姿态是否在每个镜头重复并配合机位高低、姿态变化是否写成动作、一场戏是否有场景空间锁且各段一字不改、场景空间锁是否只写实际空间（不写画面左右）、静态对话是否只用房间一角、方位词参照是否明确、多机位时各镜的左右和光向是否与该机位一致、文字与参考图是否一致、总规定的位置是否在某一镜被改口、换位是否有路线（`references/scene-blocking-axis.md` 第十节）
18. 场景与道具连续性风险：场景图中是否已有会被重复生成的道具、道具参考图是否与场景中的物体绑定为同一个、道具状态变化是否靠上传第二张图实现、双人手部动作是否跨切点、是否写明用哪只手、场景中是否有多个同类物体（门、椅子、杯子）而提示词只写了类别名、剧本只写大地点时具体房间和门的开关是否符合剧情（密谈不放在敞门的临街空间）、首帧或关键帧里没有的物体是否写了何时从哪进入、动一件物体时是否写了旁边哪些不动、手部镜头是否写了手的数量和来路、大件道具尺寸是否挂在地标上
19. 对话戏与跨段风险（文戏或多段拼接）：说话角色是否锁定声线（优先音频参考）、跨段是否复述有依据的进入状态并分清实际尾帧与文字计划、道具是否有来源和去向、是否逐句机械正反打、同一生成段内跨切点的台词是否连续且无重复漏字，跨独立生成任务的台词衔接是否未说明、普通轮流对白是否有错误发声、听者反应是否在信息到达时发生（锁定抢话保留并另列风险）、空镜是否承接正在进行的动作或声音、单段台词是否超量；采用版本与验证版本是否明确，修改是否影响后续且尚未同步（v1.36，见 `references/project-state.md`）
20. 参考素材风险（有设定图时）：多视图拼图是否超过 5 个主体、图上标题图注等文字是否已裁掉、布景文字是否已在出图时处理、平面图或俯视图是否被直接上传、人物图背景是否排除、图中附带道具是否在文本中绑定、人物图是否只保留清楚的脸（全身视图去头时是否写了“脸以头像为准”）、是否有只有衣服没有人的展示格、场景图是否为 3/4 斜角空场景且留了地标物、对手戏是否有正反两张场景图、前视站位图是否带字或填色、是否有写实真人人脸
21. 单集节奏风险（每集第一段或最后一段，仅评估原稿，不强制新增）：第 1 秒是否有动作或异常、3 秒内是否有疑问或情绪冲击、第 5 秒左右是否有转折、第二集起原稿连续接续时是否接住上集结尾且未自行新增回顾（原稿已有回顾、跳时或另起场景照原稿保留，不据此判错）、最后一段是否停在钩子处、钩子是否依赖画面文字、是否为凑钩子新增了未经确认的内容
22. 动作与焦点风险：下一镜是否从头重演上一镜的动作、焦外人物是否定格、移焦是否缺起止焦点或与其他运镜同时写、时间段是否过载、拿着东西的手是否去做别的事、反打时受光方向是否按机位换算、群戏是否写了“其他人保持原位”、画内演奏是否被“无 bgm”误删、最终提示词里是否残留修改过程的负面句、参考图标注是否会被画出来
23. 情绪弧风险（文戏）：情绪变化是否缺触发器、是否无依据强塞判断过程、是否套用默认反应、相邻状态是否无故重置、强度是否过度夸张或强制回落、群戏观看重点是否混乱、核心道具交接是否缺过程、台词是否直接说出情绪（只提示，不改）
24. 景别与转场风险：是否有无观看目的的放大镜头、主要观看重点是否不清、同时发生的信息是否竞争或实际超载、揭示环境时是否缺锚点、剧情是否依赖画面文字、段内转场是否缺时间点和方式、段间转场是否选了路线、接缝是否定性（连续 / 硬切 / 剧本已写转场 / 建议升级）、特殊转场是否有剧本依据或已标“建议，待确认”、桥是否是剧本里本来就有的东西、A 段结尾和 B 段开头是否成对写、接缝两边的信息情绪节奏画面声音是否断开、转场是否只写了“丝滑、无缝、电影级”而没写连接依据、做转场的两张图生成前是否比对过位置大小视角方向光照、特殊转场是否缺“验收”行、首尾帧画幅是否一致或槽位颠倒、跨段动作是否重新起手、甩镜方向是否混写、遮挡是否真的盖满画面
25. 表演风险：人物是否只有情绪状态没有目标和行为、策略是否符合已有局面、是否无依据强加手头动作、地位和距离是否只靠台词体现、倾听者是否无反应、醉态病弱受伤等状态是否缺身体支撑点（能依据已有内容补的补上并标注，不能的列为待确认槽位）、特写动作是否过多
