# 转场路线与写法

分镜有多个场次、多个生成段，或需要转场时读取本文件：先按第零节从剧本找接缝、判断要不要转场，再按第一、二节决定在哪里转、走哪条路线，按第三节写法写，按第四节检查是否割裂。具体转场案例、52 种扩展转场和写法示例见 `references/transition-catalog.md`。

来源：用户提供的《AI 分镜转场 Skill》（动作匹配、视线、遮挡、甩镜、图形匹配、声音六类）和《AI 分镜：15 套景别组合》。逐条对照《Doubao Seedance 2.5 提示词指南》（下称“指南”）和《Seedance 2.5 教程》（下称“教程”），标注“官方写法”“经验”或“推断”。核对全文见仓库 docs 目录的 v1.16 优化记录。第零节、段间调度和第四节为 v1.27 新增，来源是用户提供的转场教程总结和补充例子，大部分是经验，按条标注。

## 零、从剧本判断哪里要转场

### 1. 先找接缝

接缝是两个画面之间要接起来的地方。从剧本里找四种：

| 接缝 | 剧本里怎么看出来 |
|---|---|
| 场次交界 | 场号变化，或场景标题的地点、内外、日夜变了 |
| 场内时间跳跃 | “茶过两巡”“半晌”“送走某人”“三天后”这类跳过时间的字眼 |
| 进出回忆、梦境、想象 | “想起”“梦里”“闪回”“回到现实” |
| 生成段交界 | 一场戏按时长评估拆成两段时，拆开的那一刀 |

每集第一段的开头和最后一段的结尾另按 `references/episode-hook-rhythm.md` 处理。

### 2. 给每个接缝定性

| 接缝类型 | 默认做法 | 可以建议升级的条件 |
|---|---|---|
| 同场景、时间连续（拆段那一刀、敲门后开门） | **不转场，做连续**：末帧复位、动作接续、声音跨段 | 无 |
| 同场景、跳过一段时间 | 硬切 | 剧本里有同一件道具或同一个构图可借：同机位换时间、道具接力 |
| 换场景、时间连续 | 硬切，或出画入画、视线衔接 | 剧本写了人物看向、走向、听到另一处 |
| 换场景、跳过时间 | 硬切 + 声音先入 | 剧本里有可借的桥：光、水、天空、相似形状 |
| 进出回忆、梦境 | 剧本写了什么就用什么；没写时硬切 | 虚焦、倒影、闪白、推进入黑 |
| 情绪最高点结束一场 | 硬切 | 剧本写了嘶吼、崩溃、爆炸等强刺激：闪白、推进入黑 |
| 平行叙事（“另一边”“与此同时”） | 硬切 | 动作匹配、声音接续、姿态对接 |

（经验）

### 3. 甲方剧本的硬规矩

- **剧本写了转场，照剧本做**（“黑场”“叠化”“闪回”“甩镜”），属于必须执行。
- **剧本没写转场，默认硬切或连续**。升级成特殊转场只写进诊断和段间衔接表，标“建议，待确认”，用户确认后才写进提示词。
- **桥必须是剧本里本来就有的东西**：剧本写了篝火才能用火光转场，写了下雨才能用水面转场。为了转场新增火、浪、烟、门洞、倒影，等于新增剧本内容，只能作为建议。
- **粒子、花开、形变这类特效**：用来表现剧本已有的事件（阵亡、消逝）算拍法；特效带出剧本没写的东西（枯树开花）算新增内容，只能作为建议。
- **不打乱剧本顺序**：转场只改两场之间怎么接，不改哪场在前。
- **不推进人物眼睛**：“推进瞳孔转到回忆”容易让眼睛发光变形，改用虚焦或倒影。
- **屏幕、照片、纸面默认不出字**：排除内容默认保留“不要字幕、水印文字”；用户明确要求某段出字时，按 SKILL.md 的覆写规则只改该段这一条。
- 暴力画面换描述方式，不改情节：写“红色液体溅满镜头”，不写“血液飞溅”“爆头”。（推断，可能触发平台审核）

### 4. 选哪种转场

1. **按意思选方向**：时间流逝用同机位换时间、虚焦、天空；回忆用虚焦、倒影、物体表面；情绪冲击用闪白、推进入黑、甩镜；同一时间换地点用视线、出画入画、声音先入；两人对照用道具接力、姿态对接、动作匹配。
2. **按剧本里有的东西选具体做法**：接缝两边有没有能盖满画面的东西（门、衣服、火、水）、相似的形状（圆形、旋转）、相同的动作（坐下、伸手）、暗处、强光源。
3. **按三段结构设计**：A 出口 → 桥 → B 入口。剪辑点放在桥上（信息最少的一帧，或 A、B 某样东西完全一样的一帧），B 入口是 A 出口的反向动作：A 被盖住，B 从盖住到露出；A 推近，B 拉远；A 越来越亮，B 越来越暗回正常。
4. **用六个“对得上”自检**：盖住、运动方向和速度、形状和位置、亮度和颜色、元素或主体、声音。至少对上两项才用；对不上就退回硬切。（详见 `references/transition-catalog.md` 第三节）
5. **强度跟情绪走**：日常文戏用连续、硬切、声音接；只有情绪顶点或时空大跳跃才用强转场。一集里特殊转场一般不超过 1–2 次，同一种不连续用。（经验）
6. **风险项**：写实画风不推进嘴里（口腔易生成怪异，改推门洞、衣服暗处、掌心）；特效类先试片。

## 一、先判断转场在哪里发生

| 位置 | 做法 |
|---|---|
| 同一生成段内 | 直接写进提示词：写明时间点、方式和到达的画面。例如“第 5s 快速向左横移转场（向左擦除+自然叠化）”（指南）。要求干净切换时写“仅用硬切”，不要叠化时写“无叠化转场”（教程乐队案例）。 |
| 两个生成段之间 | 按第二节选路线。 |

转场为剧情服务。普通硬切已经能讲清楚时，不加复杂转场。（经验）

切段时就考虑转场：场次交界尽量放在生成段交界上，一段一个场景，转场在段间做；两个场景都很短、一段放得下时，才在段内转场。段内转场按 1–2 秒计入时长评估（`references/script-polish-capacity.md`），不够时不压缩剧本内容，改成段间转场或交给剪辑。（经验；指南：时间段内容过多会导致过度剪切或剧情遗漏）

转场要写到达：写明在第几秒完成、到达后是什么画面，例如“第 5 秒向左横移转场，第 6 秒客厅完整可见”。不写“慢慢飘向”“渐渐变成”这类没有终点的过程，否则过渡会占掉下一段的时长；转场中间也不要长时间停在纯色或空画面上。（官方写法“第 5s 快速向左横移转场”+ 经验；原资料用 0.2–0.8 秒的小数时长，已改为整数秒）

## 二、段与段之间的四条路线

| 路线 | 做法 | 适用 | 依据 |
|---|---|---|---|
| 1. 剪辑 | A、B 分别生成，在剪辑中对齐切点；写在“剪辑建议”里 | 默认；硬切、声音转场、黑场、相似颜色 | 本 skill 原规则 |
| 2. 视频无缝转场任务 | 上传 A、B 两段视频，由模型补出中间的过渡 | 想要镜头穿越、形变式的连续过渡 | 官方任务类型（需试片） |
| 3. 首尾帧桥接 | A 段实际最后一帧作首帧，B 段实际第一帧作尾帧，生成一段短过渡，再在剪辑中裁掉重复的首尾 | 需要两端画面都锁定 | 官方首尾帧能力（需试片） |
| 4. 两段在桥上切 | A 段最后 1 秒停在桥最满的状态（盖满、全黑、全白、模糊最强），B 段第 0–1 秒从同一状态退出来，剪辑时在桥上对接 | 遮挡、推拉对接、闪白、推进入黑、甩镜、动作锁定换背景 | 经验（B 段开头的“全盖满”可能生成不满，需试片） |

### 路线 2 的写法

按指南“视频无缝转场”案例改编（原例是麻将牌慢慢变成高楼）：

```
将视频1和视频2衔接起来，视频1的镜头从书桌缓慢上摇到窗外夜空，再垂直向下俯冲，无缝自然地衔接转场到视频2的城市街道，在镜头切换的过程中台灯的光点慢慢变成街灯。同时不要改变上传的两个视频。
```

- 写清 A 段的镜头怎么离开、用什么方式过渡、B 段怎么到达，并写“同时不要改变上传的两个视频”。（官方写法）
- 参考视频合计不超过 30 秒，只上传切点附近的片段。（官方素材上限）
- 官方案例的素材标签写成【视频1】；本 skill 不照抄，写“视频1”，因为【】表示字幕。

### 路线 3 的要求

- 首帧和尾帧的画幅必须一致；不一致时，尾帧会被拉伸。（官方写法）
- 首帧槽位放 A 段的末帧，尾帧槽位放 B 段的首帧，不能颠倒。（经验）
- 生成后检查两端是否接上、人物身份是否漂移、中间有没有变形。（经验）

### 路线 4 的写法

A 段结尾和 B 段开头成对写，桥上的画面写成一样的句子（颜色、方向、速度、盖满的状态）：

```
A 段 10-13秒：特写，正面俯视机位，镜头缓慢向前推近唱机上顺时针旋转的黑色唱片，第 12 秒唱片盖满整个画面，只看得到一圈圈旋转的纹路和反光，结束时唱片仍在顺时针旋转并盖满画面。
B 段 0-4秒：特写，侧面机位，画面被顺时针高速旋转的黑色车轮盖满，纹路和反光在转动，镜头快速向后拉远，第 2 秒看清是赛道上 F1 赛车的车轮，第 4 秒拉出整辆赛车向画面右侧飞驰。
```

- 旋转方向、运动速度、颜色两段一致，否则切点处会“倒转”或“跳色”。（经验）
- B 段第一帧要求全黑、全白、全盖满不一定准：更稳的做法是 B 段开头写镜头在暗处、对着强光或贴着遮挡物，再退出来；或者由剪辑在两段之间加几帧黑或白，写进“剪辑建议”。（推断，需试片）
- 更多成对写法（推进入黑、动作锁定换背景、火光）见 `references/transition-catalog.md` 第五节；那里的“方式 1–4”对应本节“段内、路线 4、路线 2、路线 3”。

### 段间调度：段间衔接表

多段输出时，在诊断报告末尾用一张表列出每个接缝（这是衔接说明，不是分镜节拍，可以用表格）：

| 接缝 | 剧本依据 | 接缝类型 | 衔接方式 | 路线 | A 段结尾 | B 段开头 | 指向与锚点 | 声音过切点 | 状态 |
|---|---|---|---|---|---|---|---|---|---|

- “状态”只有两种：**剧本已写**（直接执行）、**建议，待确认**（用户确认后才写进提示词；未确认时按默认的硬切或连续写）。
- 连续类接缝：A 段结尾写清人物位置、姿态、手里的东西和视线，B 段开头从同一状态继续，不重新起手；提示词正文不写“承接上一段”，直接写画面。
- 剪辑要做的部分（加几帧黑或白、对齐切点、声音前后挪）写进“剪辑建议”。

## 三、六类转场的写法

### 1. 动作匹配

- 同一段内：上一镜停在动作的哪个阶段，下一镜就从哪个阶段接着做，按 `references/action-focus-crowd.md` 第一节。
- 跨段：从 A 段选一帧动作进行到一半的画面，作为 B 段首帧（role = first_frame）。B 段写“从首帧的半转身姿态继续向画面右侧转动”，不重新起手。（官方首帧能力 + 经验）
- 跨场景（房门接车门）：两次动作在画面中的位置、方向和速度相近，写明“这是另一扇门”。（经验）
- 复杂动作（奔跑、跳跃、拔剑）不保证两段动作完全对上：缩小需要精确接续的动作范围，或改用遮挡、声音转场。（经验）

### 2. 视线衔接

- 写法：上一镜人物看向画外某处，下一镜接他看到的东西。（`references/camera-grammar.md` 第八节）
- 目标在下一镜中的高度和方向要符合人物所在的空间。例如人物抬头看，下一镜写成从地面仰望的视角，不机械照搬眼神的左右方向。（经验）
- 两镜之间的天气、时段和光线保持连续；回忆和梦境除外。（官方：保持空间方位和视线方向连续）

### 3. 甩镜

- 方向写摄影机的动作，例如“摄影机快速向画面右侧转动”，景物会向左掠过；不要同时写“背景向右滑动”。（经验）
- 段内甩镜写起点、方向、中途模糊、终点和停稳。见 `references/camera-movement-library.md` 第 03 条；官方案例写过“手持甩镜切入”。
- 跨段甩镜：A 段结尾仍在甩动中，B 段以相同方向的模糊开始，逐渐减速并停稳，能看清新场景。两段的模糊方向和速度要相近。（经验）
- 倒放不作为默认解法，交给剪辑，并且只用于画面里没有人走动、水流这类有时间方向的短镜头。（经验）

### 4. 遮挡与黑场

- 遮挡物必须真实存在于画面里。布料、门板等不透明物体比树叶、玻璃、头发更可靠。写成“镜头靠近他胸前的深色外套，布面逐渐放大，最终盖满整个画面”。（经验）
- 切点处整个画面必须被完全盖住，没有漏出的背景。没有完全盖住的帧时，不能在这里切。（经验）
- 黑场：只有画面里确实有暗处（没开灯的门洞、隧道）时，才写“镜头向前进入门洞，画面完全变黑”；没有暗处就由剪辑加黑场，写进“剪辑建议”。（经验）
- B 段从遮挡物或黑暗中退出，需要单独设计；只有一张清晰的 B 图，不能要求它的第一帧就是全黑。（经验）
- 推进入黑：A 段镜头推进人物嘶吼的嘴（动漫风格）或门洞、衣服暗处、捂脸的掌心（写实风格），推到全黑；B 段从隧道口、山洞、黑暗门洞向后拉出新场景。推镜和变焦一段里只写一种，写清全黑的整数秒。见 `references/transition-catalog.md` 07-2。（经验）

### 5. 图形匹配（相似形状、构图）

- 两个轮廓要完整，视角接近，在画面中的位置和大小大致对应，例如圆形的饼干接满月。（经验）
- A、B 分别生成，在剪辑中叠放对齐后硬切。不必强行做形变；需要形变时用路线 2，参考官方案例“麻将牌慢慢变成高楼”。
- 借用的只是轮廓，材质要符合各自的物体：白云是水汽，棉花糖是糖丝。（经验）
- 相似颜色只算色彩呼应，效果弱，只写进剪辑建议。

### 6. 声音

段内和段间的声音先入、声音后留，见 `references/episode-hook-rhythm.md` 第四节。不要求重新生成画面。

## 四、防割裂五项检查

观众觉得割裂，多数不是转场方式选错，而是接缝两边断了。每个接缝按五项检查，手段都从剧本已有的内容里选，不新增剧情；剧本里找不到时列为“建议，待确认”。

1. **信息接得上**：
   - 上段末尾留一个指向（问题、视线、声音、动作的开始），下段开头回应它。（经验）
   - 新场景前 1–2 秒给定位锚点：谁在、在哪、和上一场什么关系，先给能认出的人物或空间，再进对话。（经验；官方：保持空间方位和视线方向连续）
   - 跳时间要有看得见的证据，用剧本里有的东西：茶已斟过两巡、天色变了、人已落座。（经验）
   - 人物状态不归零：上一场的情绪、伤、衣服、手里的道具，下一场开头接着；剧本写了变化的除外。（经验）
2. **情绪接得上**：高接高、低接低可以直接切；高接低时在 A 段尾或 B 段头留 1 秒反应或环境镜头作缓冲，落在剧本已有的停顿、动作上。（经验）
3. **节奏接得上**：
   - 切点选在动作或台词完成的那一下；动作匹配转场相反，切在动作进行到一半。两种不混用。（经验）
   - 两边运动速度一致：A 段尾在快速推进，B 段头不能是静止画面。（经验）
   - 段内塞了转场又塞满剧情，会“过度剪切或剧情遗漏”（指南）。
4. **画面接得上**：两段的画幅、光线时段、主光源方向、色调一致；同一场景跨段时站位和视线方向不变，不越轴（官方：保持空间方位和视线方向连续）。同一场景跨段接续时，B 段开头的景别或角度和 A 段结尾至少差一级，避免跳切感；只有刻意的同机位换时间例外。（经验）
5. **声音接得上**：最有效的去割裂手段。B 段的声音在 A 段尾提前响起（声音先入），或 A 段的声音延续到 B 段开头再衰减（声音后留）；同一场景跨段，环境声写成一样的句子。写法见 `references/episode-hook-rhythm.md` 第四节。（经验）

检查方法：
- 段间衔接表的“指向与锚点”“声音过切点”两列空着，这个接缝就容易割裂。
- 先把转场拿掉，只按剧本顺序读每个接缝两边的内容；读不通说明剧本本身跳，按 `references/script-polish-capacity.md` 在诊断里提示，不靠转场硬补。
- 生成后看切点前后各 3 秒，只找五项里哪项断了，按第五节只修那一项。

## 五、返工规则

- 生成后只修最影响衔接的一项，保留合格的部分。（经验；指南：复杂任务拆成简单任务）
- 局部问题用编辑任务修改，写明“其余内容不要变化”。（官方写法）
- 同一处修两次仍然接不上，就缩小动作复杂度，或改走剪辑路线；用户坚持要的效果，不擅自替换。（经验）
- 提示词写的比例、秒数和停留时长是目标，不是逐帧保证；需要停留的画面，在剪辑中选实际稳定的一段。（经验）
