# 片头、片尾与标题

分镜需要片头、片名、集数标题、片尾、logo 或下集预告文字时读取本文件。

**默认规则（用户可覆写）：视频提示词的排除内容默认保留“不要字幕、水印文字”（来源：`references/negative-prompt-library.md` 视频分镜层“不要水印文字”，以及 Seedance 2.5 注入方式第 3 条“不要字幕”）。默认情况下片名、集数、“未完待续”、logo 在剪辑软件里加，视频提示词只生成留好标题位置的干净画面。用户在当前对话中明确要求某段由视频直接生成文字时，只调整该段排除内容里的这一条，其余排除条目原文保留，并在诊断中注明“按用户要求覆写”；写法见第三节第 6 条。**

## 一、官方资料里有什么

以下官方资料中让模型直接生成文字的写法，本 skill 默认不采用；用户明确覆写时按第三节第 6 条使用。两份官方文档（《Doubao Seedance 2.5 提示词指南》下称指南，《火山方舟 Seedance 2.5 教程》下称教程）都没有专门的“片头 / 片尾制作教程”，但有以下可直接借用的内容：

1. 片头标题动画的纠错案例（指南“文字拼写错误”）：原提示词是为甲虫游戏 'DIHETAO' 做 opening title sequence，模型把单词拼错。修正方法是先写画面，再要求字母 "D" "I" "H" "E" "T" "A" "O" 依次出现。
2. 中文大字的写法（同一章节案例二）：每处文字写明位置、字体和内容，并在后面附参考图编号，把正确文案做成图片作为参考素材，例如“画面中央浮现黑体大字‘伴你安心出行’ 参考图2”。指南明确给出两种防错字方法：英文拆字母按顺序出现；需要准确展示的文字做成图片作为参考素材。
3. logo 片头（指南“关键帧参考”案例）：“镜头 1：静止展示图片 1 的「江湖风云」水墨风格 logo，背景为统一浅蓝底色，画面保持约 1 秒静止。镜头 2：图片 1 中的文字区域消失后，角色从画面底部滑入……”。即片头标题静止约 1 秒，再让文字消失、正片内容入画。
4. logo 结尾（教程“通过提示词控制时长”示例）：30 秒序列的最后写“回到滴答作响的宏大黄铜钟面。最后一秒出现 logo，参考图像 1”。
5. 文字收尾（教程多素材参考示例）：“结尾英文文字快速分词切换入画，配合强节奏文字运动与产品定格……最终品牌感收束”。
6. 定格（指南“时间戳”部分）：“主角按下快门后画面定格 1 秒”。可用于片尾停在最后一个画面上再出标题。
7. 向前 / 向后延长（指南任务类型）：延长任务可以“向前 / 向后延续输入的视频，可要求画面 / 音频无缝衔接”。已经生成好的第一段正片，可以用“向前延长”在它前面接一段片头；最后一段用“向后延长”接片尾。
8. 一键成片（指南任务类型）：输入多个图 / 视频生成短片，“可添加文字 / 贴纸 / 转场”。
9. 字幕符号的区别（教程）：【】 表示字幕。官方让模型生成标题的写法是“画面中央浮现……大字”；本 skill 默认不采用，标题在剪辑中加。

每集开头的抓人节奏、冷开场和每集结尾的悬念钩子见 `references/episode-hook-rhythm.md`；本文件只处理片名、标题和片尾文字的位置。

## 二、为什么之前做不出标题

- 视频里没有专门留给标题的镜头和画面空间，后期加字时没有合适的位置和时长。
- 标题默认不交给视频模型生成：本 skill 默认排除文字；模型生成中文也容易出错别字。

## 三、做法：视频生成干净画面，剪辑加字

1. 片头标题卡单独生成一段（推荐）：4–6 秒，与正片分开生成，后期拼在最前面。画面是空镜或氛围镜头，写明为标题留出的空白区域（例如“画面中央上方三分之一是干净的夜空，没有任何物体”），镜头固定或极缓推进，便于后期叠字。背景可用正片的场景参考图，保证风格一致。
2. 冷开场接标题（占用剧本段时长，需列为待确认槽位）：正片第一段的最后 1–2 秒写“画面定格 1 秒”或缓慢拉远到空镜，留出叠加片名的画面；片名在剪辑中加在这一段上。
3. 向前延长：正片第一段已经满意时，用“向前延长视频 1”在前面生成一段空镜作为片头背景，要求画面和声音与视频 1 的开头无缝衔接（官方能力）。
4. 片尾：最后一段结尾写“画面定格 1 秒”（官方写法）或逐渐压暗，留出 2–3 秒干净画面（占用剧本段时长时列为待确认槽位，否则单独生成片尾段）；“未完待续”、下集预告文字、logo 在剪辑中加。也可以单独生成片尾空镜段，或用“向后延长”。
5. 文字、logo、贴纸默认在剪辑软件或一键成片的加字功能中完成，字形准确、可随时修改。
6. 用户明确要求视频直接生成标题时（覆写）：按官方写法写明文字的位置、字体和内容，需要准确展示的文字做成图片作为参考素材（例如“画面中央浮现黑体大字‘伴你安心出行’ 参考图2”）；英文按字母顺序依次出现。只删去该段排除内容里的“不要字幕、水印文字”，其余排除条目保留；其他段不受影响。

写法规则：

- 排除内容默认保留“不要字幕、水印文字”；只有用户明确要求视频生成标题时才改这一条。
- 未覆写时，提示词里不出现片名、集数、台词以外的任何文字内容，也不上传含文字的参考图。
- 写清留白区域的位置（画面中央 / 上方三分之一 / 正下方）和这块区域里是什么（干净的天空、虚化的墙面、黑场），要求“该区域没有任何物体和图案”。
- 留白画面保持稳定：固定机位或极缓推进，不快速运动，便于后期叠字。
- 写清留白时长（整数秒），对应剪辑中标题的停留时间。
- 标题画面也写声音：片头音乐用 ()，或写“无背景音乐，只有低沉的风声”；按 `references/seedance-2-5-adapter.md` 的声音规则写。
- 片头和正片分开生成时，片头最后一帧和正片第一帧要能接上：同一场景、同一光线，或片头以黑场 / 淡出结束。
- 在该镜头后附一行“剪辑建议”：写明在第几秒到第几秒、画面哪个位置加什么标题（与 `references/camera-grammar.md` 的“交给剪辑”一致）。

## 四、示例

片头标题背景（单独生成，后期拼接并加字）：

```
素材指代：图片1是古宅庭院场景，只参考空间、建筑和夜间光线。
一句话概述：雨夜古宅庭院空镜，画面中央上方留出干净的夜空，古装悬疑风格片头背景。
0-2秒：大全景，固定镜头，雨夜古宅庭院空无一人，屋檐下灯笼微微摇晃。
2-5秒：镜头极缓推进，画面中央上方三分之一是干净的深色夜空，只有细密雨丝，没有任何物体和图案。
5-6秒：画面淡出至黑场。
贯穿要求：<细密的雨声>；无背景音乐（需要配乐时先列为待确认槽位）。画面中无人物。
排除内容：不要字幕、水印文字；无人物出现。
```
生成参数：duration=6

剪辑建议：2–5 秒在画面中央上方加片名“雨夜归人”，淡入淡出。

片尾（接在最后一段正片结尾）：

```
……
10-12秒：她转身走进雨中。
12-13秒：画面定格。
13-15秒：画面逐渐压暗，画面正下方是干净的深色地面，没有任何物体。
排除内容：不要字幕、水印文字。
```

剪辑建议：13–15 秒在画面正下方加“未完待续”。
