# 片头、片尾与标题

分镜需要片头、片名、集数标题、片尾、logo 或下集预告文字时读取本文件。

## 一、官方资料里有什么

两份官方文档（《Doubao Seedance 2.5 提示词指南》下称指南，《火山方舟 Seedance 2.5 教程》下称教程）都没有专门的“片头 / 片尾制作教程”，但有以下可直接借用的内容：

1. 片头标题动画的纠错案例（指南“文字拼写错误”）：原提示词是为甲虫游戏 'DIHETAO' 做 opening title sequence，模型把单词拼错。修正方法是先写画面，再要求字母 "D" "I" "H" "E" "T" "A" "O" 依次出现。
2. 中文大字的写法（同一章节案例二）：每处文字写明位置、字体和内容，并在后面附参考图编号，把正确文案做成图片作为参考素材，例如“画面中央浮现黑体大字‘伴你安心出行’ 参考图2”。指南明确给出两种防错字方法：英文拆字母按顺序出现；需要准确展示的文字做成图片作为参考素材。
3. logo 片头（指南“关键帧参考”案例）：“镜头 1：静止展示图片 1 的「江湖风云」水墨风格 logo，背景为统一浅蓝底色，画面保持约 1 秒静止。镜头 2：图片 1 中的文字区域消失后，角色从画面底部滑入……”。即片头标题静止约 1 秒，再让文字消失、正片内容入画。
4. logo 结尾（教程“通过提示词控制时长”示例）：30 秒序列的最后写“回到滴答作响的宏大黄铜钟面。最后一秒出现 logo，参考图像 1”。
5. 文字收尾（教程多素材参考示例）：“结尾英文文字快速分词切换入画，配合强节奏文字运动与产品定格……最终品牌感收束”。
6. 定格（指南“时间戳”部分）：“主角按下快门后画面定格 1 秒”。可用于片尾停在最后一个画面上再出标题。
7. 向前 / 向后延长（指南任务类型）：延长任务可以“向前 / 向后延续输入的视频，可要求画面 / 音频无缝衔接”。已经生成好的第一段正片，可以用“向前延长”在它前面接一段片头；最后一段用“向后延长”接片尾。
8. 一键成片（指南任务类型）：输入多个图 / 视频生成短片，“可添加文字 / 贴纸 / 转场”。
9. 字幕符号的区别（教程）：【】 表示字幕。片名、标题不是字幕，不要放进 【】，要写成“画面中央浮现……大字”。

## 二、为什么之前做不出标题

- 本 skill 默认在排除内容里写“不要字幕、文字、标志”，和标题直接冲突。
- 标题写在 【】 里会被当成字幕处理。
- 中文标题直接写在提示词里容易出现错别字。

## 三、做法

按可靠程度排序：

1. 标题卡单独生成一段（推荐）：4–6 秒，与正片分开生成，后期拼在最前面。标题做成图片作为参考素材，提示词写画面背景、标题出现方式、停留时长。背景可用正片的场景参考图，保证风格一致。
2. 冷开场接标题：正片第一段的前几秒是剧情，最后 1–2 秒画面定格或拉远，标题浮现。适合“先抓人再出片名”的短剧结构。
3. 向前延长：正片第一段已经满意时，用“向前延长视频 1”在前面生成片头，要求画面和声音与视频 1 的开头无缝衔接。
4. 片尾：最后一段的结尾写“画面定格 1 秒”，再写标题、“未完待续”、下集预告文字或 logo 浮现；也可以单独生成片尾段，或用“向后延长”。
5. 剪辑软件加字：对文字准确度要求最高时（长标题、生僻字），在剪辑软件里加标题最稳；视频提示词只负责留出干净的背景画面。

写法规则：

- 标题文字写成“画面中央浮现［字体］大字‘标题’ 参考图 N”，不要用 【】。
- 中文标题一律做成图片作为参考素材，并在文字描述后附图片编号（官方写法）。
- 英文标题拆成独立字母，要求按顺序依次出现（官方写法）。
- 写清位置（画面中央 / 正下方 / 左上）、字体风格（黑体、毛笔书法、金属质感）、出现方式（淡入、逐字出现、从画面下方滑入）、停留时长（整数秒）、消失方式。
- 排除内容改成“除标题外，不出现字幕、其他文字、水印、标志”，不再写“不要文字”。
- 标题画面也写声音：片头音乐用 ()，或写“无背景音乐，只有低沉的风声”；按 `references/seedance-2-5-adapter.md` 的声音规则写。
- 片头和正片分开生成时，片头最后一帧和正片第一帧要能接上：同一场景、同一光线，或片头以黑场 / 淡出结束。

## 四、示例

片头标题卡（单独生成，后期拼接）：

```
素材指代：图片1是古宅庭院场景，只参考空间、建筑和夜间光线；图片2是片名“雨夜归人”的书法字图片，严格按图片2的字形显示，不改字。
一句话概述：雨夜古宅庭院空镜，片名书法大字缓缓浮现，古装悬疑风格片头。
0-2秒：大全景，固定镜头，雨夜古宅庭院空无一人，屋檐下灯笼微微摇晃。
2-5秒：画面中央浮现毛笔书法大字“雨夜归人” 参考图2，墨色由淡到浓逐渐显现，文字保持静止清晰。
5-6秒：文字连同画面一起淡出至黑场。
贯穿要求：(低沉的古琴单音) <细密的雨声>。文字只出现图片2中的四个字，字形、笔画与图片2一致。
排除内容：除片名外，不出现字幕、其他文字、水印、标志；排除错别字、文字变形、多余笔画。
```
生成参数：duration=6

片尾（接在最后一段正片结尾）：

```
……
12-13秒：她转身走进雨中，画面定格1秒。
13-15秒：画面逐渐压暗，画面正下方浮现黑体小字“未完待续” 参考图3，保持静止。
排除内容：除“未完待续”外，不出现字幕、其他文字、水印、标志。
```
