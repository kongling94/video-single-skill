# 运镜写法库

仅在运镜类型易混、组合运镜或路径复杂时按 SKILL.md 路由查第一至五节及第六节选用的条目。普通运镜使用 production-core.md，不自动通读本库。选哪种运镜、它服务什么情绪、可执行度如何，见 `references/camera-grammar.md`。

来源：用户提供的一套运镜教程图（12 种运镜，原图为第 2–11 页）。教程的方法和检查点用本 skill 的话重新整理；每种运镜另给一份按 Seedance 2.5 官方规则改写的写法（依据 `references/seedance-2-5-adapter.md`）。

关于模型版本：教程图没有标注 Seedance 2.0，也没有 @ 引用、镜头序号这类 2.0 专用写法，属于通用写法。但它的节奏全部靠“缓慢”“停稳留一拍”这类相对描述，没有时间戳，这正是 2.0 只响应镜头序号时的写法。Seedance 2.5 响应整数秒时间戳，所以下面每种运镜都改写成带整数秒时间戳的 2.5 版本。

## 一、写运镜前先想清楚的六件事

1. 空间关系：人物、门、窗、桌等在空间里的相对位置。
2. 起始画面：机位高度、景别、人物在画面中的位置。
3. 人物调度：人物做什么动作、朝哪里看。
4. 摄影机运动：用哪一种运镜，朝哪个方向。
5. 焦距与焦点：焦距是否不变，谁始终清晰。
6. 终点与节奏：到达什么画面，切点处继续运动还是停稳；需要停稳时保留多久。

判断标准：运镜服务什么观看作用，例如揭示、跟随、强调、情绪压力或有依据的状态延续。说不出观看作用的自加运镜不用；原分镜指定的运镜保留，问题只在诊断中提示，不以是否增加剧情信息作为唯一标准。

两条硬性检查（经验，来自 v20 分镜模板）：

- **一镜一个主导运镜**：每个镜头只选一种主要运动（或固定），写清从哪开始、跟谁或揭示什么、速度节奏（匀速、先快后慢、中途停顿）、停在哪。确实需要第二种运动时，写清先后，例如“先横移到门口，停稳后再缓慢推近”，不把推、拉、环绕、升降同时叠在一句里。例外：一镜到底和风格化奇观镜头可以写组合运镜（官方教程案例“连续流畅的环绕与穿透运镜”），但仍写清连续路径和先后。
- **机位路径要符合空间**：按场景里已知的墙、门窗、家具和层高检查路径。拉远要看摄影机身后有没有空间，横移和环绕要看沿途有没有墙和大件家具，升降要看层高。路径不成立时改用固定、摇摄或小幅移动；写实剧情镜头不安排穿墙、穿过天花板或穿过家具。例外：一镜到底、FPV、穿透或穿梭运镜等风格化镜头可以穿过物体（官方教程案例“环绕与穿透运镜”“无缝穿梭运镜”，指南列 FPV、一镜到底可直接写），要写清穿过什么、从哪进、到哪出。

## 二、每个运镜都按四段写

起点（机位、景别）→ 触发（人物的哪个动作引出运镜）→ 运动（运镜类型、方向、速度、焦距是否不变）→ 终点（到达什么景别或位置，切点处继续运动还是停稳）。

文生视频要补全场景、人物和起始构图；图生视频（首帧）沿用首帧画面，重点写动作、运动路径和终点。

## 三、最容易混淆的三组运镜

- 摇摄与横移：摇摄是机位不动、原地左右转向；横移是摄影机整体向侧面平移。区别看前景物体与远处背景的相对位置是否变化，摇摄不变，横移会变。
- 俯仰与升降：俯仰是机位不动、原地上下转向；升降是摄影机高度改变，可以保持朝向不变。低机位不等于仰拍，机位高度和镜头角度要分开写。
- 变焦与推拉：变焦是机位不动、焦距改变，透视关系不变；推拉是摄影机前后移动、焦距不变，前后景的透视关系会变。人物在画面里变大，不代表摄影机真的推近。景别要写清裁切位置，例如腰部以上、胸部以上、面部特写。

## 四、互相冲突的写法

不要把所有条件都锁死，以下组合会互相打架：

- 推近又要求人物大小不变：人物静止、焦距不变时，推近必然让人物变大。要保持大小，就另写人物后退，或改用反向变焦。
- 等速跟拍又要求不断缩短距离：要维持景别，就写距离大致稳定；要追近，就先写接近，再写等速跟随。
- 环绕又要求人物始终居中、朝向完全固定：写成摄影机沿弧线移动，同时持续转向人物。
- 移焦又要求前后景始终清晰：移焦必须允许两个距离层交换清晰度。

## 五、方向和设备

- “向右”必须写参照：人物自身右侧、画面右侧、还是摄影机向右移动。
- 稳定器、手持、无人机是拍摄设备，不是运动路径。写了设备仍要写路径，例如“手持跟随，摄影机在人物身后同向前进”。

## 六、12 种运镜

每种运镜给出：作用、要点、检查项，以及 Seedance 2.5 写法示例（文本框外附生成参数）。示例人物和场景只是演示，使用时替换为用户分镜内容。示例是片段，完整生成段必须补上排除内容“不要字幕、水印文字”。

### 01 固定镜头：让表演发生

作用：机位、朝向、取景范围都不变，把注意力交给表演。
要点：写明三者固定；动作结束后停留一拍。
检查：背景边缘是否稳定，有没有悄悄推近。

```
一句话概述：室内书房，女人在书桌后读完纸条后抬眼看向门口，固定镜头。
0-3秒：平视腰部以上中景，女人坐在书桌后低头读手中的纸条。
3-5秒：她读完纸条，抬眼看向画面右侧的门口。
5-6秒：她保持视线停住，画面静止停稳。
贯穿要求：摄影机位置、朝向和取景范围全程固定，不推近、不摇动，背景边缘稳定；窗光方向一致。
```
生成参数：duration=6

### 02 摇摄：顺着视线找信息

作用：机位不动，原地左右转向，跟着人物视线把新信息带进画面。
要点：先写视线触发，再写转向方向和终点。
检查：是原地转向，还是变成了侧向滑行。

```
一句话概述：室内书房，女人看向门口，镜头原地向右摇到门口站着的男人。
0-2秒：平视中景，女人坐在书桌后，看向画面右侧的门口。
2-5秒：摄影机在原位置缓慢向右摇摄，女人移出画面左侧，门口进入画面。
5-7秒：镜头停在门口男人的腰部以上中景，停稳。
贯穿要求：摄影机位置不变，只改变左右朝向；前景与远处门框的相对位置不变。
```
生成参数：duration=7

### 03 甩镜：快速转移注意

作用：快速摇摄，中途画面横向模糊，再停稳在新主体上。
要点：写清起点主体、甩动方向、中途模糊、终点主体和景别。
检查：有没有自动切镜，停稳时有没有多余回摆。

```
一句话概述：书房里男人在画面左、女人在画面右，男人突然看向女人，镜头快速向右甩到女人。
0-2秒：男人胸部以上近景，他坐在桌后，突然转头看向画面右侧的女人。
2-3秒：甩镜，摄影机在原机位快速向右旋转，画面出现强烈横向运动模糊。
3-5秒：镜头停稳在女人胸部以上近景，她手拿纸条，若有所思。
贯穿要求：一个连续镜头完成，不切镜；摄影机位置固定，只改变朝向；停稳后不回摆。
```
生成参数：duration=5

### 04 俯仰：沿上下方向揭示

作用：机位固定，只改变上下朝向，从局部揭示到整体。
要点：写明起点（如鞋与地面）、转动方向、终点构图，并写摄影机高度和距离不变。
检查：有没有把仰摇变成升高机位。

```
一句话概述：室内，低机位正对站立的女人，镜头从脚下原地向上仰摇到她的上半身。
0-2秒：低机位画面，只看到女人的鞋和地面。
2-5秒：摄影机原地缓慢向上仰摇，依次露出裤腿、毛衣背心。
5-6秒：镜头停在略带仰视的上半身构图，停稳。
贯穿要求：摄影机高度和距离全程不变，只改变上下朝向。
```
生成参数：duration=6

### 05 变焦：改变取景范围

作用：机位不动，焦距改变，取景范围变宽或变窄。
要点：“变焦”不在官方可直接写的运镜清单里，按“名词 + 描述性解释”写；写明观察位置不变。
检查：有没有出现不需要的机位前移。

```
一句话概述：书房里男人静坐，固定机位，镜头变焦拉近到他的面部特写。
0-2秒：平视中景，男人坐在椅子上，腰部以上入画。
2-6秒：变焦拉近，摄影机位置不动，取景范围逐渐收窄，从腰部以上收紧到面部特写，背景透视关系不变、背景被放大。
6-7秒：停在面部特写，眼睛持续清晰，停稳。
贯穿要求：摄影机不前移，保持同一观察位置。
```
生成参数：duration=7

### 06 移焦：改变清晰主体

作用：取景基本不变，焦点从一个距离层转到另一个距离层。
要点：官方示例就是移焦，写成“名词 + 描述”：哪一层由清晰变模糊，哪一层由模糊变清晰。浅景深要写成画面效果。
检查：清晰度是否真的交换了；移焦可能伴随轻微的画面缩放感，那不等于变焦。
可执行度：先试片；2.0 时执行不稳定，不稳定时拆成两个镜头。

```
一句话概述：书房里固定构图，焦点从前景桌上的钥匙平滑转移到后景的女人。
0-2秒：固定构图，浅景深，前景桌面上的一串钥匙清晰，后景桌后的女人模糊。
2-5秒：移焦，画面焦点平滑转变，钥匙逐渐变模糊，女人的眼睛由模糊逐渐变清晰。
5-6秒：女人清晰、钥匙虚化，画面停稳。
贯穿要求：取景范围基本不变，摄影机不移动。
```
生成参数：duration=6

### 07 推近：靠近主体看表情

作用：摄影机向前移动、焦距不变，靠近人物看清表情。
要点：写起点景别、直线推近、终点景别；焦点跟随眼睛；前景物体和门框的透视连续变化。
检查：是合理的空间变化，还是平面放大。

```
一句话概述：书房里男人坐在桌后，摄影机沿直线缓慢推近到他的胸部以上近景。
0-1秒：男人腰部以上中景，坐在桌后托腮。
1-5秒：摄影机沿直线缓慢向前推近，他轻轻抬眼，焦点跟随他的眼睛，桌边与门框的透视随推近连续变化。
5-6秒：停在胸部以上近景，停稳。
贯穿要求：焦距不变，靠摄影机移动改变景别，不是画面放大。
```
生成参数：duration=6

### 08 拉远：让环境参与叙事

作用：摄影机后退、焦距不变，逐渐露出环境，让处境成为信息。
要点：提前写明要露出的空间和物件；拉远不只表达孤独，要写清露出的新信息是什么。
检查：房间有没有重建，家具有没有突然冒出。

```
一句话概述：教室般的房间里，摄影机从女人近景平稳后退，露出她身后两排空椅子。
0-1秒：女人胸部以上近景，她坐在桌后托腮。
1-6秒：摄影机焦距不变，平稳向后退，逐渐露出她的全身、书桌和身后两排空椅子。
6-7秒：停在房间全景，她保持坐姿，画面停稳。
贯穿要求：房间结构和家具从一开始就存在，后退过程中不新增、不变形。
```
生成参数：duration=7

### 09 横移：绕开前景遮挡

作用：摄影机向侧面平移，前后景相对位置变化，露出被遮挡的信息。
要点：写明移动方向的参照、焦距与朝向不变、哪个前景物体与哪个背景物体发生相对变化、露出了什么。
检查：遮挡是否连续，人物有没有原地转身。

```
一句话概述：走廊里女人抱着书站立，摄影机向右横移，绕过前景柱子露出门口。
0-1秒：女人站在走廊，画面右侧被前景柱子挡住，门口看不见。
1-5秒：摄影机向自身右侧缓慢横移，焦距与朝向保持不变，前景柱子与远处门框的相对位置变化，被挡住的门口逐渐露出，女人在画面中移向左侧。
5-6秒：门口完整露出，画面停稳。
贯穿要求：女人保持站姿和朝向，不原地转身；柱子遮挡连续。
```
生成参数：duration=6

### 10 升降：越过遮挡

作用：改变机位高度，可保持朝向不变，越过前景遮挡露出后方信息。
要点：“升降”不在官方可直接写的清单里，写成“摄影机竖直升高 / 降低”的描述，并写明朝向和焦距不变。
检查：真的换了高度，还是只是向上摇。

```
一句话概述：书房里镜头水平朝向桌后架子，摄影机竖直升高，越过桌沿露出文件盒。
0-1秒：镜头水平朝向桌后的架子，桌沿挡住文件盒下部，女人在中景托腮。
1-5秒：摄影机焦距和朝向不变，缓慢竖直升高，越过桌沿，文件盒逐渐完整露出。
5-6秒：文件盒完整入画，画面停稳。
贯穿要求：镜头始终保持水平朝向，不向上摇。
```
生成参数：duration=6

### 11 跟拍：跟着人走

作用：配合主体移动，摄影机与人物保持关系。
要点：先写人物路线，再写摄影机关系（在身后、侧面还是前方，同向还是反向，距离是否稳定）；写人物停下时镜头怎么停。
检查：人物有没有原地踏步，镜头有没有追得太近。

```
一句话概述：走廊里男人向前走，摄影机在他身后同向跟随，背部中景。
0-1秒：男人背面腰部以上中景，站在走廊起点。
1-6秒：他沿走廊向前行走，摄影机在他身后同向跟随，距离大致稳定，背部保持在画面中央，景别基本不变。
6-7秒：他停下脚步，镜头随之平稳停住。
贯穿要求：人物真实向前移动，脚步与地面接触清楚，不原地踏步；摄影机不追近。
```
生成参数：duration=7

### 12 环绕：围着人看

作用：摄影机沿弧线移动，同时持续转向人物。
要点：写明起点角度、环绕方向（以人物自身左右为参照）、终点角度；写人物朝向固定、距离与高度稳定、人物居中。
检查：是摄影机绕人，还是人物在转身。
可执行度：可直接写（官方清单），写明方向和幅度；幅度大时先试片。

```
一句话概述：室内女人原地站立，摄影机从正面沿圆弧环绕到她的左侧。
0-1秒：女人正面胸部以上近景，原地站立，身体朝向固定。
1-5秒：摄影机沿圆弧缓慢移向她自身左侧，同时持续转向她，人物始终居中。
5-6秒：停在她的左侧脸近景，画面停稳。
贯穿要求：人物不转身，身体朝向不变；摄影机与人物的距离和高度大致稳定。
```
生成参数：duration=6

## 七、接镜前检查

连接两个镜头前，检查视线方向、左右关系和行动轴线是否一致（与 `references/position-relationship-library.md` 的轴线规则相同）。

## 八、套用到 Seedance 2.5 时的规则汇总

- 普通生成的四段式（起点、触发、运动、终点）用整数秒时间区间组织；先按原镜头意图确定终点画面及切点处的运动状态。需要停稳时才预留时间，“起点 0–1 秒、最后 1 秒停稳”只是估算示例，不是固定节拍。编辑沿用原片时间线。
- 原镜头要求“停稳留一拍”时，可写清停稳所处区间和持续时间；持续跟拍、甩镜或运动中切镜照原稿，不插入停稳。“缓慢”仍可写，具体用多久由剧情和时间段容量决定。
- 一个时间段只写一种主运镜；多种运镜组合时按时间段依次写，并写清两段之间如何衔接。
- 推、拉、摇、移、跟、环绕、俯冲、后拉、上摇、手持晃动可以直接写（官方清单）；甩镜是教程案例用法（“手持甩镜切入”），也可以写；变焦、升降、移焦这类按“名词 + 描述性解释”写。
- 焦距、焦段、光圈不是参数，“焦距不变”“浅景深”写成画面描述。
- 时长示例只演示普通生成显式指定 4–30 秒整数时长的写法；普通生成也可用 duration=-1。多个运镜可在同一生成段内按时间戳连续排列；编辑任务 duration=-1，沿用原片时间线，输出可能非整数秒。
