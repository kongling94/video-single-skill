# 动作阶段、焦点与群戏

动作跨镜头延续、镜头内有焦点变化、一个时间段里事件较多，或画面里有三人以上的群体反应时读取本文件。

来源：用户提供的《影视镜头导演》（cinematic-shot-direction）skill。逐条对照《Doubao Seedance 2.5 提示词指南》（下称指南）和《Seedance 2.5 教程》（下称教程），标注“官方写法”“经验”或“推断”。核对全文见仓库 docs 目录的 v1.15 优化记录。

## 一、动作阶段

一个动作从开始到结束分成以下阶段（阶段划分为经验）：

未开始 → 开始 → 接触 → 受力 → 完成 → 余势 → 静止

1. 每个镜头写清动作的起始状态和结束状态（官方写法：指南“编辑宽高比效果差”案例要求“每个镜头均需保留其起始状态、中间运动轨迹及结束状态”）。
2. 下一个镜头从上一镜结束时的阶段接着往下演，不从头重演。例如上一镜停在“手刚碰到门把手”，下一镜写“手已握住门把手，向下压”，不写“她伸手去开门”。（经验）
3. 动作按先后写，不同时抢拍（官方写法：周婆婆案例“动作依次发生，不同时抢拍”）。
4. 阶段落在整数秒的时间段里，不写小数秒（官方：时间戳以 1 秒为单位）。一个时间段可以包含几个阶段，不必每个阶段切一镜。
5. 焦点之外、不是本镜主体的人物，也继续做自己的动作，不定格。例如林秀兰被看时仍“困惑而警觉地回望她”（官方案例写法）。
6. 跨生成段时，上一段的“结束时……”写到动作的哪个阶段，下一段的站位设定就从这个阶段开始。配合 `references/dialogue-scene-continuity.md` 第二节。
7. 改变局面的关键动作（递交、夺走、受伤、入场、离场、揭开）补齐五项：动作前的事实（东西在谁手里、人在哪）、谁发起、什么触发（看到什么、听到哪句话）、接触过程（哪只手、碰到哪里）、动作后的事实（东西现在在谁手里、伤在哪里）。五项都要能在画面里看到；剧本没给触发原因时列为待确认槽位，不自行编造。（经验，来自 v20 分镜模板）

## 二、焦点变化（移焦）

1. 官方写法：小众或专业的术语写成“名词 + 描述性解释”。指南原例：“移焦，画面焦点发生平滑转变，原本在前景清晰的树木变模糊，背景中的人物由模糊逐渐变得清晰。”
2. 写全四项（经验）：
   - 起始焦点在谁或什么上；
   - 结束焦点在谁或什么上；
   - 由什么触发（一句台词、一个动作、一个声音）；
   - 发生在哪个时间段、对应动作的哪个阶段。
3. 例：“6-8秒：近景，固定机位。前景苏晚的手指停在杯壁上，清晰；背景陈屿模糊。苏晚说完‘你是哪种？’后，移焦，焦点从前景的手平滑转到背景陈屿的脸上，手变模糊，陈屿逐渐清晰。”
4. 移焦和变焦是两回事：
   - 移焦改变清晰的位置，人物大小不变；
   - 变焦改变画面大小，见 `references/camera-movement-library.md` 中“变焦与推拉”的区分。
   - `references/negative-prompt-library.md` 流畅优先层的“不要镜头内变焦”指变焦，不禁止移焦。
5. 组合运镜分段完成（经验）：先推近，到位后再移焦，不同时写推近、横移和移焦。
6. 一个时间段内最多一次移焦。（经验）

## 三、景别的补充写法

1. 景别直接写官方词：大全景、全景、中景、近景、特写（指南：景别“可以直接写”）。
2. 需要精确控制画面裁到哪里时，在景别词后补一句画面下沿的位置（经验），例如：
   - “近景，画面下沿在胸口”；
   - “中景，画面下沿在腰部，桌面露出一条边”。
3. 只补，不替代景别词。

## 四、时间段负载检查

官方依据：

- 指南：“指定时间段内容过多，则会导致过度剪切或剧情遗漏。”
- 指南：“不建议用时间戳控制频率/频次”，比如“一秒摇头 3 次”。
- 指南：复杂任务拆成多个简单任务。

检查方法（经验阈值，按生成结果校准）：

- 一个 2–3 秒的时间段里，最多一个主要动作、一次运镜或一次移焦、一个人的明显反应。
- 3 秒内写了三次焦点变化加三个人的反应，就是过载：拆成两个时间段，按原剧本的先后顺序写。
- 发现过载时，先删自己添加的修饰，再拆时间段，最后才考虑拆成两个生成段。原剧本的动作和反应不删，只拆开写。

## 五、群戏写法

1. 不写“其他人保持原位”“众人看着”。每个看得见的人都要有自己的状态：在做什么、看向哪里。（经验）
2. 反应分层，写清谁先、谁后、谁不动（经验）：
   - 离事件最近或关系最直接的人先反应；
   - 外围的人后反应；
   - 至少一人反应不同（不动、避开、反向）。
3. 反应的传播要有触发：一个人先看过去，旁边的人才转头；一声惊叫传开，后排的人才起身。不写全场同一帧一起变脸。（经验；与官方“动作依次发生，不同时抢拍”一致）
4. 群体中有人说话时，只写一人说话，其他人“全程自然闭口”，排除“多人同时说话”。（官方写法）
5. 表演场面的统一律动可以整体写，例如官方乐队案例“乐手们随节奏摇摆律动”；剧情反应不用统一写法。
6. 人数写明，并在贯穿要求中写“人数保持不变，无重复人物”。（官方乐队案例：“无重复人物”）
7. 群像站位见 `references/position-relationship-library.md` 的群像轴。

## 六、示例

```
站位设定：宴会厅中央，主持人站在画面中间的小台上；画面左侧前景是新郎的父亲，坐在圆桌旁；画面右侧背景有一桌五位宾客。
0-3秒：全景，固定机位。主持人念到新娘名字时停下。新郎父亲最先抬头看向画面右侧的门口，握着的酒杯停在半空。右侧那桌离门最近的两位宾客随后转头，其余三人还在交谈。
3-5秒：中景，镜头缓慢推近新郎父亲。他放下酒杯站起来，椅子向后滑开。背景的宾客陆续停下交谈看向门口，最左边的一位低头避开。结束时新郎父亲站在桌旁，酒杯立在桌面上。
5-7秒：近景，固定机位。前景新郎父亲的肩膀清晰，背景门口模糊。门被推开的声音响起后，移焦，焦点从前景的肩膀平滑转到背景门口，门口的人逐渐清晰。
贯穿要求：人数保持不变，无重复人物；同一时刻只有一人说话，其他人全程自然闭口。
```
