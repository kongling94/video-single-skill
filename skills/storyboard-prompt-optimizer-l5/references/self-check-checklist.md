# 自检索引

普通交付在内部按 production-core.md“交付前内部检查”核对，不必额外读取本文件。用户要求审计或复杂专项时用下表定位对应规则，不把全库抄成勾选清单。输出遵守 SKILL.md 的交付结构，默认一句核对结果及未决项；用户要求逐专项结果时才展开。

| 检查项 | 权威定义 |
|---|---|
| 原稿逐次覆盖、原稿重复与模型重复、删改授权、整集范围 | SKILL.md“剧本保护与覆盖核对”“工作与交付” |
| 缺项是否阻塞、默认和继承是否有依据 | SKILL.md“确认政策” |
| 常用镜头、空间、表演、道具、声音、负载 | production-core.md 对应章节；复杂情况按入口路由查详细库 |
| 参数锁定、连续时间戳、素材与声音格式、排除注入 | seedance-2-5-adapter.md 对应章节 |
| 变焦/推拉/移焦、复杂运镜与路径 | production-core.md“选镜、运镜与光影”；camera-movement-library.md 对应条目 |
| 多机位、换位及图文对应 | scene-blocking-axis.md 第九、十节 |
| 道具交接、数量、占手、空间容量 | scene-prop-continuity.md 对应章节 |
| 长台词覆盖、段内不断声与跨任务衔接 | dialogue-scene-continuity.md 第四至八节 |
| 具体情绪、特殊身体状态、群戏、打斗 | 入口已命中的表演/动作/打斗参考对应章节 |
| 特殊转场及验收 | transition-routes.md 对应路线；只查已选用的 transition-catalog.md 条目 |
| 标题和素材准备、关键帧/白模 | opening-ending-title.md、reference-asset-prep.md、适配模块第七八节 |
| 时长不足或润色 | script-polish-capacity.md；删改权限仍由入口决定 |
| 接续、版本和下游影响 | project-state.md，核对采用与验证状态，不将生成偏差改为故事事实 |

必须核对实际文本：计数时间戳、台词、段号与来源，不能凭“写过了”宣称通过。未查看的素材或视频不能标已验看；文本检查不等于出片验证。完整诊断分类见 diagnostic-audit.md，仅输出适用且用户要求的维度。
