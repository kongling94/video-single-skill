# 自检索引

普通交付在内部按 production-core.md“交付前内部检查”核对，不必额外读取本文件。本文件只是该规范检查表的索引，不是第二套执行：不重新跑覆盖、时长、空间核对，只定位某项的权威文件。执行顺序、状态记忆、脏段重算、单一所有者表见 references/execution-flow.md。用户要求审计或复杂专项时用下表定位对应规则，不把全库抄成勾选清单。输出遵守 SKILL.md 的交付结构，默认一句核对结果及未决项；用户要求逐专项结果时才展开。

## 逐镜状态检查定位（分支修正）

触发条件、字段与检查步骤只按 execution-flow.md 第八节；不把本索引变成第二次执行。重点核对实际成稿：

- 关键变化是否有起态、动作、终态；位置、坐站、椅子、身体与头向/视线是否分开？
- 对象变化后是否设计了保持或转向；非主体重新入画是否处于当前状态，而非段首旧状态？
- 起点、同一门槛/通路、到达落点能否对应；连续步行和省略剪辑是否明确区分？
- 交接施事、接触、释放及归属是否单义；普通制作选择是否自行完成，而非无依据禁代词或反复问手别？
- 全程锁、局部动作、排除句是否冲突；只有段首/尾相等却段中跳位的情况是否被漏过？
- 图文是否同一有效空间，背景与光向是否有依据；未收到的图不称已验，已离场不当画外在场？
- 剧情与呈现、转述与实际验看、文本通过与出片通过是否分清；局部返修是否检查同类问题与下游依赖？
