# 场景、道具与动作连续性

使用场景参考图、道具参考图，或分镜跨镜头延续同一个动作（握手、递物、搀扶、开门）时读取本文件。

来源：用户在实际制作中遇到的三类问题；解决方法依据火山方舟《Doubao Seedance 2.5 提示词指南》（下称指南）中的素材映射、编辑、首尾帧、延长和常见问题案例。每条注明是官方写法还是推断。

## 一、场景图里已有的道具被重复生成或叠加

现象：场景图里已经有沙发、茶杯、外套等物品，再上传同一物品另一种状态的参考图，画面出现两个同类物品，或道具穿模、叠在一起。

原因：参考图里看得到的东西，模型默认都会参考；两张图里各有一个茶杯，模型会当成两个物体。指南指出只在图片上呈现映射信息、不在文本里绑定，容易导致混淆或重复（指南原文针对人物，道具同理是推断）。

解决，按优先级：

1. 场景图做成空场景（推断，最稳）：场景参考图只保留固定陈设（墙、地面、门窗、大件家具），会被拿起、移动、改变状态的道具从场景图中去掉，单独做道具参考图。
2. 写清场景图参考哪一部分（官方写法）：指南要求“分工要具体到参考什么，部分参考要写明参考哪一部分”，示例“参考图片 1 的光影和滤镜”。写成“图片 3 只参考客厅的空间结构、墙面、地板、家具摆放和光线，不采用图片 3 茶几上的茶杯”。
3. 把道具参考图和场景里的那件物品绑定为同一个（官方写法的延伸）：指南示例“将纸质车票定义为去大城的火车票”“将图片 5 定义为某场景”。写成“图片 4 的茶杯就是茶几上的那只茶杯，以图片 4 替换图片 3 中原有的茶杯”。
4. 写明数量（官方写法的延伸）：指南在约束里写“同一画面中仅保留单个对应角色，不出现角色重复复刻”。道具写成“画面中始终只有一只茶杯”。
5. 道具状态变化写成动作，不再上传第二种状态的图（推断）：例如“5-8 秒：她喝掉半杯水，杯中水位降到一半”。必须用图片指定新状态时，改用首尾帧（尾帧是新状态），或先生成再用编辑任务修改（指南：编辑写明从 A 到 B 的变化，“其余内容不要变化”）。
6. 排除内容写：同类道具重复出现、道具穿模、道具叠加、道具凭空出现或消失（官方案例排除“手掌穿模”“角色增减”，道具同理是推断）。
7. 每个时间段结尾写道具状态（官方写法）：指南案例每段写“结束时……”，道具也写进去，例如“结束时外套搭在沙发右侧扶手上”。

## 二、切镜后站位互换、握手的手不对

现象：上一镜两人面对面右手握右手，下一镜两人左右互换，或变成右手握对方左手。

原因：切镜后模型重新构图，如果提示词没有重复左右位置、朝向和用哪只手，就可能按自己的理解重画。

解决，按优先级：

1. 关键动作不跨切点（推断，最稳）：握手、递物这类需要双方手部对应的动作，放在一个连续镜头里完成，从伸手到握住到松开都在同一个时间段，用固定机位或缓慢推近，不在握手中途切镜。
2. 每个镜头重复站位（官方写法）：按 `references/scene-blocking-axis.md` 第五、六节，开头写站位设定，每个镜头再写一次“画面左侧是甲，画面右侧是乙”。
3. 写清用哪只手，并用服装锚点区分两只手（推断）：“两人面对面，甲伸出右手（深色西装袖口），乙伸出右手（白色衬衫袖口），右手与右手相握”。手部特写镜头只看得见手，袖口颜色是唯一能区分两人的依据。
4. 写动作结束状态（官方写法）：“结束时两人仍右手相握，甲在画面左、乙在画面右”，下一镜从这个状态开始。
5. 贯穿要求与排除内容（官方写法）：“保持两人的空间方位和视线方向连续”；排除“空间位置跳变、手掌穿模、多余手指、手指粘连”，并加“排除左右手互换”（推断）。
6. 跨生成段时用首帧或延长（官方能力）：下一段要接上一段的动作时，把上一段的最后一帧作为下一段的首帧，或直接用“向后延长 @视频1”续写，让模型从同一画面接着生成。
7. 必须切镜时守轴线：切到手部特写或反打时机位不越过两人连线（见 `references/scene-blocking-axis.md`）。

## 三、场景里有多个同类物体，模型选错了

现象：场景图里有洗手间门和房间正门，正门在侧面只露出门把手，提示词写“去开门”，模型去开了更显眼的洗手间门。

原因：“门”在画面里有两个候选，模型会选画面中最明显的一个；文档没有专门说明这一点，这是根据现象的推断。

解决，按优先级：

1. 不写“门”，写这扇门独有的特征和画面位置（推断）：“画面右侧边缘那扇只露出黄铜门把手的深色木门”，而不是“门”。
2. 在素材指代里给场景中的物体命名（官方写法的延伸，同“将纸质车票定义为……”）：“将图片 3 画面右侧边缘的深色木门定义为房间正门；图片 3 画面左侧的白色门是洗手间门”。之后提示词只用“房间正门”。
3. 写排除（官方写法的延伸）：“她走向房间正门，不走向洗手间门，洗手间门全程保持关闭”。
4. 补一张能看清正门的场景图（推断）：指南支持多张参考图，并建议多视角拆成多张图输入。补一张从另一个角度拍、正门清楚可见的场景图，写明“图片 4 是同一客厅从沙发方向看向正门的视角”。
5. 用镜头先交代目标（推断）：在人物走向门之前，插一个正门门把手的特写或摇镜到正门，让目标在画面里变得明显，再写人物走过去。
6. 用尾帧锁定结果（官方能力）：把“人物手握正门门把手”的画面作为尾帧，模型必须走到那里。

## 四、占手与固定光线

1. 占手检查（经验；官方案例写清了手被什么占着，如周婆婆“用一只手短暂揉一次自己的眼睛”，春丫和石头“仍扶住她”）：
   - 每个时间段开始前，查每个人两只手各拿着什么。
   - 拿着杯子的手不能去开门；要开门，先写放下杯子或换手。
   - 换手、放下、交给别人都写成可见动作，并写落点。
2. 道具只有一件：同一件道具在同一时刻只能在一个地方。被拿走后，原来的位置空着；需要两件时写明数量。（与第一节第 4 条配合）
3. 光线固定（官方依据：指南扩展画布（编辑）案例“静态环境细节在世界空间中保持固定”，编辑案例要求“保留……光线”）：
   - 光源在场景里的位置不随机位改变，例如窗户在左墙，光就一直从左墙来。
   - 反打时，主光照在人物脸上的方向按机位换算，不跟着上一镜照搬（推断）。例如甲脸的左侧被窗光照亮，切到乙的反打时，窗光照亮的是乙的右侧脸。
   - 灯被打开或关掉、太阳落山这类光线变化，写成画面里的事件。

## 五、写进提示词的位置

- 素材指代：写每张图参考哪一部分、不采用哪一部分；给场景中的关键物体命名；把道具图与场景中的物体绑定为同一个。
- 人物设定 / 站位设定：写左右、朝向、用哪只手、服装锚点。
- 时间戳情节：关键双人动作放在一个时间段内完成；每段写人物和道具的结束状态，以及每只手拿着什么。
- 贯穿要求：空间方位、视线方向、道具数量和状态连续。
- 排除内容：同类道具重复、道具穿模叠加、左右手互换、空间位置跳变、走向错误的门或物体。

## 六、示例

用户需求：客厅里两人握手后，女人去开房间正门。场景图片 3 里茶几上有一只茶杯，正门在画面右侧边缘只露出门把手，画面左侧有一扇明显的白色洗手间门。

```
素材指代：男人@图片1，女人@图片2，客厅@图片3。图片3只参考客厅的空间结构、墙面、地板、沙发和茶几的摆放以及光线，不采用茶几上原有的茶杯。将图片3画面右侧边缘那扇只露出黄铜门把手的深色木门定义为房间正门；图片3画面左侧的白色门是洗手间门。
一句话概述：傍晚客厅，男女两人握手道别后，女人走去打开房间正门，写实都市剧风格。
站位设定：男人站在画面左侧，面朝画面右侧；女人站在画面右侧，面朝画面左侧；两人相距一臂。
0-6秒：中景，平视，侧面机位，固定。两人面对面，男人伸出右手（深色西装袖口），女人伸出右手（白色衬衫袖口），右手与右手相握，轻轻晃动两下后松开。结束时两人仍面对面站立，男人在画面左、女人在画面右。
6-8秒：特写，房间正门的黄铜门把手，深色木门占满画面。
8-13秒：中景，镜头缓慢跟随。女人转身走向画面右侧的房间正门，伸出右手握住黄铜门把手，向内拉开门。洗手间门全程保持关闭。结束时女人站在敞开的正门前。
贯穿要求：保持两人的身份、数量、外貌、服装、空间方位和视线方向连续；茶几上始终没有茶杯。
排除内容：不要字幕、水印文字，无背景音乐、配乐、BGM；排除左右手互换、手掌穿模、多余手指、空间位置跳变、走向洗手间门、同类物品重复出现。
```
生成参数：duration=13
