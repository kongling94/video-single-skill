# 表演目标与行为

写有人物表演的镜头时读取本文件，用来决定人物为什么这样动：想要什么、用什么办法争取、身体怎么表现地位和距离。单个情绪的面部写法查 `references/emotion-quick-reference.md`，情绪变化的顺序和触发查 `references/emotion-arc-triggers.md`。

来源：用户提供的《表演系统 ACTING》（迈斯纳体系，原文针对 Seedance 2.0）和《100 种情绪表达·分类版》。逐条对照《Doubao Seedance 2.5 提示词指南》（下称指南）核对，标注“官方写法”“经验”或“推断”。核对全文见 `docs/优化记录-v1.17-表演目标与情绪扩充.md`。

核心原则：表演是人物在压力下争取某样东西的行为，不是展示情绪。提示词以行为为主，简短情绪或语气可作辅助，不以抽象标签代替表演。（经验；与指南“表演细腻真实，不过度夸张”一致）

## 一、设计层：目标、障碍、策略、节奏点

以下内容只在设计时想清楚，不原样写进提示词；写进提示词的是由它产生的可见动作。（经验）

1. 目标：每个在场人物写一个指向对方的动词，例如“逼他还钱”“求她再宽限一周”“让他相信自己不怕”。不写“感到愤怒”“感到内疚”这类状态。
2. 障碍与赌注：什么在阻止他，失败了会怎样。赌注越高，张力越大。
3. 策略：此刻用什么办法争取，例如施压、讨好、恳求、威胁、拖延、讨价还价。一种办法失败，人会换办法；整段只用一种办法，表演会平。
4. 节奏点：一段里策略或局面变化 2–4 次（参考值，不是配额；次数由剧本决定，一人汇报这类单向戏可以只有一次变化，不为凑数新增事件，v1.30）。每次变化在行为上看得见：一个停顿、一个姿势变化、语速变化或视线转移。与 `references/emotion-arc-triggers.md` 的五个功能位合并使用，不另起一套。
5. 潜台词：嘴上说的和真正想要的可以相反。不写“他心里其实……”，让动作和台词出现偏差，例如嘴上说“行”，手里的杯子却放得很重。

## 二、手头动作与中断

1. 剧本或当前状态已有手头动作时，可保留边做事边说话，例如数钱、叠衣服。没有依据时不为避免干站而新增家务、道具或事件。（经验）
2. 关键那句话改变当前行为时，可用停手作标点，不要求每句重话都停手。例如“她擦桌子的手停在半空，抹布还按在桌面上”。（经验）
3. 停顿里要有事发生：人物在判断、在决定、或拒绝回答。视线维持、身体不动或延迟回答也能承载停顿，不强制填手头动作；原剧本写到的停顿一律保留，不删掉。（经验）

## 三、地位写在行为上

以下是可选观察方向（创作经验），不是地位与动作的固定对应。

| 地位 | 可见行为 |
|---|---|
| 高 | 头部稳定不动，动作慢，看人时间长，回答前先停一下，占据空间，随手碰别人的东西 |
| 低 | 小动作多，频繁摸脸摸头发，话说得断断续续，用笑填补空白，说话前先看对方脸色 |

- 地位反转是戏剧事件：强势的人突然露出一瞬间的慌，或一直赔笑的人突然不笑了。写成一个具体动作。（经验）
- 安静可表现掌控，也可能表现恐惧；躁动可表现不安，也可能表现进攻。按本场人物选择表达，不用“强者必安静、弱者必躁动”代替剧情依据。（经验）
- 与 `references/camera-grammar.md` 第三节“角度＝权力关系”、`references/position-relationship-library.md` 的高低轴一起使用。

## 四、距离变化

- 两人之间的距离就是关系：谁拉近、谁拉开、谁僵在原地。距离一变，就是一个节奏点。（经验）
- 不写米数，用参照物写：“隔着一张桌子”“近到能碰到对方的衣袖”“退到门边”。（指南用参照物写身高，如“比走廊画面中的门低一个头”）
- 有动机才移动：走向某物或远离某物。常用的动机动作：逼近、转过身去、对方坐着时站起来、在门口停下、开始收拾东西。（经验）

## 五、倾听的先后

1. 倾听者在信息真正到达时反应：关键字、被看见的动作或声音都可触发，细微或明显反应的时机按剧本，不一律等整句说完。听者闭口不等于身体必须不动；若剧本要求抢话而目标任务存在多人同时说话风险，单列冲突，不擅自删改台词或延后已锁定的反应。（经验；官方案例：倾听者“全程自然闭口，只用眼神和表情回应”）
2. 已有犹豫或判断时可用视线、吞咽或停手承载；原稿要求立即回应、持续凝视或沉默时照原稿，不强加判断动作。（经验）
3. 对方提高音量后，回应可以是语气变化，也可以是沉默、维持原动作或拒绝理会；按人物关系选择，不强制换档。（经验）

## 六、人物表演档案（设计层）

反复出场的人物，在设计时先写一份表演档案，之后每段从中取用。（经验）

档案内容：
- 年龄、体态和身体留下的经历（例如常年弯腰干活的背）；
- 声线：与 `references/dialogue-scene-continuity.md` 第一节的声线句一致，逐字复用；
- 两三个标志性小动作，每个都写清在什么情况下出现，例如“紧张时反复转戒指”；
- 走路的样子：重心、步幅、手臂和头在做什么。直接描述，不起名字，不加引号（引号在提示词里通常表示台词）；
- 面具和面具破裂的条件：平时表现出来的样子，以及“然而，当……时”会怎样变化，至少写一条；
- 一个能让他真正软下来的人或物，只写一个。

写进提示词的方式：
1. 档案不整段放进提示词。每个生成段只取本段用到的 1–2 句，写进人物设定或时间段，避免时间段内容过多（指南：内容过多会导致过度剪切或剧情遗漏）。
2. 只写在场的人物。
3. 换了场景，习惯转化而不删除：习惯踱步的人被迫坐下，就改成抖腿、反复折纸。
4. 档案不写服装、机位和色彩，这些写在提示词其他位置。

## 七、特殊身体状态先写支撑点

人物处在醉酒、生病、受伤、虚脱、刚睡醒、惊吓后腿软等状态时，第一句先写身体的支撑点：靠在哪里、扶着什么、坐在或倒在什么上，再写表情和台词。支撑点不写清，人物容易漂移或站姿不稳。（经验）

执行顺序：
1. 诊断时检测：人物处于以上状态，镜头却没写支撑点，列为风险。
2. 能从已有内容推出的，直接补上，并标注依据。依据只能来自用户已给的站位设定、场景图中的家具陈设、上一段末帧状态。例如站位写“她坐在床边”，补“一只手撑着床沿”，标注“（依据站位设定补充）”。
3. 推不出的，列为待确认槽位，给 2–3 个选项并标出推荐，例如“扶着身旁的桌沿（推荐）／靠墙滑坐在地／被旁人搀扶”。不凭空增加场景里没有的道具或人物。

## 八、减法

- 景别越紧，动作越少：特写只保留视线、呼吸和一处细小变化。（官方写法：“表演细腻真实，不过度夸张”）
- 拿不准时做减法，只减自己添加的装饰性小动作和解释性表情；原剧本写到的动作和表情保留，太多时只在诊断中提示。（经验）

## 九、不吸收的写法

| 原写法 | 不吸收的原因 |
|---|---|
| 只写状态、不写过渡 | 这是 Seedance 2.0 时期的经验。2.5 官方案例大量写过渡，如“原本高兴的眼神突然变得伤心，缓缓垂下眼眸”“眼神里的隐忍慢慢化开……最后破涕为笑”。2.5 按整数秒时间段写动作的先后 |
| 眼睛湿润有光、鲜活、写眼神光 | 指南“情绪过度响应”案例：情绪写到眼睛上容易发光。只写视线、眨眼、眼睑和泪水 |
| 主动新增台词交叠、抢话 | 不为增强张力而新增；原剧本已锁定时保留并单列目标任务风险，不擅自改成轮流发声 |
| 在台词里加入打断、重复、吞音 | 不改用户台词；只在诊断中提示 |
| 步态起名并加引号 | 引号可能被当成台词 |
| 距离用米数 | 改为参照物写法 |
